# 纳兰诗（纳兰性德诗集）

　　同上作者，简介见 `清代/词/纳兰词/README.md`。本文件收其诗 39 首：五七言古近体，以及诗题下分首的作品——
《拟古》《南海子》《汤泉应制》《拟冬日景忠山应制》在诗集里以「题·首句」记为一首一首，题名里的「·」是小题分隔，不是词牌。
词 219 首见 `清代/词/纳兰词/纳兰词.json`。
