====

体例：

- **一行一句，一行一条正文。** 蒙学书是韵语，断句就是原文的一部分，不跨行合并
  （旧版的《千字文》把四字一句排成 250 条、每条两字，是早年按「两字一顿」切的，已照底本改回）。
- **夹注不进正文。** 底本行末的 `(一作「秦眇房」)`、`(唐人作「律召調陽」)` 是异文，收在记录的
  `variants` 里（`{chapter, line, note}`）；正文只留底本的正读。
- **`〔全文完〕`** 是底本的版式标记，不收。
- **繁简、字形一仍底本**（`竒`、`幷`、`徧` 这类生僻写法照录），不按通行本改。
- `author` 照题署；`dynasty` 与 `authors/authors.json` 对齐（王應麟 宋、周興嗣 南北朝、
  李毓秀 清、李廷機 明、史游 汉、李瀚 唐、程登吉 明）。百家姓、增廣賢文作者未詳，记「佚名」，
  朝代取成书期（北宋 / 明）。

## 与旧版的分别

**《三字經》原来的两份（`sanzijing-new.json`「新版」、`sanzijing-traditional.json`「傳統版」）已删。**
两份是同一部书的两种改本：「傳統版」到「廿一史，全在茲」为止，「新版」续到清亡。现在只留一份，
按 `reference/三字經.txt`，底本是**民国增补本**：「遼與金，皆稱帝。元滅金，絕宋世。輿圖廣，超前代」，
明以后到「革命興，廢帝制。立憲法，建民國」，止于「古今史，全在茲」——与旧录的「十八傳，南北混」
「廿一史」都不是一个本子。一件作品只留一份正文，版本差异记在这里，不再留两份副本。

**《百家姓》旧版附「郡望」一表（`origin`），新版没有。** `reference/百家姓.txt` 只有姓氏正文；
郡望表逐姓核过，错处不少（旧 README 的比對表自己就列了「孟〔平陵〕」「谈〔文平〕」几条）。
它既不是底本的内容，也不属于「正文」，这一批不收；要补得另找一部书作依据。

**《千字文》去重 1000 字。** 底本 125 句、每句四字两句，合 1000 字，与「千字文不重复」的说法一致
（旧版 250 条、每条两字，也是 1000 字）。

**《弟子規》按八章分卷**（總敘、入則孝、出則弟、謹、信、汎愛眾、親仁、餘力學文），旧版分的还是七章
（「汎愛眾」写作「泛愛眾」，且「餘力學文」作「余力學文」），照底本改。

**《幼學瓊林》旧版分卷（卷一…卷四）与底本不符**，改为按底本三十三章平列，不套卷。旧版
`paragraphs` 里还有一层 `content`，与全库 `paragraphs`「一行一句」的契约不一致，一并拉平。
旧版 191 条是「一章一条、一段到底」，新版 978 条是一行一段。

**《急就章》《李氏蒙求》是新增的两部书。**《李氏蒙求》旧有一份在
`唐/诗/全唐诗/poet.tang.48000.json`（题「蒙求」，298 条，无夹注），2026-11 删去，改由 `reference/` 生成。

## 勘误

底本有讹字，脚本的 `FIXES` 里逐条改、逐条记，依据写在这里。底本原文未动。

| 书 | 底本 | 改作 | 依据 |
| --- | --- | --- | --- |
| 千字文 | 劒號巨闕 | 劍號巨闕 | 「劒」是「劍」的异体，底本通篇用正体，只此一处误作异体 |

底本里另有一处**不属于讹字**、但值得记一笔的：《千字文》「嶽宗恆岱，禪主云亭」通行本作「嶽宗泰岱」，
底本自己已经用夹注记了「一作嶽宗泰岱」，两读并存，按异文处理，正文不动（`variants` 里有）。

## 底本里另有几处可疑，未改

按「不是自己愿意押上把握的，就不动」：下列几处看着别扭，但没有一部可据的刻本可查，
一律照底本录，留待有版本可依时再定。

- **《五字鑒·下唐紀》**章前一行为散语「因安祿山、史思明、李輔國之亂，曰下唐。」，
  不是五言句。像是底本的编者按语混进了正文，但这家底本全书 884 句其余都是五言，只此一行例外，
  删改都会动到底本的编次，故照录。
- **《五字鑒》韵脚**多处出韵（如「三皇紀」的 皇/黃/光/郎/綱/長/邦/疆/糧/裳/茫/妨/詳 显然不是一韵到底），
  这部书本来就不严于韵，不作改动。
- **《急就章》第三十二章**末句「長樂無極老復丁」是七言，前七句为四言对句；底本如此，照录。
