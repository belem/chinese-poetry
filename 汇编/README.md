汇编
====

跨朝代的整部书，按「一部书一个目录」排在这里，不按朝代切。

```
汇编/
  古文观止/（古文观止.json 母本、12 个卷文件、古文观止·补.json）
  课本选目/（人物故事、寓言故事、山水游记、志人逸事、治学勤读、神话传说、蒙学经典、诸子论道）
  诗文总集/{乐府诗集/（5 卷）, 昭明文选/（91 个文体文件）}
  蒙学/（三字经、百家姓、千字文、弟子规、幼学琼林、朱子家训、声律启蒙、文字蒙求、增广贤文）
```

## 为什么单开一层

顶层是 14 个朝代目录（见 [README](../README.md)）。一部书跨代收文时，按作者朝代切会把它拆散：
《古文观止》收周文到明文 222 篇，按朝代能拆成七八份，读者按书名就查不到了。

## 诗文总集与蒙学为什么也在这里（2026-10）

这两组书原先在 `先秦/诗文总集/`、`先秦/蒙学/`，理由是「所收篇目以先秦为大宗」。可这个理由站不住：

- **`先秦/` 是朝代目录**（顶层 14 个朝代之一），不是「传统文化」目录。按目录名查先秦，
  查到的是 `昭明文选`（梁昭明太子编）、`乐府诗集`（宋郭茂倩编）、`三字经`（宋王应麟）、
  `百家姓`（北宋）、`弟子规`（清李毓秀）——一部先秦的都没有。
- 它们确实跨代：《文选》收先秦至梁，《乐府》收汉魏至唐五代，蒙学十种成于梁至清；
  也没有哪一部真能指认一个主时段（《文选》的赋、诗、书、表铺满六朝，不只先秦）。

按本文开头那条规矩——没有单一主时段的书放这里——两组书整体移入 `汇编/`。

**能指出主时段的仍按主时段落位**。《千家诗》收唐宋人诗、唐宋各占一半，编定于南宋（谢枋得《重定千家诗》，
明王相补五言部分），所以正文放 `宋/诗/千家诗/`，说明留在 [`蒙学/README.md`](蒙学/README.md)。
《唐诗三百首》是唐诗选本，已并进 `唐/诗/全唐诗/poet.tang.*` 作 `tags`，目录不再留副本。

## 古文观止

清康熙三十四年（1695）吴楚材、吴调侯编，12 卷 222 篇。本目录以母本
`古文观止.json`（原 `先秦/蒙学/guwenguanzhi.json`）为准，按卷切出 12 个文件。
原 `先秦/古文观止/卷*.json` 是从这个母本抄出来的子集（227 篇），与母本互有出入——篇前提要、
篇末校记、《古文观止》原书的评注——对不上的 49 篇留在 `古文观止·补.json`，见
[docs/汇编归位.tsv](../docs/汇编归位.tsv)。

## 课本选目

原 `先秦/课外经典/`。八个文件是按主题编的课本选目，不是一个集子名，也不是一部书：
一章《山海经》可以和一段《宋史》编在同一个文件里。篇目多为课本的改写、节选、拉平了的一段
（《精衛填海》只取《山海经·北山经》里的一小段），并进各书会把底本弄脏，所以整体保留在
`汇编/` 下，文件名不变。正文**未逐字对勘**，`fix_progress.json` 记为 `needs_review`。

## 诗文总集

两部诗总集，各自有底本与编次，不合进《全唐诗》《全宋诗》：

- `乐府诗集/`（5 卷）：宋郭茂倩编，收汉魏至唐五代的乐府。与 `唐/诗/全唐诗/` 正文逐字相重的
  （李白《月下独酌》、杜甫《茅屋为秋风所破歌》等）已按「一件作品只留一份正文」删去选本那一份。
- `昭明文选/`（91 个文件）：梁昭明太子编，按《文选》体类分卷（赋、诗、骚、七、诏、表、书……）。
  它一条可以裹几篇（`兩都賦二首`），所以不做跨库并条。

## 蒙学

成于梁至清的十种启蒙读物，没有一部是先秦的，所以从 `先秦/蒙学/` 整目录移到这里。
《千家诗》的正文归 `宋/诗/千家诗/`，《唐诗三百首》并进了《全唐诗》，两本书的说明还留在
[`蒙学/README.md`](蒙学/README.md) 里。各书正文**未逐字对勘**的按原状保留。
