孟子
====

儒家经典，战国中期孟子及其弟子万章、公孙丑等著。全书七篇，每篇分上下，共十四卷。
南宋朱熹与《大学》《中庸》《论语》合称「四书」。

## 说明

繁体中文分发。底本为 repo 内的 [`reference/孟子.txt`](../../reference/孟子.txt)，**整本重出**。

- 14 篇 723 章，篇名照底本（`梁惠王上` … `盡心下`）。
- 底本以 `## 梁惠王上` 标篇、空行分段，一段即一条 `paragraphs`；
  问对分段的照底本分成两条，不并回一段。
- 旧文件 784 段，多出的 61 段是当年从 `poet.xianqin.json` 按「书·卷·篇·节」补录的异文与重复段。
  底本已是完整一本，这些不再保留，见 [`docs/四书校对.md`](../../docs/四书校对.md)。

## 数据格式

```
[
    {
        "chapter": "梁惠王上",
        "paragraphs": [
            "孟子見梁惠王。",
            "王曰：「叟不遠千里而來，亦將有以利吾國乎？」"
        ]
    }
]
```

## 关于「四书五经」

`先秦/四书五经/` 目录已删，四书一目录一本书：`论语/` `孟子/` `大学/` `中庸/`。
五经不在四书里：`诗经/` `楚辞/` 在 `先秦/`，`尚书` `礼记` `周易` 与《春秋》三传在 `先秦/文/`
（《大学》《中庸》原本是《礼记》里的两篇，本目录收的是朱熹合编的单行本）。
