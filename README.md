# chinese-poetry（poem-source）

中华古典诗文语料库。按朝代分目录，一部书一个目录，正文繁体、每行一句。约 **365000** 条正文、**880** 个 JSON 文件，覆盖先秦至当代，以 MIT 协议发布。

fork 链：[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（2016 年 JackeyGao 发起）→ [palemoky](https://github.com/palemoky/chinese-poetry)（大规模数据修正）→ 本项目。本 fork 保留上游全部成果，另做了一轮目录重构与语料增补，详见 [AGENTS.md](AGENTS.md) 与 [`docs/`](docs/)。

## 目录

顶层 14 个朝代目录加一个 `汇编/`，第二层按「一部书」或「诗 / 词 / 文」切：

```
先秦 汉 三国 晋 南北朝（小说/世说新语 诗/ 词/） 隋 唐 五代十国 宋 元 明 清 近现 当 ＋ 汇编

先秦/  诗经 楚辞 论语 孟子 大学 中庸  文/
唐/    诗/全唐诗/（poet.tang.*）  词/ci.tang.json
宋/    诗/全宋诗/  诗/千家诗/  宋词/（ci.song.*）
元/    元曲/yuanqu.json  诗/poet.yuan.json
明/    诗/  词/  小说/（三国演义 水浒传 西游记 陶庵梦忆）
清/    诗/  词/  幽梦影/  小说/（红楼梦 聊斋志异 浮生六记 笑林广记）
汇编/  古文观止/ 课本选目/ 乐府诗集/ 昭明文选/ 蒙学/（十四种启蒙书，2026-11 起按 reference/ 重出）
```

- **一部书一个目录**：《全唐诗》是康熙年间编的一部书，不是「唐代的诗」，书不拆。
- **作者朝代决定归属**：辽、金归 `宋`；春秋战国、秦、商归 `先秦`；1912—1949 年出生的归 `近现`，其后归 `当`。
- **跨代又无主时段的书进 `汇编/`**：《古文观止》《昭明文选》《乐府诗集》、蒙学、课本选目。
- **选本不占目录，占标签**：唐诗三百首、宋词三百首、水墨唐诗、纳兰词并进总集作 `tags`，一件作品只留一份正文。
- 路径与判据的完整说明见 [`docs/目录结构.md`](docs/目录结构.md)。

## 字段格式

```json
{
  "author": "李白",
  "title": "靜夜思",
  "paragraphs": ["床前明月光，疑是地上霜。", "舉頭望明月，低頭思故鄉。"],
  "id": "dhfil4"
}
```

- `paragraphs` 是全库唯一的正文键；词、曲另用 `rhythmic`。
- `id` 为 6 字符短标识，由「作者 + 题名 + 正文」哈希得来，搬目录、重分片都不变号。
- 可选字段：`tags`（选本归属、题材）、`sources`（这条正文还见于哪部书）、`prologue`（赏析）。
- 读数据用 `loader/datas.json`，82 个 dataset 的 key 沿用上游。

## 本 fork 增补的内容

**语料**：海棠诗社（MIT）集外诗文 7791 条及作者小传；补充选本 65 条；《千家诗》224 首（按 `reference/千家詩.txt` 逐首勘正，见 [`docs/千家诗勘正.md`](docs/千家诗勘正.md)）、《昭明文选》443 条、《古文观止》271 篇、《乐府诗集》29 首、《幽梦影》219 条、课本选目 228 条；元曲三百首 27 首并回 `元/元曲/`。各批的来源、判重规则与去向见 [`docs/`](docs/) 下对应 TSV。

**结构**：目录由 25 个平铺语料目录重排为「14 朝代 + 汇编」；`历代/` 按作者朝代拆散；《全宋诗》独立成目录；32 部子史佛经移入 `先秦/文/`；旧键 `content`、`para` 统一并入 `paragraphs`；全库补 `id`。

**名著**：四大章回小说、四部笔记小说与笑话集、《世说新语》各占一个目录，按识典古籍的版本整本收：三国演义（120 回通行本，底本 `reference/三國演義.txt`）、水浒传（容与堂本）、西游记（世德堂本）、红楼梦（庚辰本 79 回）、陶庵梦忆（粤雅堂本，八卷 120 篇）、浮生六记（中央書局本，卷一至卷四）、聊斋志异（青柯亭本，27 篇）、《世说新语》（三十六门 1130 条，底本 `reference/世說新語.txt`）、笑林广记（十二卷 826 则，底本 `reference/笑林廣記.txt`）。`poet.*` 里原来的选篇已删，一件作品只留一份正文。凡未逐字对勘的一律记 `needs_review`，见 [`docs/名著增补.md`](docs/名著增补.md)。

**重写**：`先秦/文/sanshiliuji.json`《三十六计》2026-11 依 repo 内 `reference/三十六計.txt` 整本重写，总说＋36 计共 37 条，每条先本计原文、再【按语】；原文一字未动，仅统一标点。生成脚本 `scripts/import_sanshiliuji.py`。

**重写**：四书与《道德经》2026-11 依 repo 内的 `reference/{論語,孟子,中庸,大學,道德經}.txt` 整本重出，
五部此前都是从别处抓来的副本（《论语》是简体版，《孟子》掺了 `poet.xianqin.json` 补录的异文段，
《道德经》简体且章次错乱）。重出后《论语》20 篇 504 段、《孟子》14 篇 723 段、《中庸》38 段、《大学》16 段、
《道德经》81 章 218 段，正文一字不动跟着底本走，底本夹注移入 `note`。
生成脚本 `scripts/import_sishu_reference.py`，体例与勘误见 [`docs/四书校对.md`](docs/四书校对.md)。

`汇编/蒙学/` 2026-11 同样依 `reference/*.txt` 整本重新生成（声律启蒙、笠翁对韵、龙文鞭影一支出自 `auto/mengxue-sanzhong`；百家姓、三字经、千字文、弟子规、五字鉴、急就章、李氏蒙求、幼学琼林、增广贤文九部出自 `scripts/import_mengxue.py`），一行一句成段，底本行末夹注另收 `variants`。原先的 `sanzijing-new` / `sanzijing-traditional` 两份合为一份，`唐/诗/全唐诗/` 里那份《蒙求》删去。体例与勘误见 [`汇编/蒙学/README.md`](汇编/蒙学/README.md)。

**校勘**：以[识典古籍](https://www.shidianguji.com)刻本为主要依据，辅以搜韵、古文岛、汉典，修正形近音近错字、繁简转换错误、西里尔/希腊字母与假名乱码、`□` 缺字与漏衍字。《全唐诗》内部重出删除 1274 条，814 条归属异说按「一作某」两存。

**不以通行本改底本**：课本写法不等于原文，两者皆有古籍依据的视为异文保留（如白居易《琵琶引》「枫叶荻花秋索索」）。底本残缺、古籍也无法确认的 `□` 缺字与裸露私用区字符仍在数据里，未作猜测。

## 工具

| 脚本 | 用途 |
| --- | --- |
| `scripts/check_structure.py` | 全库质检：乱码、缺字、句长与词牌异常，只报告不修改。PR 只比改动文件，基线由 CI 维护，见 [docs/质检基线.md](docs/质检基线.md) |
| `scripts/collate.py` | 整部合集逐句与古籍对勘，每日分批运行 |
| `scripts/twin_collate.py` | 选本 ↔ 总集互校，一字之差以古籍判定 |
| `scripts/shidian.py` | 识典古籍批量检索取证，生成审核表，确认后写回 |
| `scripts/backfill_ids.py` | 补 `id`、旧 uuid 换短 id；发号时避开库里现存 id，重跑幂等，见 [docs/id去重.md](docs/id去重.md) |
| `scripts/split_dynasty.py` | 按作者朝代拆分语料 |
| `scripts/shidian/` | 识典古籍整书抓取：目录串链、章节取段落、落成记录 |

参与修正请先读 [AGENTS.md](AGENTS.md)，人工与 AI 贡献者适用同一份流程。
