# chinese-poetry（poem-source）

中华古典诗文语料库。按朝代分目录，一部书一个目录，正文为繁体、每行一句。

本仓库 fork 自两个上游：

- [chinese-poetry/chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) —— 项目源头，2016 年由 JackeyGao 发起，收《全唐诗》《全宋诗》《全宋词》《元曲》《诗经》《楚辞》《论语》等；
- [palemoky/chinese-poetry](https://github.com/palemoky/chinese-poetry) —— 本项目实际接续的分支，在上游基础上做了大规模数据修正（剔除重复、以古籍校字、统一字段）。

本 fork 保留两者的全部数据成果，并另做了一轮目录重构与语料增补（见下文）。数据以 MIT 协议发布，见 [LICENSE](LICENSE)。
[belem/chinese-poetry](https://github.com/belem/chinese-poetry) 是同一内容的 GitHub 镜像。

## 目录

顶层是 14 个朝代目录，外加一个 `汇编/`。朝代目录名与 `dynasties/dynasties.json` 的 `name`、`authors/authors.json` 的 `dynasty` 同一个值空间：

```
先秦 汉 三国 晋 南北朝 隋 唐 五代十国 宋 元 明 清 近现 当 ＋ 汇编
```

第二层按「一部书」或「诗 / 词 / 文」体裁切：

```
先秦/  诗经 楚辞 论语 孟子 大学 中庸  文/（35 部子史佛经）
唐/    诗/全唐诗/（poet.tang.*）  词/ci.tang.json
宋/    诗/全宋诗/ 诗/千家诗/  宋词/（ci.song.*）
元/    元曲/yuanqu.json  诗/poet.yuan.json
清/    诗/ 词/  幽梦影/
汇编/  古文观止/ 课本选目/ 乐府诗集/ 昭明文选/ 蒙学/
```

几条规矩：

- **一部书一个目录**。《全唐诗》是康熙年间编的一部书，不是「唐代的诗」；《全宋诗》同理。书不拆，加朝代目录只是第一层导航。
- **作者朝代决定归属**。辽、金归 `宋`；春秋战国、秦、商归 `先秦`；1912—1949 年出生的作者归 `近现`，1949 年以后归 `当`。
- **跨代、又指不出主时段的书进 `汇编/`**：《古文观止》周文至明文 222 篇、《昭明文选》先秦至梁、《乐府诗集》汉魏至唐五代、蒙学十种成于梁至清、课本选目跨先秦至近现代。
  能指出主时段的按主时段落位，《千家诗》唐宋各半、编定于南宋，故在 `宋/诗/千家诗/`。
- **选本不占目录，占标签**。唐诗三百首、宋词三百首、水墨唐诗、纳兰词都并进总集作 `tags`，同一部作品只留一份正文。

## 字段格式

```json
{
  "author": "李白",
  "title": "靜夜思",
  "paragraphs": ["床前明月光，疑是地上霜。", "舉頭望明月，低頭思故鄉。"],
  "id": "dhfil4"
}
```

- `paragraphs` 是正文段落，全库只有一个正文键。词、曲另用 `rhythmic`（词牌 / 曲牌）。
- `id` 是 6 字符短标识，由「作者 + 题名 + 正文」哈希得来，搬目录、重新分片都不变号。
- 可选字段：`tags`（选本归属、题材）、`sources`（这条正文还见于哪部书）、`prologue`（赏析，仅水墨唐诗并入的那批有）。

读数据用 `loader/datas.json`，79 个 dataset 的 key 沿用上游，路径变了不必改代码。

### 二、结构

- **目录从 25 个平铺语料目录重排为「14 朝代 + 汇编」**。原来《全宋诗》混在 `全唐诗/` 里、选本与总集各存一份正文、`历代/` 一锅烩，现在各归其位。
- **一件作品只留一份正文**。唐诗三百首、水墨唐诗、宋词三百首、纳兰词并入总集作 `tags`；《古诗源》与《诗经》《楚辞》相重的删选本那一份。按选本查靠 `anthologies/` 的目次与记录上的 `tags`，不靠目录副本。
- **统一字段**。`content`、`para` 等旧键一律并入 `paragraphs`，全库不再有第二个正文键。
- **补 `id`**。全库 35 万条各有 6 字符短 id，互不重复。
- **拆分错归的书**。32 部子史佛经从「诗」里拆出到 `先秦/文/`；《全宋诗》从 `全唐诗/` 拆出独立目录；隋诗 475 条里混进的 457 条先秦两汉作品归位。

### 三、校勘

以[识典古籍](https://www.shidianguji.com)的刻本、抄本为主要依据，辅以搜韵、古文岛、汉典，修正乱码与错字：

- 形近 / 音近错字、繁简转换错误（`鬥酒` → 斗、`空穀` → 谷、`範蠡` → 范）；
- 西里尔 / 希腊字母乱码、日文假名与注音符号乱码、GBK 字节错位、私用区字符；
- `□` 缺字补全、诗句漏字衍字；
- 《全唐诗》内部重出 1274 条删除，814 条归属异说按「一作某」两存。

**不以通行本改底本**：课本写法不等于原文，两者皆有古籍依据的视为异文保留（如白居易《琵琶引》「枫叶荻花秋索索」）。
改动逐条见 git 历史，`python3 scripts/check_structure.py` 可随时全库重查。

底本残缺、古籍也无法确认的 `□` 缺字（约 4500 处）与裸露私用区字符（300 余处）仍在数据里，未作猜测。

## 工具

| 脚本 | 用途 |
| --- | --- |
| `scripts/check_structure.py` | 全库质检：乱码、缺字、句长与词牌异常，只报告不修改 |
| `scripts/collate.py` | 整部合集逐句与古籍对勘，GitHub Actions 每日分批运行 |
| `scripts/twin_collate.py` | 选本 ↔ 总集互校，一字之差以古籍判定 |
| `scripts/shidian.py` | 识典古籍批量检索取证，生成审核表，人工确认后写回 |
| `scripts/backfill_ids.py` | 补 `id`、旧 uuid 换短 id |
| `scripts/split_dynasty.py` | 按作者朝代拆分语料 |
