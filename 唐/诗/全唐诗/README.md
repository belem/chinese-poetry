全唐诗
======

> 本目录只收《全唐诗》。《全宋诗》已拆到 `宋代/诗/全宋诗/`；宋词在 `宋代/词/宋词/`。

《全唐诗》是清康熙四十四年（1705年），彭定求、沈三曾、杨中讷、汪士鋐、汪绎、俞梅、徐树本、车鼎晋、潘从律、查嗣瑮10人奉敕编校，“得诗四万八千九百余首，凡二千二百余人”，共计900卷，目录12卷。来自[百科](https://baike.baidu.com/item/%E5%85%A8%E5%94%90%E8%AF%97)

## 说明

《全唐诗》是繁体存储，如有需要请自己转换，但转换后的字不符合上下文。

本库对这批数据做过系统性勘误，并与 `御定全唐詩`（同一部书的另一份录文）逐句对勘过，
逐类修法与判例见仓库根目录 README 的「本 Fork 的数据修正」一节。

## 数据形式

*poet.tang.[0-58000].json*，每个 JSON 文件 1000 首诗（末片除外）。

```text
[
  {
    "author": "太宗皇帝",
    "paragraphs": [
      "秦川雄帝宅，函谷壯皇居。",
      "綺殿千尋起，離宮百雉餘。",
      "連甍遙接漢，飛觀迥凌虛。",
      "雲日隱層闕，風煙出綺疎。"
    ],
    "note": [],
    "title": "帝京篇十首 一"
  }
]
```

部分记录另有 `id`、`tags`（选本标签，如「唐诗三百首」）、`sources`（还见于哪些书）、`prologue`（赏析）。

作者表：`authors.tang.json`。

`唐诗补录.json` 是 海棠诗社的语料补入的唐诗。`表面结构字.json` 是平仄签用的结构字表，不是作品。
