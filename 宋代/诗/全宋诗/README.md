全宋诗
======

《全宋诗》是北京大学古文献研究所编纂的一部宋诗总集，1991—1998 年由北京大学出版社出版，
共 72 册，收诗人九千余家、诗作二十余万首。本目录的语料按 1000 首一片存放，
文件名 `poet.song.[0-254000].json`，与上游 chinese-poetry 仓库的编号一致——
编号沿用上游，**不重新分片**，以免下游按文件名取数据的代码失效。

> 历史：这批文件原本放在 `唐代/诗/全唐诗/` 下（上游把《全宋诗》追加在《全唐诗》目录里），
> 目录名与内容不符。2026-xx 已拆出为本目录。`strains/json/`、`rank/poet/` 里的
> `poet.song.*` 仍按原文件名一一对应，可直接与这里的同名文件配对。

## 说明

《全宋诗》是繁体存储，如有需要请自己转换，但转换后的字不符合上下文。

本库对这批数据做过系统性勘误（乱码、缺字、形近音近错字），逐类修法见仓库根目录 README
的「本 Fork 的数据修正」一节，查过哪些文件见 `fix_progress.json`。

## 数据形式

每个 JSON 文件有 1000 首诗（末片除外）。

```text
[
  {
    "author": "李清照",
    "paragraphs": [
      "……"
    ],
    "title": "……",
    "id": "……"
  }
]
```

作者表：`authors.song.json`（8934 位，字段为 `name` / `desc`）。

`error/` 是上游标出的问题数据（无作者、无正文、占位题名等），**不在发布范围内**，
`loader/datas.json` 不收录，`scripts/check_structure.py` 也不扫描。
