# 法名前加「釋」的同人异写

`scripts/dedupe_shi_prefix.py` 的说明。逐组判定见 [`释字头去重.tsv`](释字头去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_shi_prefix.py            # 预演：逐组打印取舍
python3 scripts/dedupe_shi_prefix.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

两书各按自己的规矩称人：《全宋诗》沿佛徒名号加「釋」，《全唐诗》不加。
于是同一个人的同一首诗，被两书各收一次：

```
唐/诗/全唐诗/poet.tang.55000.json#586  延壽《永明山居詩（六十九首） 一》   ← 留
宋/诗/全宋诗/poet.song.0.json#45       釋延壽《山居詩  其一》              ← 删
```

上一批（[`全唐诗全宋诗异作者.md`](全唐诗全宋诗异作者.md)）把两书「作者不同」的组逐组定了归属，
其中这类有 84 组。它的量与别处不同 ——《山居詩》六十余首、《武肅王有旨石橋設齋會進一詩》
一组六首、釋贊寧释乾康等人的偈颂 —— 所以单列一批，用一条机械判据跑，不必逐组查书。

## 判据

1. 组的《全唐诗》侧作者去掉「釋／释」与《全宋诗》侧相同（`延壽` ↔ `釋延壽`）；
2. 《全唐诗》侧那条不是残句（题名不以「句」起、正文不少于 16 字）；
3. 以下任一条成立即判同一首：
   - 正文一字不差；
   - 长度相差 ±10% 且相似度 ≥ 0.90（一字之差的异文，如「凌雲峯／凌雲峰」「窠／窼」）；
   - 《全唐诗》那条是「整首 + 校记」：宋条是它的前缀，多出的尾巴够长且前半段相似度 ≥ 0.90
     （《全唐诗》把 `notes` 里的话也写进了 `paragraphs` ——「见宋诗纪事卷九十一」
     「五灯会元卷十按…」「瀛奎律髓卷四十七释梵类见…」「同前按以上三颂皆为参德韶后作」）；
   - 《全唐诗》那条是整组并成一条（《永明山居詩（六十九首） 六十九》），删拆出来的那一首。

## 不删的

- **《全宋诗》那条正文更全**：《山居詩  其二八》比《永明山居詩（六十九首） 二十八》多一联
  （「轮蹄碌碌何时歇，辗尽红尘为阿谁」）—— 删了就丢正文，留待逐字对勘。
- **《全唐诗》那条更长、宋条只是其中一段**：《偈 一》（61 字）对《偈一首》（28 字），
  《寄題明月禪院（之二）》（144 字，含按语）对《寄題明月禪院二首  其二》（56 字），
  两边各收各的，不能判哪条是副本。
- **作者不是同一个人**：321 组里只有作者去掉「釋」后相同的那部分进了这一批；「釋惠崇」
  与「惠崇」这类如果《全唐诗》侧是残句（《句 一》），也不删 —— 残句不是副本。

## 结果

| 指标 | 清理前 | 清理后 |
| --- | --- | --- |
| 「釋」字头同名组 | 400 | 400（其中同一人 79） |
| 删《全宋诗》记录 | — | 77 |
| 留待对勘 | — | 2 |
| `check_structure.py` missing_char | 6024 | 5953 |
| `check_structure.py` shi_line_length | 151 | 151 |

`missing_char` 降 71 处，是删掉的那批释徒诗里带的 `□`（《山居詩》底本缺字）；
`shi_line_length` 不变。正文一个字没改。

被改过的文件在 `docs/progress/` 里记一条「删了哪条、留哪条」的 fixes，`status` 不动。
