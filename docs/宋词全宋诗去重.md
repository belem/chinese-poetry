# 《全宋词》与《全宋诗》之间的重出

`scripts/dedupe_songci_shici.py` 的说明。逐组见 [`宋词全宋诗去重.tsv`](宋词全宋诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_songci_shici.py            # 预演：逐组打印
python3 scripts/dedupe_songci_shici.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

宋人常把词题作诗题收进诗集（《漁父詞》《漁父樂》《開元樂詞》《白玉樓步虛詞》），
《全宋诗》按诗收、《全宋词》按词收，同一位作者的同一首被两书各录一次：

```
宋/宋词/ci.song.1000.json#80          沈括《开元乐・三台》       ← 留
宋/诗/全宋诗/poet.song.39000.json#155  沈括《開元樂詞  其一》      ← 删
```

两书正文前 16 字相同的组 89 个，分三类：

| 判定 | 组 | 处理 |
| --- | --- | --- |
| 同作者、正文全同或相似度 ≥ 0.95 | 21 | 删诗那一份 |
| 作者不同 | 67 | 两存（两书之间的归属异说） |
| 同作者、正文有出入 | 1 | 两存，记在 TSV |

删诗那一份：词籍是这个调子的本来归属（《全宋词》按词牌编次，`rhythmic` 字段记词牌），
《全宋诗》那边的题名多是后加的分首小注（「漁父樂 無一事」「開元樂詞 其一」），不是诗题。

## 不动的

- **作者不同的 67 组**：《全宋词》与《全宋诗》各记一个人，是归属异说，按老口径两存。
- **正文有出入的那 1 组**：相似度低于 0.95，两存。

## 结果

| 指标 | 清理前 | 清理后 |
| --- | --- | --- |
| 正文前 16 字相同的组 | 89 | 67 |
| 删《全宋诗》记录 | — | 21 |
| `check_structure.py` missing_char | 5953 | 5953 |
| `check_structure.py` ci_pattern | 318 | 318 |

正文一个字没动，删的都是整条记录。
