# 《全宋词》与《全宋诗》之间的重出

`scripts/dedupe_songci_shici.py` 的说明。逐组见 [`宋词全宋诗去重.tsv`](宋词全宋诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_songci_shici.py            # 预演：逐组打印
python3 scripts/dedupe_songci_shici.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

宋人常把词题作诗题收进诗集（《漁父詞》《漁父樂》《開元樂詞》《白玉樓步虛詞》），
《全宋诗》按诗收、《全宋词》按词收，同一位作者的同一首被两书各录一次：

```
宋/宋词/ci.song.1000.json#80          沈括《开元乐・三台》       ← 留
宋/诗/全宋诗/poet.song.39000.json#155  沈括《開元樂詞  其一》      ← 删
```

两书正文前 16 字相同的组 68 个（2026-10-29 已清 21 组），分四类：

| 判定 | 组 | 处理 |
| --- | --- | --- |
| 同作者、正文全同或相似度 ≥ 0.95 | 37 | 删诗那一份 |
| 作者不同 | 24 | 两存（两书之间的归属异说） |
| 同作者、正文有出入 | 3 | 两存，记在 TSV |
| 同作者、诗那一份不到词的一半长 | 4 | 不算重复（组诗里的一首对上了词里的另一首） |

2026-10-30 这一批，两处判据补正：

- **作者比对要去朝代前缀**：诗题作者作「（唐）杜牧」，词作「杜牧」，原先按原字比会判成
  「作者不同」，白放过一批。现在 `author_of()` 去掉「（唐）」这类前缀与「…其一」这类序次。
- **长度差 25% 以上的不算重复**：谢逸《玉楼春》56 字对《絕句》28 字、辛弃疾《生查子》40 字对
  《重葉梅 其一》20 字、张埴《失调名》49 字对《小軒生日 其一》24 字、向子諲《鹧鸪天》55 字对
  《題薌林》28 字 —— 相似度 0.62–0.68，是组诗与词的边界，不是同一首。

删诗那一份：词籍是这个调子的本来归属（《全宋词》按词牌编次，`rhythmic` 字段记词牌），
《全宋诗》那边的题名多是后加的分首小注（「漁父樂 無一事」「開元樂詞 其一」），不是诗题。

## 不动的

- **作者不同的 24 组**：《全宋词》与《全宋诗》各记一个人，是归属异说，按老口径两存
  （惠洪／釋德洪、赵构／宋高宗、王谌／薛嵎《漁父詞七首》这类同人与同题异系）。
- **正文有出入的 3 组**：相似度低于 0.95，两存。
- **长度差 25% 以上的 4 组**：不是同一首，两存。

## 结果
