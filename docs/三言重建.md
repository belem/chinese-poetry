# 《喻世明言》《警世通言》《醒世恒言》整本重出（issue #244）

三部书原先的情况：`明/小说/三言二拍/` 里的《喻世明言》《警世通言》是从识典古籍抓的电子本，
残缺得厉害（喻世明言缺卷 11、12，警世通言只有 23 卷、卷 39 页面错乱），《醒世恒言》根本没进库
（识典上只找得到 5 卷的电子本）。2026-11 按 issue #244 改用 repo 内 `reference/` 的排印本底本，
三部整本重出，一部一个 commit。

**三本必须一次发号。** `make_id()` 是拿「库里现存的 id」去避让的：三本书并行重出时，
各自只让开了自己那个旧文件占的 id，于是同一批 id 被三本各占一份，谁先合谁就把别人的撞掉。
本批在一条分支上按「喻世明言 → 警世通言 → 醒世恒言」固定顺序一次性发号，三本之间、
与全库都不撞码（`make_id` 逐条核对过）。

## 标点：改了什么、凭什么改

底本的标点本身就不统一 —— 同一个句式，有的地方带引号，有的地方不带。本次按
「同句式里带引号的实例占多数」这一条经验证据统一，规则都写在
`scripts/import_sanyan_reference.py` 的 `fix_punct()` 里：

- **补后引号**：本段起了引文（`“`）、念到尾没有 `”`，而下一段已回到叙述。
  喻世明言 40 处、警世通言 45 处、醒世恒言 16 处。
- **补前引号**：上一段是「…《西江月》为证：」「…诗云：」「…词曰：」这类引导语，本段是引文而漏了 `“`。
  依据是同类引导语后面带引号的六十余处、不带的只有个位数，而且不带的那一处，引文自己收着后引号
  （`…随分安闲得意。”`）—— 前后本该成对。本批只需补 1 处。
- **引文转叙述**：引号里的诗念到一半、叙述插进来接着走的（`…独自窝盘三个。”四个打…`），
  把 `”` 挪到诗的末了。喻世明言卷 12 一处。
- **底本点多了的**：警世通言卷 24「吃钟喜酒。。」作一个句号；卷 38 两处半角 `;`、一处半角 `,` 夹在
  汉字中间，改全角。
- **缺字**：底本的私用区码位（`\ue41d` 之类）按全库口径包成 `{…}`，字不补（喻世明言 18、警世通言 56、
  醒世恒言 30 处）；《醒世恒言》卷 13「■纹微皱」、卷 12「〓〓耳有姻缘」是底本自己的空缺记号，
  一律记作 `□`，字不补（通行本前者作「縠」、后者作「似恁」）。

**对话不带引号不动。** 三部书的叙述是「某某道：」直接起话，不带引号，这是底本（也是不少排印本）
的一贯写法，全篇一致，不是漏字，一律不补。

**底本自身的讹字基本不动**（异文、俗字、OCR 讹误都留着，等另一版本逐句对勘）。
只改了拿得出字典证据的两处：《醒世恒言》卷 22「垂肩䴙袖太憨生」、卷 32「云发半䴙」——
「䴙」是《字汇补》才有的僻字（䴙䴘，一种水鸟），此处当是「亸」（下垂），
李绅《嘲李端端》「垂肩亸袖太憨生」可证，两处改作「亸」。
