## 体例

- **一行一句，一行一条正文。** 蒙学书是韵语，断句是原文的一部分，不做跨行合并。
  旧版《千字文》每两个字一条（250 条），是早年按两字一顿切的；底本四字一句，照底本。
- **夹注不进正文。** 底本行末的 `(一作「秦眇房」)`、`(唐人作「律召調陽」)`、`(克，又作「剋」)`
  是异文与校记，收在记录的 `variants`：`[{"chapter": 章名, "line": 正文, "note": 夹注}]`。
  《千字文》17 条、《急就章》27 条、《李氏蒙求》1 条，其余六部底本无夹注。
- **`〔全文完〕`** 是底本的版式标记，不收；`#`/`##`/`###` 的书名行、著者行（`急就章 〔漢〕史游 撰`
  `千字文〔梁〕敕員外散騎侍郎 周興嗣 次韻`）也不收，题名与作者另给。
- **分卷**：底本有 `##` 章节的按章节分（弟子規 8 章、五字鑒 31 章、急就章 32 章、
  幼學瓊林 33 章、增廣賢文 2 卷），无章节的整部平列（百家姓、三字經、千字文、李氏蒙求）。
  《急就章》底本的行款 `○ 第一章` 是章次，转成 `chapter: "第N章"`。
- **字形一仍底本**：`竒`、`幷`、`徧`、`鋗鉇`、`𤬪` 这类生僻写法照录，不按通行本改繁简。
- `dynasty` 与 `authors/authors.json` 对齐：王應麟 宋、周興嗣 南北朝、李毓秀 清、李廷機 明、
  史游 汉、李瀚 唐、程登吉 明；百家姓、增廣賢文作者未詳，记「佚名」，朝代取成书期（宋 / 明）。

## 底本可疑但未改

**《五字鑒·下唐紀》**章前一行「因安祿山、史思明、李輔國之亂，曰下唐。」是散语，不是五言句，
像是编者按语混进正文。全书 884 句其余都是五言，只此一行例外；删改都会动到底本的编次，照录。

**《急就章》第三十二章**前七句四言对句、末句「長樂無極老復丁」七言；**第一至七章**为四言名姓
（每句六字）夹七言长句，第八至三十一章为七言。都是底本原样，不是串行。

**《增廣賢文》**有四处把「個」写作「个」（「哪个人前不說人」「哪个男兒是丈夫」「哪个梳頭無亂髮」
「一个不做聲」等），底本是繁体本，只这几处用了简体「个」。全书字形未统一，未改。

**《增廣賢文》**有两处行末用逗号收句（「別人騎馬我騎驢，仔細思量我不如，」「十分伶俐使七分，
常留三分與兒孫，」），底本如此；下文另起一句「待我回頭看，還有挑腳漢。」，缩进不同说明是断行，
不是漏字。照录。

## 与旧版的分别（逐部）

- **三字經**：旧有「新版」「傳統版」两份。底本 `reference/三字經.txt` 是民国增补本：
  「遼與金，皆稱帝。元滅金，絕宋世。輿圖廣，超前代」，明以后一路到「革命興，廢帝制。立憲法，建民國」，
  止于「古今史，全在茲」，共 118 句——与旧「傳統版」（止于「廿一史，全在茲」）与旧「新版」
  （续到清亡）都不是同一个本子。一本子一份正文，只留这一份；版本差异记在这里，不再留副本。
- **百家姓**：旧版附 `origin` 郡望表（438 姓），底本没有；那张表逐姓核过，错处不少
  （旧 README 的比對表自己就列了「孟〔平陵〕」「谈〔文平〕」「袭/裘」几条）。既非底本内容，
  也不属于正文，这一批不收。
- **弟子規**：旧版分七章，章名作「泛愛眾」「余力學文」；底本是八章，作「汎愛眾」「餘力學文」，照底本。
- **幼學瓊林**：旧版套「卷一…卷四」四卷，底本无卷，三十三章平列；旧版 `paragraphs` 里还有一层
  `content`，与全库 `paragraphs`「一行一句」的契约不一致，一并拉平。旧 191 条一章一段到底，
  新 978 条一行一段。
- **增廣賢文**：旧版 752 条、新 748 条，底本里有两行以逗号收句（「別人騎馬我騎驢，仔細思量我不如，」
  「十分伶俐使七分，常留三分與兒孫，」），旧版把这两对并成了一条，故条数差 4。其余分别都是异文或字形：
  旧版多把句末作问号（「知心能幾人？」），底本一律句号；旧版「爲」、新版从底本作「為」；
  旧版「癡」、底本作「痴」；旧版「哪個人」「哪個男兒」，底本作「哪个人」「哪个」。
  底本这两处在全篇混用简体「个」（另有三处同），是底本自己的不统一，未改，留给维护者定。
- **李氏蒙求**：`唐/诗/全唐诗/poet.tang.48000.json` 里那条题作「蒙求」的 298 句，正文与底本
  逐句相同，只是没有夹注、字形偶有出入（`缝掖/逢掖`、`郤诜/郄诜`），已删，改由本目录收。
