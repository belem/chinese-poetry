# `ci.tang.json` 里的词，《全唐诗》也收了一遍

`scripts/dedupe_tangci_shi.py` 的说明。逐条判定见 [`唐词全唐诗去重.tsv`](唐词全唐诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_tangci_shi.py            # 预演：逐组打印
python3 scripts/dedupe_tangci_shi.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 现状问题

`唐/词/ci.tang.json` 是从《历代》拆出来的唐五代词补录（30 条），
《全唐诗》末几卷按「雜歌謠辭」「曲子詞」的路子把不少词也收了进去：

```
唐/诗/全唐诗/poet.tang.49000.json#411  呂巖《蘇幙遮》  61 字   ← 留
唐/词/ci.tang.json#24                  吕岩《苏幕遮》  62 字   ← 删
```

[`唐词花间集去重`](唐词花间集去重.md) 清的是《花间集》那一头（35 条），这一批清《全唐诗》这一头。

## 判据

1. 正文 `t2s` 归一、去标点后前 16 字相同；
2. 作者同一人（`呂巖／吕岩` 繁简归一后是同一人）；
3. 相似度 ≥ 0.90，且补录那条不比总集长过 1.6 倍。

留《全唐诗》那份：它是整部总集，一条一页、有 `title` 与卷次编次；`ci.tang.json` 是拆出来的补录，
`title` 是 `null`（词牌只在 `rhythmic` 里）。删之前把补录的 `rhythmic` 记进总集那条的 `tags`，
「这是词牌」这层信息别丢。
