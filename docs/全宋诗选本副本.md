# 《全宋诗》里选本并进来的副本

`scripts/dedupe_quanmingshi_anth.py` 的说明。逐条见 [`全宋诗选本副本.tsv`](全宋诗选本副本.tsv)：

```bash
node scripts/shidian/search.mjs q.json results.jsonl     # 每首一句，见 TSV 的差字
python3 scripts/dedupe_quanmingshi_anth.py               # 预演
python3 scripts/dedupe_quanmingshi_anth.py --apply --date YYYY-MM-DD \
    --evidence results.jsonl --qmap qmap.json
```

## 现状

`宋/诗/全宋诗/poet.song.255000.json` 是选本（千家诗、宋诗三百首一类）并进《全宋诗》时留下的那一批：
230 条，标题多作「饮湖上初晴后雨（其二）」「晚春感事」这种并入选本写法。总集里同一首还躺着一条，
两条**几乎逐字相同**——差在繁简之外的个别字上（`沈/沉`、`雁/鴈`、`樽/尊`）。

`scripts/dedupe_qianjiashi.py` 的第 5 条判据当时把这一批「留给选本对齐那条线」，这一批就是来收它的。
口径不变：**删总集那条副本，选本 230 条一条不动**。

## 判据

1. 同一首：正文 `t2s` 归一去非汉字后前 16 字相同，长度相同；
2. 逐字比对**只有一处**出入（差一个字）；
3. 那一字之差查过识典古籍：
   - 两读都见于古籍（同一句的对应位置各有书证）→ 异体字，删副本；
   - 只有一读见于古籍 → 删副本，另一读的讹字**另行记进该文件的 needs_review**，本批不改字；
   - 查不出（`驴/馿`、`麈/尘`、`限/恨` 这一类）→ 两存，不动；
   - 差额是多字、缺字、行序不同（文天祥《正气歌》一类的两份录文）→ 两存，不动。

证据是 112 条检索（差异所在的那一句）、每首取识典古籍结果页里的 6 字窗口逐字投票。

## 顺带发现的讹字

查证时发现总集那边有条目把字录错了（`衣杵相望` ← `砧杵相望`、`井桐` ← `井梧`、
`何曾吹堕` ← `何曾吹落`、`暖烘烘` 那首的 `榾柮` 脱字）。**这一批只删副本，一个字不改**——
那些记进对应文件的 needs_review，另起一轮改字。
