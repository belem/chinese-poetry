# 《幽梦影》在 `poet.qing.json` 里的整套副本

`scripts/dedupe_youmengying.py` 的说明。逐条判定见 [`幽梦影去重.tsv`](幽梦影去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_youmengying.py                      # 预演
python3 scripts/dedupe_youmengying.py --apply --date YYYY-MM-DD
```

## 现状问题

`清/诗/poet.qing.json` 是从 `历代/` 按作者朝代拆出来的补录，正文来自 海棠诗社语料。
里面混着张潮《幽梦影》的一整套 227 条：题名一律「幽梦影·卷一·其一」，一条一段语录。
整部书另有 `清/幽梦影/youmengying.json`（219 条，正文带 `comment` 评语），

于是同一段语录有两份正文：勘误时两边都要改，改漏一处就漂。

## 判据

题名以「幽梦影」开头，并且与《幽梦影》某条对得上——对得上的方式有三种，
按证据强弱依次试：

| 判据 | 例 |
| --- | --- |
| 正文逐字相同（`t2s`、去非汉字） | 「读经宜冬，其神专也……」等 175 条 |
| 一头是另一头的前缀 | 摘条（`poet.qing` 摘了半条）、或一字之差（「其机**畅**也」对「其机**物**也」） |
| 等长而只差一两个字 | 「欸乃」对「欺乃」、「可执**着**」对「可执**著**」这类抄写出入 |
| 每句都见于某条（子序列） | 「花与叶俱可观者……」之于「花之宜于目而复宜于鼻者……」那一整条 |

对得上的删 `poet.qing.json` 那条，留整部书那本（它是成书的单行本，带评语、有编次）。

**序、跋除外。** 《幽梦影》那本没收序跋，`poet.qing.json` 里那 6 条（「序·一～四」「跋·一～二」）
删了就丢正文，留下。

## 本轮结果：227 条里删 202 条，留 25 条

留下的 25 条 = 序 4 条 + 跋 2 条 + 19 条与《幽梦影》对不上的（多是那本把两条并成一条、
而 `poet.qing` 只摘了其中一段，如「幽梦影·卷一·其七」之于「风／世」两字有出入的那条）。
逐条记在 TSV 的「两存」行，留待对勘过后再定。

`poet.qing.json` 从 624 条减到 422 条。改动只有删除：逐条比对过，没有一条正文被改动。
