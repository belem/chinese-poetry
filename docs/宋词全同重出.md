# 宋词全同重出

`scripts/dedupe_songci_full.py` 的说明。逐条判定见 [`宋词全同重出.tsv`](宋词全同重出.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_songci_full.py                     # 预演
python3 scripts/dedupe_songci_full.py --apply --date YYYY-MM-DD
```

## 这一批做的是什么

[`重复体检`](重复体检.md) 按「正文前 16 字相同」分组，一组里正文对不齐的一律两存 ——
那是异文，对的。这里补它管不到的另一种：**整篇正文一字不差**的两条记录。

判据比「前 16 字」严，三条都要：

1. 正文 `t2s` 归一、去一切非汉字后**整篇相同**；
2. 同一个人：署名一字不差，或经同一人异写表（`揚无咎/杨无咎`、`张元幹/张元干` 之类）归并后相同；
3. 同一词牌：比的是 `rhythmic`（去标点），不比 `title` —— `title` 是这首词的小序
   （「其一·和人」），同一词牌下的两首各有小序，比它会把两首不同的词误当成一首。
   `凤栖梧・蝶恋花` 这种一个词牌两个名的，按 `・` 切开算两个名字。

三条都满足就删一条，留信息多的：有题名 > 有 tags > 分句更细。同分留靠前的一条。

## 写回：只让删掉的那几条进 diff

`ci.song.*` 的排版是 `json.dump(indent=2)` 加上**不齐的行尾空格**（同一个内容在不同位置
常是两种写法）。按行号搬行尾（`dedupe_duplicates.dump`）在删条后会把后一条的排版抄给前一条；
按内容查邻居（`dedupe_songci_attr.render`）遇到「同一内容两种写法」仍会翻新一部分行。

这个脚本按记录切：把原文按「`\n` + 缩进 + `{`」切成每条记录一段，重新序列化后逐条对回来
（记录只删不改，两端一次单调对齐即可），对得上的段**整段照抄原文**，删掉的段整段不进输出。
本轮 5 个文件、109 行变动，全是那 11 条记录本身。

- 作者不同的两存组不动正文：宋词归属异说已由 `scripts/dedupe_songci_attr.py` 互挂 `tags`，
  见 [`宋词归属异说`](宋词归属异说.md)；
- 两批录文「差一个字」的异文（`docs/宋词两批异文.tsv` 那 500 组）照旧两存，不在这一轮。
