# `ci.tang.json` 与《花间集》的重出

`scripts/dedupe_tangci.py` 的说明。逐条判定见 [`唐词花间集去重.tsv`](唐词花间集去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_tangci.py                      # 预演
python3 scripts/dedupe_tangci.py --apply --date YYYY-MM-DD
```

## 现状问题

`唐/词/ci.tang.json`（《历代》按作者朝代拆出的补录，正文来自 海棠诗社语料）65 条里，
**35 条是《花间集》里已有的词**。花间集在 `五代十国/词/五代诗词/huajianji/`。
`scripts/merge_anthologies.py` 2026-10 清过 `poet.tang` 里同作者的副本，`ci.tang.json` 是那之后才拆出来的，
两者之间一直没清——同一首词两份正文。

## 判据

正文 `t2s` 去标点后**等长（差 ≤ 2 字）、相似度 ≥ 0.90**，且作者同一人（补录未署名也算）：

| 补录 | 花间集 | 差在哪 |
| --- | --- | --- |
| 韦庄《菩萨蛮（其二）》 | 《菩萨蛮·人人尽说江南好》 | 霜/双 |
| 韦庄《菩萨蛮（其四）》 | 《菩萨蛮·劝君今夜须沉醉》 | 尊/樽 |
| 温庭筠《菩萨蛮》 | 《菩萨蛮 其二》 | 精/晶、颇黎/玻璃 |
| 李珣《女冠子》 | 《女冠子·春山夜静》 | 裾/裙 |

这种一字之差是两种录法的用字不同，不是两首词。删 `ci.tang.json` 那条，留花间集那份
（有底本、有卷次、有词牌）。

## 不删的

- 作者不同的：归属异说，两存；
- 花间集里根本没有的 24 条（吕岩、鲍溶、敦煌曲子、白居易《忆江南》这类）；
- **6 条组词不拆**：温庭筠《新添声杨柳枝词》（两首并成一条）、韦庄《女冠子二首》《菩萨蛮五首》
  （230 字，五首并成一条）、白居易《忆江南三首》等——拆条是另编书，不在这一轮。

## 结果

`ci.tang.json` 65 → 30 条，删 35 条，正文一字未动（逐条比对过）。
