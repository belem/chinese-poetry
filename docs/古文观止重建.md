# 《古文观止》整本重出

2026-11 依 [識典古籍](https://www.shidianguji.com) 光緒二十八年（1902）善成堂重校刊本
（书号 `SDZJ0641`）整本重出，补上逐段白话译文。本文记过程、底本、取舍与已知问题。

## 为什么重出

旧版是爬取稿，四处不合格：

- **正文不对**：无引号，夹注（「一作某」「音某」）混进正文；《梅花嶺記》这类篇目直接断在中间。
- **篇目错位**：卷六之后接的是明文，《送天台陳庭學序》起 18 篇本该在卷七、卷八；卷十二又把这批收了一遍。
- **译文没有**：issue #225 说的「译文跟着不全」其实是**一篇都没有**——全库还没出现过 `translation` 字段。
- **篇目对不上通行本**：卷一周文只有 32 篇，少《寺人披見文公》《齊桓下拜受胙》；补编混进《浣花溪記》
  《遊黃山記》《柳敬亭傳》《芋老人傳》《口技》这些编外篇，另有 22 条补编记录指向卷文件里不存在的 id。

共 **222 篇 / 12 卷**，段级译文逐段与正文对应。字段：

```json
{
  "author": "全祖望",
  "title": "梅花嶺記",
  "paragraphs": ["…", "…"],
  "translation": ["…", "…"],
  "notes": "底本：… 章節 1kxuct5pbqccg。…",
  "id": "…"
}
```

- `translation` 与 `paragraphs` **逐段一一对应**（段数、次序都对齐），不出现 `null` 或空数组。
- 底本夹注、眉批不进 `notes`：`notes` 只记本篇的底本章节号与取字口径。上一轮把夹注抄进 `notes`
  的做法已停 —— 夹注是《古文觀止》的评点，不是正文，混进去既难读也没法校。
- `id` 由 `scripts/backfill_ids.py` 按「作者+篇题+正文」发号。

## 取字的三条口径

1. **正文取 `lineType=1` 的行**。`2` 是双行夹注、`3` 是眉批、`8` 是篇题，都不进正文。
   底本把句读单独排成一行（全库 607 处），拼回时只把纯标点行并进前行、叠标点收敛成一个；
   底本自己缺标点的那 20 来处不动，留给逐篇勘误（见下「已知问题」）。
2. **译文按 `logicSentenceId` 段内定序**。底本返回的译句是批内乱序，`logicSentenceId`
   又是节级共享的：只能按「本段正文里出现的那些 id」对齐，不能跨段、不能只按返回次序。
3. **无译文的段不进库**。底本偶尔把相邻两篇排进同一个响应（《上梅直講書》+《喜雨亭記》），
   或把作者署名单列一段 —— 这些段没有译文，整段跳过。

## 与上一轮（231 篇版）的差异

`890b0f3a` 那一版删《左傳》34 篇正文、只留指针，又加了善成堂本卷末「國朝文」10 篇，篇目变成 231 条：

- **篇目对不上通行本**。通行本是 222 篇、12 卷；「國朝文」十篇是善成堂的附录，不是这本书的篇目，
  本库不留。
- **卷一周文是空数组**。那 34 篇正文归了《左傳》整本，卷一于是什么都没有，读取端加载这本选集时
  卷一空白。本库仍按「一件作品只留一份正文」删选本副本，但 `古文观止·选目.json` 里这一卷 34 条
  都在，「记录」指 `史书/春秋左氏传/zuozhuan.json#<id>`——**目录完整，正文只有整本那一份**。
  判据与复核脚本见 [左传古文观止去重.md](左传古文观止去重.md)、`scripts/dedupe_zuozhuan_gu.py`。
- **《五人墓碑記》重出**：「今文」里的那一篇就是卷十二正篇（張溥），已删。

## 已知问题

- **底本自缺标点**（15 处）：两行都在汉字处断开，或引号收尾后直接接正文，底本没有给出中间的
  断句。补什么标点全凭猜，一处都没补，等逐篇勘误对通行本定。集中在卷十一（《超然臺記》
  《放鶴亭記》《遊襃禪山記》《三槐堂銘》…）、卷十二（《象祠記》《親政篇》《青霞先生文集序》…）几篇。
- **卷五《五帝本紀贊》多一段**：底本的响应把《五帝本紀贊》《項羽本紀贊》两篇排在同一批段落里，
  取段时按 `chapterId` 过滤了，但这一篇的段数仍比通行本多一段，勘误时核。
- **上一轮拼接的残留已按底本重算**：`，。`「？。」这类叠标点全部消掉，只剩《五代史宦者傳論》一处
  （原文「不能與謀，謀之而不可爲」中间底本插了夹注），逐篇勘误时改。
- **底本是粗校**：OCR 讹字（`臧德立違`、`輔車相依`、`長鋏`…）逐条对通行本核过，明细见
  [古文观止勘正.tsv](古文观止勘正.tsv)。这一轮先把篇目、正文、段级译文立稳，逐卷勘误在后续提交里做，
  `docs/progress/` 里 12 卷 + 目录 + 选目记 `needs_review`。
