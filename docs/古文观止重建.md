# 《古文观止》整本重出

2026-11 依 [識典古籍](https://www.shidianguji.com) 光緒二十八年（1902）善成堂重校刊本
（书号 `SDZJ0641`）整本重出，并补上逐段白话译文与底本夹注。本文记过程、底本、取舍与已知问题。

## 为什么重出

旧版按 12 卷拆分，问题三处：

- **篇目错位**：`卷六宋文.json` 之后接的是明文，从《送天台陳庭學序》起到《五人墓碑記》（18 篇）本该在卷七、卷八，却被续编在卷六；`卷十二明文.json` 又把这批篇目收了一遍，只是 id 不同。
- **目录与正文互相指着空处**：`古文观止·选目.json` 里大量「记录」指向 `古文观止·补.json` 的 id，而卷文件里没有这些 id；反过来「补」里 38 篇有 22 篇在正编里另有一份。
- **正文不全**：`古文观止·补.json` 里的《梅花嶺記》只有 7 段（718 字），底本作 9 段 1266 字，结尾「予聞忠烈兄弟…當另爲别室以祀夫人，附以烈女一輩也」整段失落；同类截断在「补」里还有几篇。全库也没有任何 `translation` 字段。

```
  卷七明文.json            13 篇（宋濂至歸有光）
  卷八明文.json             4 篇（歸有光、茅坤、王世貞、袁宏道）
  今文.json                10 篇（善成堂本卷末「國朝文」）
  古文观止·选目.json       231 条目次（卷次 / 篇题 / 作者 / 记录 id）
```

共 **231 篇**、正文 133232 字、译文 227682 字。

字段：

```json
{
  "author": "全祖望",
  "title": "梅花嶺記",
  "paragraphs": ["…", "…"],
  "translation": ["…", "…"],
  "notes": ["1. 順治二年乙酉…", "3. …"],
  "id": "…"
}
```

- `translation` 与 `paragraphs` **逐段一一对应**（段数、次序都对齐），`null` 不出现。
- `notes` 是底本的夹注与篇末评语，`N.` 表示这条注属于第 N 段；夹注不再混进正文。
- `id` 与旧版不同（旧 id 无法与正文对应，已全部重算）。

## 底本

| 项 | 值 |
| --- | --- |
| 书 | 《古文觀止》十二卷，吴楚材、吴调侯编 |
| 版本 | 光緒二十八年善成堂重校刊本（卷末附「國朝文」十篇） |
| 来源 | 識典古籍 `SDZJ0641`（`https://www.shidianguji.com/zh/book/SDZJ0641`） |
| 分篇 | 底本目录 222 个 `chapterId`，其中卷七、卷八在善成堂本里合为「古文觀止卷之六」一个长卷 |

抓取方式：每篇一个章节页，正文、夹注、译文都取自页面内嵌的 `paragraphs/v3` 响应
（`lineType: 1` 正文、`2` 夹注、`8` 题名），带标点的整理文本取自同一页渲染后的 `<p>`。
抓取脚本见 `scripts/shidian/`（`gwz_fetch.mjs`、`lines2.mjs`、`dots.mjs`、`reorder.mjs`）。

## 与旧版的差异

1. **正文用底本的字**。底本与旧版是两套不同的录文，异体字（`於/于`、`旣/既`、`敎/教`…）一律取底本，
   与全库其它书同口径。逐字差异清单见 [`古文观止勘正.tsv`](古文观止勘正.tsv)。
2. **底本讹字改回旧版**。底本 OCR 也有错字（`臧德立違` 误作 `滅德立違`、`輔車相依` 误作 `輔車繫`、
   `長鋏` 误作 `長硤`、`權使其士` 误作 `欋`…），这类逐条列在上表的「处置＝底本误」行里。
3. **缺篇补入**。底本卷五（六朝唐文）缺《范雎說秦王》，据通行本正文补入，译文取自《戰國策》同篇白话（本库未收，暂缺，见下）。

## 已知问题

- 《范雎說秦王》一篇译文暂缺：底本无此篇，白话须另作，未擅补。
- 底本夹注本身有 OCR 残留（短音注如「去聲」「同避」混在注文里），`notes` 里保留了原样，
  只删去了纯拼音的音节。夹注不参与正文校勘，仅供阅读参考。
- 善成堂本的卷七、卷八在底本里合为一卷，本库仍按通行本 12 卷拆分（卷七 13 篇、卷八 4 篇）；
  「今文」十篇是善成堂本的附录，通行本 222 篇之外的内容，单列一个文件，不算进 12 卷。
