## 现在这一版的处理

1. **正文照录底本**：段序、分段、句读一字不动，只改讹字（见下「勘误」）。
   旧版的 `translation`（机器译文）整份不要了 —— 底本没有译文，译文也就无从对校。
2. **篇题取通行本**：底本目次里 12 处题名有讹（脱字、形讹、作者栏串进题里），
   逐条按通行本改，明细见 `docs/古文观止勘正.tsv` 与本文「篇题」一节：
   `产告范宣子轻币` → `子产告范宣子轻币`、`里隔断罟匡君` → `里革断罟匡君`、
   `诸稽郢形成于吴` → `诸稽郢行成于吴`、`颜斶说秦王` → `颜斶说齐王`、
   `触詟说赵太后` → `触龙说赵太后`、`州画像记` → `张益州画像记`、
   `潮洲韩文公庙碑` → `潮州韩文公庙碑`、`乞校正陆贽奏议进御扎子` → `…进御札子`、
   `讳辨` → `讳辩`、`钴鉧沄西小丘记` → `钴鉧潭西小丘记`、
   `五代史宦官传序` → `五代史宦者传论`、`后日复上宰相书` → `后十九日复上宰相书`。
3. **未编码生僻字**：底本用私用区码位 U+E848 记「宛」「炙」两个字的半边（《捕蛇者说》
   「挛{宛}」、《治安策》「{炙}戾」），照全库写法收成 `{…}`，字不补。
   底本还有一处 `太守谓谁？。`（《醉翁亭记》）的叠标点，收敛成一个。
4. **作者归一到 `authors/authors.json` 的写法**：底本目次的出处栏只写书名或人名的
   简称，按通行本署原作者 —— 《左傳》《國語》→ 左丘明，《國策》→ 刘向，《史記》→ 司马迁，
   漢詔 → 刘邦 / 刘恒 / 刘启 / 刘彻 / 刘秀，`相如` → 司马相如、`禹锡` → 刘禹锡、
   `张益` → 張方平（底本把「張益州」拆成了「張益」）、`谷梁传` → 谷梁赤、
   `公羊传` → 公羊高。《檀弓》六篇出《礼记》，作者指实不了，记「無名氏」。
5. **引号补配**：底本断行时把一对引号拆在相邻两段（前段只有 “、后段只有 ”），
   或整段漏了收尾，17 篇逐篇接回。只动引号，字一个不动，见
   `scripts/build_guwen_reference.py` 的 `QUOTE`。

```bash

python3 scripts/dedupe_guwen_books.py --apply --date YYYY-MM-DD --reviewer <名字>
```

《史記》只删 4 篇，是因为 `shiji.json` 的十表只有篇题、没有表序正文：
《秦楚之際月表》《高祖功臣侯者年表》两篇的序在整本里找不到，只能留在选本里；
《伯夷列傳》《酷吏列傳序》《游俠列傳序》《貨殖列傳序》四篇与整本对不上全文，
