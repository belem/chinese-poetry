# 重复体检

`scripts/check_tree.py` 的输出说明。报告本身在 [`重复体检.tsv`](重复体检.tsv)，可随时重跑：

```bash
python3 scripts/check_tree.py --out docs/重复体检.tsv
```

## 判重口径

**正文前 16 字相同**，比较前简繁归一（`t2s`）、去掉一切非汉字字符。取 16 字而不是整篇，是为了让异文也能对上——半首之后有出入的同一首作品同样是重复。

**只在同一部书内部判重。** 这是这份报告最重要的一条口径。

选本收录总集里的作品，是编书方式，不是重复：《昭明文选》按体类收诗、《乐府诗集》按曲调收诗、《历代》是补录，它们与《全唐诗》《全宋词》大量重叠（实测跨书重 8 处，在 34 万条里可以忽略）。把这些算成重复，报告就会淹没在「《文选》里有《古诗十九首》」这类不是问题的问题里。

同一部书的划法：

| 作用域 | 范围 |
| --- | --- |
| 全唐诗 | `唐/诗/全唐诗/poet.tang.*.json` |
| 全宋诗 | `宋/诗/全宋诗/poet.song.*.json` |
| 全宋词 | `宋/词/宋词/ci.song.*.json` |
| 元曲 | `元/元曲/yuanqu.json`（原《全元曲》+ 海棠诗社语料补入的 331 条，同文件） |
| 其他 | 一个顶层目录一部书 |

目录按朝代分层之后，作用域取「朝代/体裁/书名」三级：`唐/诗/全唐诗`、`宋/诗/全宋诗`、`宋/词/宋词` 各成一部书。海棠诗社语料补录时曾用 `sources: ["haitangshishe"]` 把元曲那 331 条分流成另一部书；该标记已清除（海棠诗社语料不是权威合集，不挂 sources），元曲整个文件算一部书。

## 三种判定

| 判定 | 含义 | 处理 |
| --- | --- | --- |
| **同作者** | 正文同、作者同 | 同诗重出，可直接删重复的那条。`poet.tang` 里多是「樂府 / 非樂府」两套标题各收一次 |
| **异作者·同题** | 正文同、作者不同、题名同 | 作者归属异说。**两条都留**，改挂 `tags` 互指 |
| **异作者·异题** | 正文同、作者不同、题名不同 | 需人工判：可能是误收，也可能是联句拆条、组诗拆条 |

## 剩余三项分别怎么办

「异作者」的两类里有一半根本不是重复，2026-11 起按下面的口径逐批清：

| 判定 | 实际是什么 | 办法 | 状态 |
| --- | --- | --- | --- |
| 同作者 | 《全唐诗》樂府／非樂府两套目录各排一遍；元曲补录撞题；宋太宗组诗两收 | 删信息少的那条 | 唐诗、元曲、宋太宗组诗 2026-10 已清完；元曲剩余 22 组 2026-10-29 清完（见下节） |
| 异作者·同题 | 归属异说（柳永／欧阳修《蝶恋花》）；同一人的两种署名（扬无咎／杨无咎） | 两存，互挂 `tags` 一条「一作某」 | **宋词 2026-11 已做完**，见 [`宋词归属异说.md`](宋词归属异说.md) |
| 异作者·异题 | 全宋诗一半是联句、组诗拆条；全唐诗是编排卷 | 联句要并成一条多人联句；编排卷不动 | 未做 |

「跨书互见」（同一首被两部书收录，如《昭明文选》与《古文观止》都收《諫逐客書》）一律不算重复：
那是编书方式，用 `sources` 表达。2026-11 起 `check_tree.py` 把这一类单独计数打印，
免得读者把它当成漏判。

「同题多首」（同作者、两录的题名只差结尾的「其 N」）同样另计不算重复，2026-10-29 起：

- 《全宋诗》把组诗拆成一条一首（`緣識 其一`、`緣識 其二`…），两种录本的组诗序号未必对得齐，
  取前 16 字判重会把 `逍遥詠 其八` 与 `緣識 其三` 报成重复。这类豁免 91 条，都是同作者、
  题名对得上的；**异作者**同题的（毕士安／毕仲游《楊照承議蘆雁枕屏》）照旧报。

## 元曲「同一支曲长短两录」：2026-10-29 清完 25 组

上一轮留下的「元曲补录撞题」标为已清，其实只清了残句：补录的《元曲三百首》曲文与原有
`yuanqu.json` 题名格式不同（`正宫・白鹤子（四首）` vs `正宫·白鹤子`），上一轮的判据要求
「长句是套数、短句题名也是同一支曲」，两样都卡住了。2026-10-29 逐组核过 63 组，改写口径后
`scripts/dedupe_duplicates.py` 的 `yuanqu_cover()` 能自动定案 25 组：

| 情形 | 判据 | 组数 |
| --- | --- | --- |
| 短的一段是一支曲 | 短句的每一句都按序在长句里，题名同一支（`・` / `·` 同一、书题有无都算） | 21 |
| 短的是一支、长的接了别的曲 | 长句书题 = 短句书题 + 另一支曲的书题（`湖上归` / `湖上晚归`、`庄家不识构阑` / `庄家不识勾栏`），且长句三倍以上 | 4 |
| 异作者 | 同一支曲署了两个人的名（关汉卿／无名氏） | 1，两存 |

留下的 38 组不动，都有据：同题组曲的一支另立一条（《大德歌·春》之于《大德歌（四首）春》，
是编法）、同曲牌的异曲（马致远《四块玉·恬退》与《四块玉·叹世》起句相同）、归属异说
（关汉卿／曾瑞《青杏子·骋怀》套数）。

几处值得注意的：

- **《全唐诗》2026-10 已做过一轮内部去重**（`scripts/dedupe_tang.py`，见 [`唐诗内部去重.md`](唐诗内部去重.md)）：删作者名下的重出 1274 条，782 组归属异说按「一作某」两存并互挂 `tags`（2026-10-30 起由 `sources` 改挂）。报告里剩下的 846 条多是那些两存的异说，以及编排卷（郊廟歌辭／樂府…）与作者名下并列的条目——那两种按体例不删。
- **《全唐诗》的重复是真重复。** `雜曲歌辭 踏歌詞 一` 与 `踏歌詞三首 一` 是同一首，作者都是謝偃，各收一次；`郊廟歌辭 封泰山樂章` 在 `poet.tang.0.json` 与 `poet.tang.4000.json` 各一套。937 条同作者重复绝大多数属于这类，是编书时按「樂府 / 非樂府」两套目录各排一遍造成的。
- **《全宋诗》的重复一半是联句与组诗拆条。** 如《來燕堂聯句》一条记在赵概名下，另一条完整收在欧阳修名下，另有两条同题各记韩绛、王珪——同一首联句被拆成四条。这类不能简单删，得并作一条多人联句。
- **《全宋词》的 201 条同作者重复**，多是 `ci.song.0.json` 与 `ci.song.22000.json` 两批数据重叠（后者是后补的一批），同词牌同正文，一条带 `title` 一条不带。
- **蒙学的 `sanzijing-new.json` 与 `sanzijing-traditional.json`** 是同一部《三字经》的简繁两版，正文归一后相同。这是有意的简繁各一份，不算重复，报告里留着提醒而已。
- **元曲那 10 条同作者重复**，是 海棠诗社语料补录的《元曲三百首》曲文与原有 `yuanqu.json` 重了。补录时按「同作者 + 题名覆盖率」判重，这两条题名格式不同（`正宫・白鹤子（四首）` vs `正宫·白鹤子`）没对上。

## 朝代字段体检

`dynasty` 取值不在 `dynasties/dynasties.json` 的 `name` 里的，11288 条：

| 文件 | 值 | 条数 |
| --- | --- | --- |
| `元曲/yuanqu.json` | `yuan` | 11272 |
| `历代/other.0.json` | `yuan` | 16 |

全是拼音，其余地方用中文「元」。与作者索引冲突 0 条——`dynasty` 只在这两处出现，其余目录根本没有这个字段，那才是「朝代对不上」的根因：不是值错了，是没有这一维。

`authors/authors.json` 覆盖 2402 位作者，`poet.song.*` 25 万条里只有 5.1 万条能对上。补 `dynasty` 字段要跟作者索引扩容一起做，是第 4 批的事。
