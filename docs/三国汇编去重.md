# `poet.sanguo.json` 里转载自汇编选本的篇目

`scripts/dedupe_sanguo_huibian.py` 的说明。逐条判定见 [`三国汇编去重.tsv`](三国汇编去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_sanguo_huibian.py            # 预演
python3 scripts/dedupe_sanguo_huibian.py --apply --date YYYY-MM-DD
```

## 现状问题

`三国/诗/poet.sanguo.json`（40 条）是从 `历代/` 拆出来的补录，诗与文混放，没有底本信息。
里面有一批是从《昭明文选》《乐府诗集》《古文观止》《课本选目》转载来的：

```
汇编/昭明文选/诗·杂诗上.json#7   曹子建《情詩》   60 字   ← 留（选本有底本、有编次）
三国/诗/poet.sanguo.json#…       曹植《情诗》     60 字   ← 删（补录转载）
```

## 判据（三条都要）

1. 作者同一人（`曹植／曹子建`、`曹丕／魏文帝` 这类名／字、名／谥号按别名表归一）；
2. 题名对得上（`t2s` 归一后相等，或补录多「（并序）」这类后缀、选本多书名前缀）；
3. 正文相似度 ≥ 0.95。

异文一字之差（`是/自`、`遥/徭`、`治/冶`、`亨/享`）也放行：补录是转载件，
正文不是独立来源，异文以选本底本为准。**这与其它批次「一字之差不删」的口径不同，理由就在这里。**

**两条不删**：
- 选本的一条是并合件 —— 《昭明文選·騷》把《九歌》四首、《九章》合成一条（627 / 309 字），
  补录逐首一条；《九辯五首》同理。编法不是重复；
- 正文相似度 < 0.95。

## 本轮结果

删 6 条：曹植《七哀诗》《情诗》《赠白马王彪（并序）》、曹丕《典论·论文》、
诸葛亮《后出师表》《诫子书》。`poet.sanguo.json` 40 → 34 条，正文一字未改。

留下的：《七步诗》（与 `汉/古诗源/汉魏六朝诗.json` 逐字相同，但那是选本对选本，
按「选本收总集是编书方式」不动）、曹植《七哀诗》的《昭明文選》那一份（三处各有副本，
删的只是补录那条）。

## 还没做的

`poet.jin.json` 的《猛虎行》102 字、《詠史八首》579 字对《咏史其一》80 字），
这类按编法不动；要逐首并进总集的 tags 是 `docs/选本对齐.md` 那条线的事。
