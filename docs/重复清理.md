# 重复清理

`scripts/dedupe_duplicates.py` 的说明。逐条判定见 [`重复清理.tsv`](重复清理.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_duplicates.py            # 预演
python3 scripts/dedupe_duplicates.py --apply    # 写回数据，并生成 重复清理.tsv
```

## 为什么另起一件工具

[`重复体检`](重复体检.md) 只报告：全库 3165 条「同一部书内、正文前 16 字相同」的多余记录，
按判定分成同作者 / 异作者·同题 / 异作者·异题三类，绝大多数要人判（联句拆条、归属异说、
组诗拆条、异文两存）。这个脚本只吃其中**能自动定案**的那几类，一次清完，剩下的原样留给人工。

判重口径与体检一致：正文简繁归一（`t2s`）、去掉一切非汉字字符、比前 16 字。

## 六类，逐条有据

| 类别 | 范围 | 判定 | 本轮 |
| --- | --- | --- | --- |
| `songci_merge` | `宋/宋词/ci.song.22000.json` 与其余 ci.song.* | 新批正文是旧批的前缀（或相等）→ 删新批；断句不同但一字不差也算 | 4 |
| `yuanqu_cover` | `元/元曲/yuanqu.json` | 一条是另一条的开头：同作者删短句，异作者两条都留、长句挂 `tags` 互指 | 24 + 2 |
| `sanguo_dup` | `三国/诗/poet.sanguo.json` | 简繁两种转录同录一首（等长、只差异体字与缺字）→ 留带 `tags` 的一条 | 1 |
| `kongzi_subset` | `汇编/课本选目/*` | 同题同作者，一条正文是另一条的真子集 → 删选段 | 1 |
| `guwen_subset` | `汇编/古文观止/古文观止·补.json` | 补篇正文被分卷收全 → 删补篇 | 3 |
| `qingci_attr` | `清/词/ci.qing.json` | 纳兰性德名下一条与佟世南同词重出（只差一字），纳兰词集不载 → 删纳兰那条 | 1 |

合计删 34 条，另 2 条挂 `tags`。

### 宋词两批数据

`ci.song.22000.json` 是后补的一批，与 0–21000 各卷大量重叠：清理前 640 组 / 644 条，清理后 641 组
（其中同作者 523 组、异作者 118 组）。
两批录文来源不同，**大多数是异文**——断句不同、个别字不同（「濛濛/蒙蒙」「无憀/无聊」
「檀郎/槟郎」），也有旧的明显讹字的地方（潘阆《酒泉子》「弄**涛**儿」应是「弄**潮**儿」）。
两批的 `title` 互补性也很小（新批 799 条有题、旧批多半是 None，但新批里只有个位数能在旧批找到
同题目的记录），所以不能拿「谁的题名更全」当取舍依据。

所以只删两类：新批正文被旧批包含（旧批更全），或断句不同而正文一字不差。
剩下同作者的 519 组异文两存，等 `宋词对勘` 逐首核对古籍后再定，逐条仍在 `check_tree.py` 的报告里。

**异作者**的 118 组一条不删：那是《全宋词》本身的归属异说（柳永/欧阳修《蝶恋花》、
仲殊/宝月一组），与《全唐诗》的口径一样，交给对勘。

### 元曲的残句

`yuanqu.json` 里有 26 处「一条短句正好是另一条的开头」，多是同一支曲的残篇：
`黄钟・侍香金童` 只有 31 字，同一支曲的完整套数 255 字；`正宫・端正好上高监司` 只有 27 字，
完整本 981 字。同作者的删残句，异作者的两条都留、长句挂 `tags: ["一作某人"]`。

套数里每支曲单列一条时，也会出现「短的一条是长的一条的开头」—— 那是同一作者的不同曲子。
所以这里只处理「短的一条不足一首」的情形（长短相差 2 倍以上），逐条列在 TSV 里供复核。

## 与审查进度

被改过的文件在 `docs/progress/` 里记一条「删除记录 + 留哪条」的 fixes，`status` 不动 ——
删重复不是逐字对勘，不能因此算 `clean`。

剩下的 3133 条都是要人判的：全宋诗 1645 条（联句拆条、组诗拆条、宋太宗一人的组诗重出）、

以及课本选目里同文异题的两条。
