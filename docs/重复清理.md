# 重复清理

`scripts/dedupe_duplicates.py` 的说明。逐条判定见 [`重复清理.tsv`](重复清理.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_duplicates.py            # 预演
python3 scripts/dedupe_duplicates.py --apply    # 写回数据，并生成 重复清理.tsv
```

宋词两批异文那一轮另需检索结果：`--work <dir>`（`scripts/shidian` 的 results.jsonl 所在目录）。
判定已写进 `SONGCI_REVIEW` / `SONGCI_NEW_ERR` 与 [`宋词两批异文.tsv`](宋词两批异文.tsv)，
不带 `--work` 也会照上一轮的结论走，只是不再重算证据。

## 为什么另起一件工具

[`重复体检`](重复体检.md) 只报告：全库 3165 条「同一部书内、正文前 16 字相同」的多余记录，
按判定分成同作者 / 异作者·同题 / 异作者·异题三类，绝大多数要人判（联句拆条、归属异说、
组诗拆条、异文两存）。这个脚本只吃其中**能自动定案**的那几类，一次清完，剩下的原样留给人工。

判重口径与体检一致：正文简繁归一（`t2s`）、去掉一切非汉字字符、比前 16 字。

### 宋词两批数据

`ci.song.22000.json` 是后补的一批，与 0–21000 各卷大量重叠：清理前 640 组 / 644 条，清理后 641 组
（其中同作者 523 组、异作者 118 组）。
两批录文来源不同，**大多数是异文**——断句不同、个别字不同（「濛濛/蒙蒙」「无憀/无聊」
「檀郎/槟郎」）。两批的 `title` 互补性也很小（新批 799 条有题、旧批多半是 None，但新批里只有
个位数能在旧批找到同题目的记录），所以不能拿「谁的题名更全」当取舍依据。

按两批逐字对出来的 545 组里，**等长、只有个别字不同的 505 组**已逐条到识典古籍查过
（932 条检索、1.6 万条段落片段，脚本 `scripts/dedupe_duplicates.py songci-diff`，
逐条核对表 [`宋词两批异文.tsv`](宋词两批异文.tsv)）：

- 差异集中在少数几对通用字上：`沈/沉` 40、`著/着` 36、`锺/钟` 23、`翦/剪` 22、`祗/只` 10、
  `馀/余` 9、`拼/拚` 4、`醿/醾` 5 —— 旧批用本库的字形，新批用通行字，都不是错字。
- 其余一字之差（`远/还`、`孤/辜`、`画/昼`、`坠/堕`……）绝大多数**没有一处**能在古籍里找到
  「只差这一字、其余全同」的读法；找到的等长段落要么全同（证实旧批原样），要么差在别处。
  两读都无从证伪的，按版本异文两存。

但「两批互见就是异文」这个结论不能一概而论。2026-10-29 按全库 516 组逐句回检（`scripts/shidian`
检索、按句子窗口对齐、逐字投票，见下表），剩下的差异里有一小撮**新批是讹字**：

| 判定 | 例子 | 处理 |
| --- | --- | --- |
| 只有新批那一读见于古籍 | 苏轼《满江红·寄鄂州朱使君》旧批「岷峨云浪」，新批「雪浪」（《东坡乐府》作雪浪） | 两存 |
| 只有旧批那一读见于古籍 | 苏轼《醉落魄·离京口作》旧批「记得歌时」，新批「公子佳人」；辛弃疾《满江红·中秋寄远》旧批「玉纤横笛」，新批「横管」 | **删新批那条**（旧批有一份完整正文） |
| 两读都有古籍 | 陈亚《生查子》「檀郎读」/「檳榔读」；蒋捷《一剪梅》「度与娇」/「渡与桥」 | 两存 |
| 都没找到 | 吴文英《寿毛荷塘》「豪/毫」等 3 首 | 两存，见 TSV |

本轮删 9 条（都是第二种），两存 536 条逐条记在 TSV 的 `verdict` / `evidence` 列。
两类不需要古籍的照旧删：新批正文是旧批的前缀（旧批更全），断句不同而正文一字不差。

**异作者**的 118 组一条不删：那是《全宋词》本身的归属异说（柳永/欧阳修《蝶恋花》、
仲殊/宝月一组），与《全唐诗》的口径一样，交给对勘。

### 元曲的「残句」：24 条误删已全部撤回

上一版把 26 处「一条短句正好是另一条的开头」当残篇处理：同作者删短句，异作者在长句挂
`tags: ["一作某人"]`。这个判据是错的 —— **前缀重合不等于重出**，误删的大多是完整作品：

- **雅词与散曲同用一个曲牌的起句。** 张可久《折桂令·九日》「对青山强整乌纱」与姚燧
  《凭阑人》「对青山强整乌纱」撞头，张可久《人月圆·春日次韵》与徐再思《人月圆·甘露怀古》
  撞头，徐再思《卖花声》与另一首《卖花声》撞头 —— 三对都是不同的两支曲。
- **同题组曲的第一支被单列一条。** 关汉卿《大德歌·春》（「子规啼，不如归」）与《大德歌四首》
  的第一支、白樸《阳春曲·知几》（「知荣知辱牢缄口」）与《知几》组曲第一支，都是组曲的头一支，
  单列一条是这批评语的排法。
- **换了题名、署了两个人，是归属异说。** 王實甫／王德信《十二月过尧民歌·别情》、
  真真／真氏《解三酲》、关汉卿／无名氏《离亭宴煞》、朱帘秀／珠帘秀《寿阳曲·答卢疏斋》——
  同曲异署，与《全唐诗》一个口径：两存，不挂「一作」。

现在只有同时满足下面两条才删：**长句本身是套数**（正文出现套数标记 `【曲牌】`，或题名标了
「套数」），**且短句的题名也是同一支曲的题名**。按这一条重跑，24 条一条都不该删，已全部恢复
（`yuanqu.json` 11622 → 11646 条）。剩下 26 处前缀重合逐条记在 TSV 的 `yuanqu_cover_open` 行，
两条都留。
