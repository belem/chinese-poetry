# 《左传》单行本与《古文观止》同名篇目

`scripts/dedupe_zuozhuan_gu.py` 的说明。逐组判定见 [`左传古文观止去重.tsv`](左传古文观止去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_zuozhuan_gu.py            # 预演：逐组打印
python3 scripts/dedupe_zuozhuan_gu.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 现状问题

`先秦/文/zuozhuan.json` 是《左传》整部书的单行本（278 条，按纪年一路排下来）；
`汇编/古文观止/` 卷一、卷二、补编里另有一批同题的篇目——它们本来就从《左传》里摘出来：

```
先秦/文/zuozhuan.json#d0jg5l   左丘明《石碏谏宠州吁》  229 字   ← 留
汇编/古文观止/卷一周文.json#2  左丘明《石碏諫寵州籲》  229 字   ← 删
```

两书按题名对得上的 31 组。同一篇作品两份正文，勘误时两边都要改，改漏一处就漂。

## 与 `汇编与诗去重` 的取舍相反

[`汇编与诗去重.md`](汇编与诗去重.md) 那批删的是**补录**、留选本：`poet.*` 是《历代》拆出来的散录，
没有版本信息，而选本有底本、有编次、有篇题。

这一批反过来。`zuozhuan.json` 是整部书，选本这一篇只是从书里摘的同一段；
按「一件作品只留一份正文」，留书、删选本摘录。

选本目录要记的是「《古文观止》收了哪几篇」，删掉整条会丢这层信息，
所以删下去的那 7 篇在 [`汇编/古文观止/古文观止·选目.json`](../汇编/古文观止/古文观止·选目.json)
留一份目次：卷次、篇题、作者、对应 `zuozhuan.json` 的记录 id。正文只有单行本那一份。

## 判据：`t2s` 归一之后一字不差

两书的繁简、用字本有出入（`寘/置`、`焞/炖`、`馀/余`、`翦/剪`、`榖/谷`、`殽/崤`），
所以比较用 `t2s` 归一、标点一律不计。归一后一字不差、且不比单行本短的有 14 组
（其中 7 组落在《古文观止·补》与卷一、卷二各排一遍的那几篇上）。

**只删 7 组，另 7 组两存**，因为「一字不差」的那一边是**选本比单行本多**：

| 情形 | 例 |
| --- | --- |
| 选本比单行本多了纪年文字 | 《齐桓下拜受胙》（选本多「夏会于葵丘，寻盟且修好，礼也」13 字）、《子鱼论战》（多「二十有二年春公伐邾取须句……」72 字）、《吕相绝秦》（多「夏四月戊午」）、《子产坏晋馆垣》（多「公薨之月」） |
| 选本夹了注 | 《介之推不言禄》（「绵上地名」）、《展喜犒师》（「用是」） |
| 一边多一联、各有出入 | 《郑伯克段于鄢》（`寘/置` 一字之差）、《齐桓公伐楚盟屈完》（`榖/谷`）、《蹇叔哭师》（`崤/殽`）、《驹支不屈于晋》（`剪/翦`）、《齐国佐不辱命》（`馀/余`）、《宫之奇谏假道》（`焞/炖`） |

删了的 7 组是：选本与单行本正文**两边完全一致**的那几篇——《石碏谏宠州吁》《臧僖伯谏观鱼》
《王孙满对楚子》《祁奚请免叔向》《子产却楚逆女以兵》《子革对灵王》《吴许越成》。

## 不动的两类

- **正文对不上**：《臧哀伯谏纳郜鼎》（单行本多「周内史闻之曰：臧孙达其有后于鲁乎」一评）、
  《蹇叔哭师》（选本多「冬，晋文公卒……」一段）、《郑庄公戒饬守臣》（选本夹「序民人一作序人民」）、
  《祁奚请免叔向》补编那条只有全篇前半（172 字 vs 334 字）、《子产却楚逆女以兵》补编那条
  配的是《徐吾犯之妹美》、《吴许越成》补编那条配的是「吴子使来儆师伐齐」那一段、
  《宫之奇谏假道》补编那条只取前四段。**抄配了别篇正文的两条建议日后按影印本订正，本批不删。**
- **同题不同文，本批不动**：《郑伯克段于鄢》等 6 组一字之差在 `t2s` 归一后仍在，
  是两读都传世的异文（`寘/置`、`榖/谷`、`崤/殽`、`剪/翦`、`馀/余`、`焞/炖`），按老规矩两存。
