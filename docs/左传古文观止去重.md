# 《左传》单行本与《古文观止》同名篇目

> **2026-11 已改判**：单行本 `先秦/文/zuozhuan.json` 整份删除，改由 repo 内
> `reference/二十四史/春秋左氏传.txt` 整本重出为 `史书/春秋左氏传/zuozhuan.json`（见
> [春秋左氏传重建.md](春秋左氏传重建.md)）。原先「两存」的口径随之作废：新版《左傳》
> 是十二公二百五十五年的全本，选本这一篇只是从书里摘的同一段，按「一件作品只留一份正文」，
> **留书、删选本摘录**。本文记这一批的判定，逐组明细见 [`左传古文观止去重.tsv`](左传古文观止去重.tsv)。

## 这一批删了什么

`汇编/古文观止/卷一周文.json` 34 篇全是《左傳》，逐篇都在新本里能对上：

| 项 | 值 |
| --- | --- |
| 选本篇数 | 34（卷一周文，署左丘明） |
| 删 | 34 篇正文，`卷一周文.json` 因此为 `[]` |
| 留 | `史书/春秋左氏传/zuozhuan.json` 一份正文 |
| 目次 | `古文观止·选目.json` 34 条的「记录」改指 `zuozhuan.json#<新 id>`，篇目信息一条不少 |

`卷二周文.json` 里署左丘明的 12 篇**一条没动**：其中 11 篇出自《國語》（祭公諫征犬戎、
召公諫厲王止謗、襄王不許請隧、單子知陳必亡、展禽論祀爰居、里革斷罟匡君、敬姜論勞逸、
叔向賀貧、王孫圉論楚寶、諸稽郢行成於吳、申胥諫許越成），不是《左傳》；
另一篇《鄭伯克段于鄢》是《穀梁傳》本，署左丘明只是沿误，正文与《左傳》不同。
判据是拿正文去新本里做六字窗覆盖：卷二这 12 篇覆盖率上限 **0.01**，卷一 34 篇全部 ≥ **0.11**。

## 判据

与历来的口径一致：`t2s` 归一、标点不计，正文去新本里逐段找，覆盖率过半即判为同篇。
选本是繁体、无书名号（`公曰：制，巖邑也`），新本是简体、有书名号（`公曰：「制，岩邑也`），
所以覆盖率不会到 1；TSV 里的「相似度」列是这条正文被新本覆盖的字窗占比，供复核。

**为什么这次不再两存。** 2026-10 那一轮判「两存」的理由是：`zuozhuan.json` 是 278 条按选本
篇目排的散录，两边互有出入、各有版本价值。新本是整部书，选本摘的那一段在书里逐字都在，
不再是「两份正文」——留着才是两份要同步维护的正文。

## 不动的两类

- **`汇编/课本选目/诸子论道.json` 的《子罕辭玉》**：课本选目是给小读者的小古文集子，
  选本不并进总集（《世说新语》整本进库时也没删课本选目那 10 篇，见
  [名著增补.md](名著增补.md)）。正文是《襄公十五年》「宋人或得玉」一段的前三句，没有删。
- **《古文观止·补.json》**：2026-11 重出《古文观止》时已整份删除，无遗留。
