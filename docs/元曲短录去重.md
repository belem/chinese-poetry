# 元曲「长套数里的一支另立一条」

`scripts/dedupe_yuanqu_short.py` 的说明。逐组判定见 [`元曲短录去重.tsv`](元曲短录去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_yuanqu_short.py            # 预演：逐组打印
python3 scripts/dedupe_yuanqu_short.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 现状问题

`元/元曲/yuanqu.json` 是《全元曲》与海棠诗社补录的《元曲三百首》合在一个文件里。补录把**组曲里的
一支**单独抄了一遍，另一份正文是整组：

```
#4892  吴西逸《双调・殿前欢》          270 字   六支    ← 留
#11295 吴西逸《双调·殿前欢》           91 字   两支    ← 删
```

同一支曲两份正文，勘误时两边都要改。删短的那条，**短条的题名记进长条的 `tags`** ——
「三百首选了这一支」这层信息不能跟着丢掉。

## 判据（都要）

1. 正文 `t2s` 归一、去标点后前 16 字相同（`check_tree.py` 的候选口径）；
2. 作者同一人；
3. 题名是同一支曲（`dedupe_duplicates.same_title`，另允许书题只差「并序／（并序）」）；
4. 长的 / 短的 ≥ 1.4 倍 —— 短录只录了一两支，不是另一支曲；
5. 短录**整条按序嵌在**长录里（`dedupe_yuanqu_pairs.subset_span`），且**逐字相同的字数 ≥ 70%**。

## 为什么不用「逐句覆盖率」

[`元曲长短两录.md`](元曲长短两录.md) 那一批用 `clause_coverage ≥ 0.5`，因为那里两录断句基本一致。
这一批不是：短录与长录里那一段凡有出入的地方都落在句尾（`绿水青山水墨图` / `云深不见南来羽`、
`淡烟荒草平沙` / `淡烟芳草平沙`、`玉萧` / `玉箫`），按句对齐只能靠「头 8 字」兜住，
`clause_coverage` 一律掉到 0，一条都判不出来。

逐字相同率分得开「异文」与「另一支曲」：

| 情形 | 逐字相同率 | 结果 |
| --- | --- | --- |
| `双调·卖花声` 72／144 | 0.80 | 删 |
| `南吕·四块玉·恬退` 93／122 | 0.80 | 删 |
| `中吕·醉高歌·感怀` 50／100 | 0.80 | 删 |
| `越调·天净沙·闲题` 56／112 | 0.63 | 留 |
| `双调·殿前欢` 91／270 | 0.69 | 删 |
| 《荆钗记·一封书》182／260 | 0.41 | 留 |

`天净沙闲题` 与《一封书》是**同一支曲牌下的另一支曲**，不是副本：前者长短两录各只对上对方的一段，
后者的两支是王十朋寄家书、孙汝权改休书（通篇「改…」「改介」），一出戏里的两段，都不是一篇的两份录文。
