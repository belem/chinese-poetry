# 宋词三百首：篇目口径（2026-11）

《宋词三百首》的正文并进 `宋/宋词/ci.song.*`，靠记录上的 `tags: ["宋词三百首"]` 认领。
凡是这本书里的篇目，`title` 一律按下面的口径写 —— 这是 issue #200 问的那件事，也是
[`宋词三百首勘正.tsv`](宋词三百首勘正.tsv) 里 108 条「改题」的落地方式。

## 口径

| 底本 | `title` | 例 |
| --- | --- | --- |
| `词牌·小题` | `词牌·小题` | `宴山亭·北行见杏花`、`念奴娇·赤壁怀古` |
| 只有 `词牌` | `词牌·正文首句`（前 12 个汉字，去标点） | `浣溪沙·一曲新词酒一杯去年天气旧` |

一条硬规矩：**小题本身已经是这一首的标识，不再叠加首句。**
`燕山亭·北行見杏花` 写作 `宴山亭·北行见杏花`，不是 `宴山亭·北行见杏花·裁剪冰绡…`。

词牌用**本库**的写法，不为一字之差改名：底本的「木蘭花」在库里是《玉楼春》、
「玉蝴蝶」库里作《玉胡蝶》、《六么令》作《六幺令》、《鎖窗寒》作《琐窗寒》，
正文同首、调名同实，硬改只会把同一调拆成两半。底本的写法留在 tsv 的「底本标题」列里备查。
只有一处动 `rhythmic`：`ci.song.22000.json#1054`「老薄幸」是「吕滨老／薄幸」断错行，
作者写成「吕滨」、词牌被切掉半截，改回「薄幸」。

简繁跟**本记录正文**走，不按文件判：`ci.song.23000.json` 两条正文一简一繁，
作者字段又都写简体，只能逐条看正文字形。

## 作者

只改库内署名本身的错，`authors/` 一个字不动：

- `吕滨` → `吕渭老`（断行）、`鲁逸仲` → `孔夷`（别号）
- **不改**的：《生查子》（欧阳修／张先）、《蝶恋花》（晏殊／冯延巳）、《鹧鸪天》（秦观／无名氏）、
  《蝶恋花》（赵令畤／晏几道）、《汉宫春》（李邴／晁冲之）——《全宋词》两收，归属异说，两存；
  `陆睿`／`陆叡` 是异体一对，`authors.json` 里没有「陸叡」，不动。

## 脚本

`scripts/anthology/songci300_titles.py`：读底本 `reference/宋詞三百首` 与
[`宋词三百首勘正.tsv`](宋词三百首勘正.tsv) 的「库位置」列，逐条改 `title` / `author`，
写回走 `scripts/anthology/patch_json.py`（只替换那个字段，不重排文件）。

```bash
python3 scripts/anthology/songci300_titles.py --verbose           # 预演
python3 scripts/anthology/songci300_titles.py --apply --date 2026-11-03 --reviewer <名字>
```

这个脚本取代了 2026-11 的 `retitle_songci300.py`（上一轮一律「词牌·正文首句」，
把小题全丢了；那一版的首句还是从库内正文取的，与逐字校过的底本对不上）。
`retitle_songci300.py` 保留原样，只作历史记录，不再运行。
