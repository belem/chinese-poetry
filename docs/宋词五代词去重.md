# 《全宋词》里的五代十国词

`scripts/dedupe_songci_huajian.py` 的说明。逐条判定见 [`宋词五代词去重.tsv`](宋词五代词去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_songci_huajian.py                      # 预演
python3 scripts/dedupe_songci_huajian.py --apply --date YYYY-MM-DD
```

## 现状问题

`宋/宋词/ci.song.22000.json` 是后补的一批《全宋词》录文，把《花间集》《南唐二主词》里
五代十国的词也收了进来：李煜、李璟、牛峤、毛文锡、顾夐、孙光宪、魏承班、牛希济。
这些人的词在 `五代十国/词/五代诗词/` 有专书。`merge_anthologies.py` 2026-10 只清过 `poet.tang`，
没碰 `ci.song.*`，于是李煜的《相见欢》在两边各有一份。

## 判据

- 正文 `t2s` 去标点后前 16 字相同；
- 作者同一人：署名一致（`顾夐/顾敻` 是同一人的两种写法，收在脚本 `ALIAS` 里），
  或《全宋词》那条把五代词人署成了「无名氏」；
- 正文相似度 ≥ 0.90 —— 差的是 `孤/辜`、`荭/葓`、`渌/绿`、`帏/帷` 这类用字。

满足就删 `ci.song.*` 那条，留 `五代十国/词/五代诗词/` 的专书（有卷次、有词牌、有词人编次）。

## 本轮：23 条里删 19 条

删的 19 条全是 `ci.song.22000.json` 里的李煜、李璟、牛峤、毛文锡、顾夐、孙光宪、魏承班、牛希济。

**作者不同的 4 条一条不删**——这是这一批最要紧的一条：

| 全宋词 | 五代专书 | 相似度 |
| --- | --- | --- |
| `ci.song.1000.json` 苏轼《浣溪沙》 | 李煜《浣溪沙·风压轻云贴水飞》 | 0.95 |
| `ci.song.3000.json` 邓肃《长相思令》 | 李煜《长相思·一重山》 | 0.94 |
| `ci.song.20000.json` 无名氏《捣练子》 | 李煜《捣练子·云鬓乱》 | 0.89 |
| `ci.song.22000.json` 顾夐《诉衷情》（70 字） | 顾敻《诉衷情·香灭帘垂春漏永》（33 字） | 0.64 |

前三条是《全宋词》自己的归属（苏轼、邓肃名下确有此词的异说），第四条是同一词牌的**另一首**
（70 字对 33 字），都不是重复。

## 结果

`ci.song.22000.json` 1173 → 1154 条。正文一字未动。
