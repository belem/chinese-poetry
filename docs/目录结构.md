# 目录结构

这份文件回答一个问题：**一首诗应该放在哪个目录，为什么。**

## 一、现在为什么乱

顶层 25 个语料目录，各按一套逻辑切：

| 切法 | 目录 |
| --- | --- |
| 按总集 | `全唐诗` `宋词` `元曲` `历代` `昭明文选` `古文观止` `楚辞` `诗经` `乐府诗集` |
| 按选本 | `唐诗三百首` `宋词三百首` `古诗源` `课外经典` `蒙学` |
| 按作者 | `曹操诗集` `纳兰性德` |
| 按朝代 | `五代诗词` `近现代诗` |
| 按数据源 | `reference` `strains` `rank` |

五种维度混在一层，怎么排序都是乱的。更具体的代价：

- **`全唐诗/` 里装的不是唐诗（历史问题，已修）。** 当时这个目录 319 个 JSON，`poet.tang.*` 是《全唐诗》，`poet.song.*` 是《全宋诗》——后者 254503 首，是前者的 4.4 倍，按目录名取数据就会取错。宋诗现已拆到 `宋/诗/全宋诗/`。
- **唐诗只剩一套并行。** `唐/诗/全唐诗/poet.tang.*`、`汇编/蒙学/tangshisanbaishou.json`（2026-10 已并入前者作 tags）。`水墨唐诗/` 已整目录并入 `唐/诗/全唐诗/poet.tang.*` 作标签（目录删除），`唐诗三百首/` 也已并作标签，`汇编/蒙学/tangshisanbaishou.json` 那套 2026-10 也并了（见 `docs/唐诗去重.tsv`、`docs/选本并入.tsv`、`docs/唐诗三百首并入.tsv`）。
- **选本在大合集里的副本会被改两遍。** 同一首诗的正文，选本一份、总集一份，勘误时两边都要改，改漏就漂。
- **朝代对不上不是数据错，是根本没有这一维。** `poet.song.*` 有 254503 首，`authors/authors.json` 只覆盖 2402 位作者，19 万首连作者索引都没有——判断不了朝代。这一维 2026-10 补上了：顶层按 14 个朝代目录切，《全宋诗》整部留在 `宋/`，不必逐首判断。

## 二、四条原则

**1. 目录按「一部书」切，不按体裁也不按朝代。**

`全唐诗` 不是「唐代的诗」，它是清康熙四十四年彭定求等十人奉敕编的一部书。`全宋诗` 也不是「宋代的诗」，是北京大学 1990 年代编的另一部书。既然一部书就是一个底本、一套编次，目录就该照书切。

**2. 朝代是目录的第一层，作者朝代决定归属。**（2026-10 修订）

原先这一条写的是「朝代是每条记录的属性，不是目录」，理由是跨朝代的作者没地方放。实践下来反过来了：
用户要的是「唐诗在哪」这种一眼可答的问题，而 `ls` 拿不到答案；至于跨代作者，按**作者自己的朝代**归一个目录
就好，李煜归 `五代十国`（他是南唐人），李祁的《郎官湖春日》虽收在《全宋诗》里、作者却是元人，仍留在
`宋/诗/全宋诗/` 不动——书是按书收的，人到哪个朝代由 `authors/authors.json` 说话。

于是：**顶层是 14 个朝代目录，第二层才按「一部书」切。** 总集不拆，跨代的总集（乐府、文选、古诗源）
归它取材的主要时段。

**3. 选本不占目录，占标签。**

唐诗三百首、宋词三百首、水墨唐诗、千家诗、课本选目，都是 200~300 首的精选视图，正文与总集重复。它们的正确定位是总集记录上的 `tags`，加上 `anthologies/` 里那份目次（已有，见 `docs/选本对齐.md`）。目录里留副本，等于同一首作品存两份正文，互相漂。

**4. 一个字段一个值空间。**

朝代字段统一成中文朝代名，与 `dynasties/dynasties.json` 的 `name`、顶层目录名对齐。`元/元曲/yuanqu.json` 里
原来 11415 条存的是 `"yuan"`，`历代/other.0.json` 也存 `"yuan"`，2026-10 一并改成 `"元"`；作者表里的
`周`/`秦`/`商`/`上古` 归 `先秦`，`辽`/`金` 归 `宋`，`当代` 改作 `当`，与目录同名。

### 不合并的理由

`昭明文选`、`古文观止`、`乐府诗集`、`古诗源`、`诗经`、`楚辞`、`花间集`、`南唐二主词`、`历代`——这九部书各自有底本、有编次，合进大总集会丢掉「这本书收了哪些」这层信息。**书与书之间不是重复关系，是「同一首作品被多本书收录」的关系**，后者用 `sources` 表达（已有此字段），不用删文件。

跨目录实测重复：`乐府诗集` 与 `全唐诗` 重 6 首，`古诗源` 与 `全唐诗`、`宋词` 重 2 首，合计 8 处（同作者同正文）。这 8 处的处理是删掉选本里那一份、不合并书：编次信息保留在 `anthologies/` 的目次与记录上的 `tags`/`sources` 里，正文只留一份。

### 该拆的理由

`近现/` 的 41 首里，33 首不是近现代作品：《江南》（漢樂府）、《畫雞》（唐寅）、《村居》（高鼎）、《所見》（袁枚）、《墨梅》（王冕）、《潼關》（譚嗣同）、《別雲間》（夏完淳）、《滿江紅・小住京華》（秋瑾）……它们进这个目录，是因为「课本里有」，不是因为「年代是近现代」。真正近现代的只有 8 首（毛泽东、鲁迅、艾青、余光中、夏明翰……）。目录名与内容不符，就是「朝代对应不上」的一种。

## 五、字段现状

同一个 `paragraphs` 键下，各路数据各有各的附加字段：

| 目录 | 常见字段 | 特殊字段 |
| --- | --- | --- |
| `唐/诗/全唐诗/poet.tang.*` | author, paragraphs, title, id | `tags` 4006、`sources` 649、`prologue` 148 |
| `全宋诗/poet.song.*` | author, paragraphs, title, id | `tags` 6905、`sources` 261 |
| `宋词/ci.song.*` | author, paragraphs, rhythmic | `tags` 931、`sources` 1000 |
| `元曲/` | author, paragraphs, title, dynasty | — |
| `历代/` | author, paragraphs, title | `sources`、`rhythmic`、`dynasty` 16 |
| `五代诗词/` | author, paragraphs, rhythmic, title | `notes` |
| `诗经/` `楚辞/` | content（不是 paragraphs）, section, chapter | — |
| `论语/` `孟子/` `大学/` `中庸/` | paragraphs, chapter | 无 author |
| `幽梦影/` | content, comment | 无 author、无 title |
| `纳兰性德/`（现 `清/*/纳兰*/`） | para（不是 paragraphs） | — |
| `曹操诗集/` | paragraphs, title | 无 author（作者即目录名） |

`content` / `para` / `paragraphs` 是同一个东西的三种写法，`author` 有时在记录里、有时在目录名里。使用方每接一个目录就要写一次特判——`loader/data_loader.py` 里那句「四书五经的其他文件不符合两层结构, 以后再想办法处理吧」就是这个代价。

**统一后的记录契约**（每条作品）：

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `title` | 是 | 题名 |
| `author` | 是 | 作者；无名者用「无名氏」 |
| `dynasty` | 是 | 中文朝代名，对齐 `dynasties/dynasties.json` |
| `paragraphs` | 是 | 正文，一句一行 |
| `rhythmic` | 词曲必填 | 词牌 / 曲牌 |
| `tags` | 否 | 选本、课本、题材标签 |
| `sources` | 否 | 还见于哪些书 |
| `prologue` | 否 | 赏析、题解 |
| `id` | 否 | 稳定标识，去重与引用用 |

`content`、`para` 合并进 `paragraphs`，`chapter`/`section` 保留（诗经、楚辞、论语的分卷信息）。
