# 《全唐诗》里的空记录

`scripts/dedupe_empty_rec.py` 的说明。明细见 [`全唐诗空记录.tsv`](全唐诗空记录.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_empty_rec.py            # 预演：列出全部空记录
python3 scripts/dedupe_empty_rec.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

`poet.tang.50000.json`–`poet.tang.57000.json` 是《全唐诗补逸》《全唐诗续补遗》一路爬下来的
敦煌残卷与逸句。其中 182 条正文只剩一个句号：

```json
{"author": "崔湜", "paragraphs": ["。"], "title": "", "id": "dkl841"}
```

`paragraphs: ["。"]` 是底本卷次里只有作者名、诗题与正文都没爬下来的位置。留着它，
下游按「条」取数据就会拿到一首空诗 —— 比缺一条更糟。删。

## 判据

`''.join(paragraphs)` 去掉标点后为空，且 `notes` 里没有可还原的正文字句。

182 条里 172 条题名也是空的（连篇题都没有），10 条有题无文
（`塞上聽彈胡笳作（幷序）`、`挽歌五首`、`五位君臣頌` 这类）。后者的正文在《全唐诗》别本里，
本批**不补**（补录是另一件事，要查底本），只删空壳。

## 结果

| 指标 | 清理前 | 清理后 |
| --- | --- | --- |
| 正文只有「。」的记录 | 182 | 0 |
| 《全唐诗》总条数 | 55873 | 55691 |
| `check_structure.py` missing_char | 5953 | 5953 |
| `check_structure.py` shi_line_length | 151 | 151 |

删的都是整条记录，正文一个字没动 —— 本来也就没有正文。
