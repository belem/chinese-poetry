# 元曲「同一支曲长短两录」

`scripts/dedupe_yuanqu_pairs.py` 的说明。逐组判定见 [`元曲长短两录.tsv`](元曲长短两录.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_yuanqu_pairs.py                      # 预演
python3 scripts/dedupe_yuanqu_pairs.py --apply --date YYYY-MM-DD
```

## 现状问题

`元/元曲/yuanqu.json`（《全元曲》＋海棠诗社补录的《元曲三百首》，同文件）里同一支曲被录了两遍：

```
双调・水仙子夜雨   485 字   八支合成一条
双调·水仙子·夜雨    48 字   只录其中一支
```

两录题名只差间隔号写法（`・` 与 `·`）与书题断法。`scripts/dedupe_duplicates.py` 的
`yuanqu_cover()` 只认「一是另一的前缀」，短的若从长句**中间**开始就判不了；2026-10-29
清完「前缀」那 25 组之后，这一批还剩 38 组。

## 判据（四条都要）

1. 题名是同一支曲（沿用 `same_title()`：曲牌 + 书题，`・`/`·` 视为同一）；
2. 作者同一人（`王德信/王实甫`、`真真/真氏` 这类别名收在脚本 `ALIAS` 里）；
3. 短的那条每一句都能在长的里找到近似的那一句（按序，允许一字之差）——
   「叹新丰**逆旅淹留**」对「叹新丰**孤馆人留**」，「渭河」对「渭水」，长的《白鹤子》还夹着「之一」「之二」；
4. 短的那条**句子**里至少一半能在长的里逐句对上（`clause_coverage ≥ 0.5`）。

第 4 条是这一版新加的：第 3 条退到「只比这一句的头 8 个字」之后，凑巧起头相同的**另一支曲**
也会被放过去 ——《荆钗记·一封书》两支（182 / 260 字）同曲牌、同出，一支是王十朋寄家书、
一支是孙汝权改休书，后者通篇「改…」「改介」，不是同一支曲的两份录文。
