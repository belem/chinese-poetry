# 《昭明文选》重建

## 问题

`汇编/昭明文选/` 现有 89 个体类文件、443 条，是爬来的白文（无注、不分段、句读参差）：

- 空格：行内夹半角空格、`　`（如 `祖太祖高皇帝　父世祖武皇帝`）
- 分段：一句一段（《養生論》53 段）、或把几十句挤成一段（《文選序》整篇一段）
- 注文混入正文：李善注、五臣注的句子被当成正文（《養生論》「豚魚無血，食之皆不利人也」
  「淮南子曰：豫章之生，七年可知……𣏞音尤」都是注文）
- 讹字：`或雲`（云）、`以儘性命`（尽）、`知一理之害生`（一過）之类
- 篇目不全、次序不对：只有 443 条，而《文選》六十卷实收 480 篇；文件按体类名排，不按原書卷次

## 底本

**《昭明文選》六臣注本**，四部叢刊集部、上海涵芬樓藏宋刊本（識典古籍 `SBCK300`，共 60 卷）。

选它的理由：六十卷足本、有完整目录（卷次／体类／篇题／首数俱全）、有原文影印可回查。
李善注单注本（`CADAL01029084`）、汲古閣本（`NGJ892411999029275221709`）可作旁校，明清选本（《八代文鈔》等）不取。

抓取：`node scripts/anthology/crawl_book.mjs` 走不通（该站目录是虚拟列表），实际用页面
`window._ROUTER_DATA` 里的 SSR 数据按章取 `paragraphList`，一章一文件缓存在工作目录，
再按目录树合成。脚本尚未入库（一次性抓取，产物即数据），抓取要点记在这里备查：

- 书籍页目录只渲染可视区 13 条，需在 `.semi-tree-option-list` 上逐步滚动才能拿全 63 章
- 章节页 DOM 里的 `<p>` 是**合并过注文**的白文，正文与注文只能靠原文数据区分：
  SSR 的 `paragraphList[i].content`（JSON 字符串）里 `lines` 才是排版单位
- 六臣本一行 = 正文 + 注文，注文以 `善曰：`「翰曰：」「向曰：」「銑曰：」「濟曰：」「良曰：」「綜曰：」
  「劉曰：」「逸曰：」「爰曰：」起头，切到第一个标记即为白文。夹在正文里的
  `五臣作某字`「善本作某字」是校记，也要去
- **`?__ssrDirect=true` 那条路 2026-11 已失效**（只回 `{"isSpider":false}`）；改成先开一个
  章节页（如 `/zh/book/SBCK300/chapter/1j73qvhqyyz39_1`）等 6 秒，再在页面里读
  `window._ROUTER_DATA.loaderData['__session/(lang$)/book/$']`——目录在该键的
  `catalog.chapters`（63 章，含 `chartId`／`page`／`volumeId`），正文则逐章
  `page.goto('/zh/book/SBCK300/chapter/<chapterId>')` 后取同一键的 `paragraphList`。
  一次 goto 只拿一章，卷四十六这样 6 章、卷四十八至五十这样 20 章都很快
- **SSR 会整段错接**：卷四十六《王文憲集序》正文在「脫落塵俗」后接上《三國名臣序贊》的文字，
  并整段丢底本第 156 行。抽完务必与底本核「段数 + 字数」，对不上就退回底本白文

## 工具

- `scripts/anthology/zhaoming_sd.py`：识典 SSR 一章的白文抽取。一行 = 正文 + 注文
  （`lineType` 1 正文、2 注文/校记、3 空行、8/9 篇题），正文与注文在一段里交错排，
  所以按「注文块」切：连续类型 2 之后不再有类型 1，则该块起即本段注文，此后整段丢弃。
  缓存目录由 `$ZHAOMING_SD` 指定（默认 `/tmp/zhaoming-sd`），一节一文件。
- `scripts/anthology/zhaoming_variant.py`：旧刻字形（髙/曺/寳/𤣥/黙/逹/瓌…）归一到本库的标准字形。
  只归一异体，不改异文。
- `scripts/anthology/zhaoming_gen47.py`：卷四十七七篇的篇目表（识典章节 id + 正文页区间 + 依底本补的脱字），
  直接生成 `汇编/昭明文选/颂.json`、`赞.json`。

底本 `reference/昭明文選4.txt` 是简体排印的李善注本，一面一行（正文 + 注文同一行），
只用来定段落边界与核字；正文取六臣本，底本讹字与六臣本脱字互校。

## 口径

1. **只收白文**。本库是语料库，不收注；原書的注文一律切掉。
2. **篇题照《文選》目录**：作者 + 篇题（`嵇叔夜 養生論`）。目录里的「一首」「二首」是计数，不进篇题；
   诗题下的小字（「五言」「并序」）不是篇题。
3. **段落照原書**：一段 = 底本的一个自然段（赋、论、书、序的段落界线很清楚），不再一句一段。
4. **句读用。和，**：段内长句照底本的句读加标点，能用「，」的地方不乱断成段。
5. **次序照目录**：六十卷、卷下体类、体类下篇题的顺序，即 `docs/昭明文选目录.tsv`。
   `tags` 记体类路径（如 `昭明文選/賦/京都上`），供按体类检索。
6. 底本有异文的，以六臣本为准，不作「据通行本改」；底本明显讹字（形近、音近）照改，
   改不动的记 `needs_review`。

## 自建底本还是借用现库

重出全書 480 篇需要对勘 60 卷约 70 万字，逐卷做。做法：

1. 用六臣本定位每一篇（目录 → 章 → 文），核清「库里缺哪些、多了哪些」；
2. 缺的篇目从六臣本补；已有的篇目**逐句对勘**，改字、清空格、分段；
3. 每卷一个 PR，按卷次推。

六臣本抓取是临时的（见上），产物不进仓库：只提交对勘后的白文。

## 底本分册与正文接口

**底本按卷拆成四册**，`reference/昭明文選{1,2,3,4}.txt` 是同一部簡體排印李善注本：

| 冊 | 卷 |
|----|----|
| 1 | 1~16 |
| 2 | 17~27 |
| 3 | 28~43 |
| 4 | 44~60 |

跨冊界限在**卷四三/卷四四之間**（卷四三是 3 冊末、卷四四是 4 冊首）。`zhaoming_ref.py`
原先寫死讀 4 冊，只覆蓋卷四四至六十；現已按卷號選冊（`ref_path(v)`），60 卷都能切。
兩個坑：`_cn2int` 對「卷十」這種純「十」會 `ValueError`（`nums` 為空時要先判十）；
`昭明文選1.txt` 開頭是**全書總目錄**，目錄行與正文卷頭同形（`卷三七 表上`），
要取「每個卷號最後一處卷頭」當正文起點，冊尾無正文的目錄殘行也要丟掉。

**識典正文接口**（`paragraphs/v3`，POST，須在同一章節頁內調用才有簽名）：

```json
{"bookId":"SBCK300","chapterId":"<章節 id>","paragraphId":"",
 "pagination":{"pageSize":100,"currentPage":0},"forwardParaNum":10,
 "needCheckVersion":false,"isWebpSupported":true,"charPicResizeWidth":40,
 "charPicQvalue":75,"figureResizeWidth":750,"figureQvalue":75,
 "translateLanguage":0,"omitContent":false,"omitTranslate":false,
 "needPinYin":true,"requestMode":0,"bookVersion":0,"preloadType":0}
```

章節 id 從書籍頁目錄取（`.semi-tree-option-list` 滾動後 `a[href*="/chapter/"]`，共 63 條，
卷三七至四四對應索引 39~46）。DOM 那條路（`article.chapter-reader`）在本站是虛擬滾動，
未進入視口的段會從 DOM 卸掉，所以只抓首屏；接口的 `totalParaNum` 才是這一章真正能拿到的段數。

## 卷一九至二九的对勘口径

這四卷的情賦與詩白文取自識典六臣注本（`SBCK300`），做法與卷五一至六十不同：這裡六臣本整卷可取，
不做「底本定段」，而是**六臣本自己定段**。

- **抓取**：卷一九、二三、二八、二九的章目在 `bookInfo.catalog.chapters[].subChapters`（lv2），
  共 72 章（含 `詩甲` `樂府下` `挽歌` `雜歌` `雜詩上` 等体类章与「詠懷」「樂府十七首」这类被切开的
  篇目章）。逐章 `page.goto('/zh/book/SBCK300/chapter/<chapterId>')` 后调页面自己的
  `POST /api/ancientlib/read/book/paragraphs/v3/`，一章一文件。这四卷的 `totalParaNum` 与章目
  `paragraphCount` 一致（卷二三 `詠懷` 4→21、`詠懷詩十七首` 3→20，章目只记卷首段数），
  所以「接口只回卷首」在这里不成立，四卷 72 章正文全拿到（25913 字）。
- **一行 = 原書一面**：識典一段 = 原書一行，正文在前、注文在後，`lineType` 1 正文 / 2 注文与校记 /
  3 空行 / 8、9 篇题。切白文：行內遇到「，某曰：」按「注文只接在正文斷句之後」判——
  `X` 是注家或书名（`善曰`「翰曰」「漢書曰」）即截断；`X` 是一两个字的说话人（`玉曰`「王曰」）保留；
  `X` 四字以上一律是正文（`太宗文皇帝曰`）。音注（`慈聿。`「仕咸。」）与行内校记（`(五臣作某)`）删掉而不断段。
- **段**：行末未斷句（下一行接着写）的并成一段，段末是「。」「？」「！」「；」的断开。
  篇末页脚（`六臣註文選卷第二十九。`）与卷头（`六臣註文選卷第二十三`）不是正文，删。
- **字**：六臣本整体用繁体，但录入时夹着简体（`为`「远」「众」「强」「东」「时」），旧刻异体
  （`髙`「𤣥」「逺」「衆」「絶」）也多；这批一律写成标准繁體（`為`「遠」「眾」「強」「東」「時」、
  `高`「玄」「远」→`遠`）。只做同字异写归一，不动异文；`于`「云」「征」「里」「后」这类本库本来就
  用这个字形的，不做简繁（`范蠡` 的范也不是「範」）。
- **篇题**：照 `docs/昭明文选目录.tsv`。`詠懷詩十七首` 等「首」数是《文選》目录里的计数，不進篇题；
  `雜詩` 十几篇同题，靠作者与卷次区分。旧库的别名写法（`銅雀臺` / `範僕射`）随重出改回目录的写法。

这四卷之外，卷二〇至二二、二四至二七、三〇、三一时六臣本的 `totalParaNum` 只有 3～8，
与卷三七至四四一样是「站上只给卷首」；要做那九卷得另找有完整白文的底本，不能拿现在这份
「一行一面」的排印本硬切（切完只剩四分之一到十分之一的字数）。

## 卷五一至六十的对勘口径

這十卷每章几十頁，《文選》在識典上又被切成一篇文章一章（長卷的後續章節沒有卷頭），
所以按「底本定段、六臣本定字句」對勘，工具鏈是 `scripts/anthology/` 下這幾個模組：

| 模組 | 作用 |
|------|------|
| `zhaoming_ref.py` | 底本 `reference/昭明文選4.txt` 按「卷五三」這樣的卷頭切卷，再按篇題切篇；一行一面，`strip_note` 切掉注文 |
| `zhaoming_seg.py` | 識典一章的 DOM 塊（h2/h3/h4/p）→ 自然段；一章一文件緩存在 `$ZHAOMING_SD`，`order.json` 記抓取順序 |
| `zhaoming_build2.py` | 逐篇把底本段與六臣本段拼串對齊，返回「六臣本段 + 底本該段白文 + 以誰為準」 |
| `zhaoming_gen50.py` | 按 `SPEC` 表寫回 `汇编/昭明文选/*.json` |

抓取要點（這次踩過的坑，留給下一次）：

- 長卷（論一、論三、誄上、碑文上、碑文下、行狀）在站上是一篇一章，後續章節**沒有卷頭**，
  必須從卷首那一章起順著 `article footer a`（下一篇）逐章抓，用抓取順序推斷卷號；
- 章末頁腳是「六臣注文選卷第五十七」這樣一行 h4/p，別當成篇題；
- 章節頁要設 `userAgent`（默認的 headless UA 會被判成爬蟲，只回「數據異常」）；
- `paragraphList`（SSR）在長卷只給前十幾頁、且正文注文交錯，**不要用**；DOM 的
  `article.chapter-reader` 一行一段，`innerText` 已是白文；
- 卷三七至四四取不到正文，**先看接口返回的 `totalParaNum`**（不是分頁沒翻完）：正文接口是
  `POST /api/ancientlib/read/book/paragraphs/v3/`，body 見下「底本分冊與正文接口」。
  `totalParaNum` 若是 6~14，就是站上只給了卷首粗校；`book/pages/v3` 那一份只回影印圖
  `picUrl`，沒有文字層。翻頁（`pagination.currentPage`）、1600×1200 視窗、`networkidle`、
  滾輪、`scrollIntoView` + MutationObserver、`article.chapter-reader` 自身 `scrollTop` 都試過，
  最大也只到 `totalParaNum`，所以判「未開放」而不是「沒抓全」；

定字：

- 段以**六臣本的自然段**為準（底本「一行一面」，注文切不乾淨時一面只剩半句，不能定段）；
- 底本某段白文比六臣本同一段短一大截（正文被注文連帶切掉）時改用底本那一段，
  如《四子講德論》「文學曰：陳懇誠於本朝之上」幾句；
- 字形：本庫《昭明文選》其餘文件都用繁體（`賦者古詩之流也`、`與君生別離`），這批照舊用繁體，
  只把舊刻異體寫成標準字形（丗→世、髙→高、𤣥→玄、漑→溉），`zhaoming_variant.py` 裡這批新增的
  對照是對勘時逐字核出來的，不涉異文；
- 六臣本與底本字句不同、又都講得通的，兩存不改，留給 `needs_review`。
