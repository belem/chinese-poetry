# `先秦/文/` 子史单行本与《古文观止》《课本选目》的同篇

`scripts/dedupe_xianqin_wen_gu.py` 的说明。逐条判定见 [`先秦文古文观止去重.tsv`](先秦文古文观止去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_xianqin_wen_gu.py            # 预演
python3 scripts/dedupe_xianqin_wen_gu.py --apply --date YYYY-MM-DD
```

## 现状问题

`汇编/古文观止/` 的周文、战国文各卷，本来就是从《左传》《国语》《公羊传》《穀梁传》
《礼记》《战国策》《庄子》这些书里摘出来的；`汇编/课本选目/` 也一样。这些书在
`先秦/文/` 下各有一份单行本（`zuozhuan.json` 278 条、`guoyu.json` 12 条、`liji.json`、
`zhuangzi.json`……），同一篇两边各存一份正文，勘误时要改两遍，改漏就漂。

```
先秦/文/guoyu.json#940h8d      左丘明《申胥谏许越成》  282 字   ← 留
汇编/古文观止/卷三周文.json     左丘明《申胥諫許越成》  282 字   ← 删
```

## 口径：留整部书，删选本摘录

与 [`汇编与诗去重`](汇编与诗去重.md) 相反（那里删补录、留选本），与
[`左传古文观止去重`](左传古文观止去重.md) 一致：`先秦/文/` 是整部书，有卷次、有编次；
《古文观止》这一篇只是从书里摘出的同一段。按「一件作品只留一份正文」，留书、删摘录。

选本目录要记的是「《古文观止》收了哪几篇」，所以删下去的篇目在
[`汇编/古文观止/古文观止·选目.json`](../汇编/古文观止/古文观止·选目.json) 里留着目次
（卷次、篇题、作者、对应的单行本记录 id，`书` 字段记是哪一部）。

## 判据（三条都要）

1. **题名对得上**：`t2s` 归一后相等，或单行本的题名是「书名·篇名」而选本取篇名
   （`檀弓·公子重耳对秦客` 对 `公子重耳對秦客`）；
2. **作者同一人，或选本署「佚名」**（《古文观止》卷三把《国语》《礼记》的篇都署了佚名）；
3. **正文归一后一字不差，且选本不比单行本长**。

归一表只收「一个字两种写法」的通用字：`於/于`、`毋/无`、`蒉/篑`、`忘/亡`、`脩/修`、`彊/强`、
`舍/捨`、`说/悦`、`反/返`、`队/坠`。`余/馀`、`知/智`、`共/供`、`陈/阵` 这类文白两读**不收**——
第一版收了 `余/馀`，把《公羊传·吴子使札来聘》三处 `余/馀` 当通用字，差点删掉一篇真异文；
《左传·齐国佐不辱命》也栽在同一个字上。宁可放过，不可错删。

## 本轮结果

| 判定 | 数 | 处理 |
| --- | --- | --- |
| 删选本那一条 | 8 | 归一后一字不差，留整部书 |
| 两存·正文有出入 | 22 | 异文（`椁/惇`、`蓺/艺`、`麋/上鹿下夭`……）或选本多了纪年文字与夹注 |
| 作者不同 | 2 | 不动 |
| 题名对不上 | 2 | 不动 |

删掉的 8 条：申胥諫許越成（国语）、公子重耳對秦客与晉獻公殺世子申生（礼记·檀弓）、
對楚王問（宋玉）、季札觀周樂／寺人披見文公／鄭子家告趙宣子／齊桓下拜受胙（左传）。
这四个文件 16/11/22/17 条 → 14/9/19/16 条，正文一字未改。

## 与上一轮「左传」那批的关系

[`左传古文观止去重`](左传古文观止去重.md) 上一轮删了 7 条、留了 7 条「只差异文」的两存。
这一轮把《国语》《礼记》《公羊传》《宋玉》几部也纳入同一判据重跑，结论一致：
《左传》那 7 组仍然两存（`寘/置`、`殽/崤`、`剪/翦`、`焞/炖`、`馀/余` 都是两读并传），
新增的只有另外 4 部书上的 8 条。
