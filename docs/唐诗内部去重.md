# 《全唐诗》内部去重

`scripts/dedupe_tang.py` 的说明。逐条判定见 [`唐诗内部去重.tsv`](唐诗内部去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_tang.py            # 预演：分类、样例与条数
python3 scripts/dedupe_tang.py --apply    # 写回数据，并生成 docs/唐诗内部去重.tsv
```

## 判重口径

正文简繁归一（`t2s`）、去掉一切非汉字字符，**前 16 字相同**即算同一首。与
[`scripts/check_tree.py`](重复体检.md) 同一口径：半首之后有出入的同一首也算重复。
差别在于按组处理——一组两条只删一条，一组三条删两条，而不是见到就删。

`唐/诗/全唐诗/` 里这样的组 2034 个、多余 2120 条，性质完全不同：

| 判定 | 组 | 多余条 | 处理 |
| --- | --- | --- | --- |
| 同作者重出 | 1252 | 1274 | 删信息少的那条 |
| 归属异说 | 782 | 814 | 两条都留，互挂 `tags` |
| 正文有出入的异文 | — | 32 | 两存，不动 |

### 一、同作者重出（删 1274 条）

作者同一人——含同一人的两种署名（僧貫休／貫休、東方虬／東方虯、李舒／李紓、
郭元振／郭震、楊希道／楊師道，见脚本 `ALIAS`）——正文前 16 字相同，就是同诗重出。

绝大多数是《全唐诗》按「乐府 / 非乐府」两套目录各排一遍造成的：

```
poet.tang.9000.json#491  韋應物《三臺二首 一》      ← 留
poet.tang.1000.json#875  韋應物《雜曲歌辭 三臺二首 一》  ← 删
poet.tang.49000.json#106 韋應物《三臺 一》           ← 删
```

保留哪条按**信息量**打分：`tags` 每条 2 分、`prologue` 10 分、正文长度（每千字 1 分）、
不在体类卷里（郊廟歌辭……）1 分。所以带杜甫集注、带选本标签、正文更全的那条留下来。

正文相似度低于 0.9 又不在 `SAME` 表里的，当**异文**两存（32 条）：《全唐诗》里
「一作某」与正文并存的地方不少，两读皆有依据的不在这一轮的范围里。逐条列在 TSV 的
「保留（异文）」行。题名不同但确系一首的（《三臺》与《三臺二首 一》这类），写进脚本的
`SAME` 表，附判据。

### 二、归属异说（814 条，一条不删）

作者不同、又都不是体类卷题名的：太宗／董思恭《詠弓》、明皇帝／梁鍠《傀儡吟》、
韋承慶／崔道融《南行別弟》、李嶠／張喬《中秋月》……这是唐宋笔记里就有的归属异说，
《全唐诗》自己用「一作某」处理。所以两条都留，在对方 `tags` 里挂一条互见：

```json
{"author": "太宗皇帝", "title": "詠弓", "tags": ["董思恭《詠弓》"], …}
```

2026-10 起互见挂 `tags` 不挂 `sources`：`sources` 的意思一直是「这条正文还见于哪部书」
（与 `tags: ["唐诗三百首"]` 这种归属标记同义），「一作某人《某题》」是校记，不是来源。
脚本上一版写进 `sources` 的 1598 条已在同一轮里改挂 `tags`，重跑时脚本会自动归位。

### 三、编排重出（一组不动）

《全唐诗》是两套编次：900 卷按体类排（郊廟歌辭、樂府、雜曲歌辭……），2200 人按作者排。
同一首同时出现在两处，是这部书的样子；《全唐詩》另一份录文也是这个排法。删了反而失真。

判据：一组里的记录全是体类卷题名（题名以体类名开头，且不带「（一作…）」），
则视为编排重出，整组保留。本轮没有整组都属于这类的情况（多数与作者名下那条混在一组，
那一条归「同作者重出」处理）；规则留在脚本的 `ROLL` / `has_aka` 里。

## 与上游的关系

同一首歌辞被拆成两条 `id`，在 chinese-poetry 上游就是这么存的——本轮不改 `id`，
只删重复的记录。`poet.tang.58000.json` 是 海棠诗社的语料补入的那一批里判重跳过的残余
（每条都带 `"sources": ["haitangshishe"]`，336 条中 331 条与库中已有记录重出），
与作者名下那一条重出的按「同作者重出」删掉；正文有出入的留着。

2026-10-30 这批残余已清理完：删 331 条重复副本，文件 336 → 5 条，`"sources": ["haitangshishe"]`
一处不剩；副本上的 `唐诗三百首` 与「某人《某题》」互见逐条并回本体的 `tags`。
留下的 5 条正文库中无二本：《除夜有怀》（崔涂）、《相和歌辞·饮马长城窟行》（李世民）、
《战城南》（李白）、《焚书坑》（章碣）、《征妇怨》（孟郊）。
