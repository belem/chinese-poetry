`scripts/dedupe_taoanzhmyi.py` 的说明。明细见 [`陶庵梦忆去重.tsv`](陶庵梦忆去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_taoanzhmyi.py            # 预演
python3 scripts/dedupe_taoanzhmyi.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

`poet.ming.json`／`ci.ming.json` 是从 `历代/` 拆出来的补录，混进了张岱《陶庵梦忆》的
6 篇散记，而整部书另在 `明/小说/陶庵梦忆/`：

```
明/小说/陶庵梦忆/taoanzhmyi.json#11  张岱《陶庵梦忆·卷一·木猶龍》   ← 留
明/诗/poet.ming.json#266            张岱《陶庵梦忆·卷一·木犹龙》   ← 删
```

这些是**散文**，挂在「诗」「词」目录下本来就不对；单行本有卷次、有编次，是这部书的正式形态。

## 判据

题名 t2s 归一后相同（补录把 `猶/犹`、`絶/绝`、`揚/扬` 转成了简体），正文相似度 ≥ 0.95。

另有两篇题名不同、正文能对上的，逐条写进脚本的 `ALSO`：

- 《陶庵梦忆·卷七·浴雪龙山》（补录）与《陶庵梦忆·卷七·龍山雪》（单行本）—— 卷七一题两记，
  正文相似度 0.993
- 《西湖七月半》（`ci.ming.json`）与《陶庵梦忆·卷七·西湖七月半》—— 补录把篇题简省了，
  相似度 0.993

## 不动的三条

- **《水浒传》第 41 回里引的苏轼《念奴娇·赤壁怀古》** —— 小说引用诗词，不是重复；
  小说正文也不能为了去重而改。
- **《西湖香市》等篇的用字差异** —— 两读出自同一底本、只差繁简与通用字，删的是副本，正文一字不动。
- `poet.ming.json` 里若还有别的散文（非《陶庵梦忆》），不在这一批的范围，另开。
