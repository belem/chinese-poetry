## 为什么放 `汇编/`

`docs/目录结构.md` 的第一条原则是「目录按一部书切」，第二条才是「作者朝代决定归属」。
格林兄弟是德国人、安徒生是丹麦人，都没有一个中国朝代可挂；两部书又都是短篇结集，
没有一个单一主时段。按 `汇编/` 现有的口径——**跨代、又没有单一主时段的整部书放这里**
——正好落下。`明/小说/`、`清/小说/` 都不对：那两层挂的是明清人的小说，童话既不是明清，
也不是小说。`汇编/README.md` 的目录表已补上这两部。

记录契约照全库：`author`（格林兄弟 / 安徒生）、`title`（底本篇名）、`dynasty`（德国 / 丹麦）、
`paragraphs`、`id`。安徒生底本分了四卷，合并成一份正文后卷次记在各篇的 `volume` 里。

## 底本的版式与两类毛病

两本都是一个书头（书名、著者、章节数、字数、简介、`========正文========`），之后一篇接一篇：
篇名前空一行，篇名短、顶格、不带句读；正文一段一行，长段落按定宽折行。书头不进正文。
格林童话的辅文（作者简介、内容简介）与童话之间还有一行「正文」作分隔，那行不是篇名。
安徒生底本另有卷题行（`第1卷`…`第4卷`）与篇末的发表年、校对署名、译者评注，后几样都不是
童话正文，一概不收。

**归底本的毛病，只改符号与认出是衍文的字：**

- 引号、破折号、省略号，底本一律写成 HTML 实体，`&ldquo;`→`“`、`&rdquo;`→`”`、
  `&hellip;`→`……`、`&mdash;`→`——`；成对的半角括号改全角；紧挨汉字的半角 `,;:!?` 与 `.`
  改全角；重复的点号（`！。` `，，` `。。`）删到该有的一个；词中间夹的空格删掉。
- **「一」当专名号／着重号，把单字圈成了「一X一」**：`一毛一`（毛）、`一抽一`（抽）、
  `一尸一`（尸）、`一槍一`（槍）、`一梆一`（梆）、`一里一`（白一里一透一红 → 白里透红）……
  `DOTTED` 里逐类核过才改；`一天一天`、`一模一样`、`一五一十`、`一颗一颗` 本来就这么写，
  不在表里，不动。
- **连写的「一一」**：`过了一一夜`、`揉一一揉`、`一一夜`，全书一律删一个。
  数词里的另算：`第一一夜`→`第一夜`、`第十一一夜`→`第十一夜`、`第二十一一夜`→`第二十一夜`。
- **着重号 `*`**：底本把词圈成 `色*彩`、`绿色*的`，「*」不是字，一律删掉，字不动。
- 电子本的校对署名（`（aisitair扫描漪然校对）`、`（漪然录入）`）连同它所在的整段评注一并剔除，
  有的还带着没换行的下一篇篇名。

以上逐类都写在脚本的 docstring 里，改一条就能重跑核对。

## 底本自己被排重的地方

`reference/格林童话.txt` 原把「弗雷德里克和凯瑟琳」整篇排了两遍（第 3014—3072 行是前一篇的
完整复制，两份正文逐字相同）。2026-11 已删掉重复的那一遍，`reference/` 里现在是 186 篇。

## 还没做的

两本都**没有与别的译本逐句对勘**：底本是一支电子本，个别地方有音近、形近的讹字
（「一快儿吃」之类），脚本只处理有把握的符号与「一」的衍文，其余一律不动。
`docs/progress/汇编@格林童话@gelintonghua.json` 记 `needs_review`，等有了可靠的译本再对勘。

## 安徒生这一本（2026-11 第二批，PR 见 issue #229）

《格林童话》先出，《安徒生童话》是同一支电子本的第二本。落了 `汇编/安徒生童话/`，
157 篇、2.31 万段、82.6 万字，`loader/datas.json` 注册 `andersen-tonghua`（id 126）。

底本比格林那本脏得多，改的都是**逐处核过上下文**的，口径如下：

- **「一」的两种衍文，近六千处**。除了格林那本已经见过的「一X一」圈字
  （「羽一毛一」→羽毛、「一抽一屉」→抽屉、「脱一裤」→脱裤），安徒生底本还整字吃掉了「一」：
  「第次」→第一次、「另只」→另一只、「点也」→一点也、「像你样」→像你一样、「他句话也不讲」→他一句话也不讲。
  这一类没有全表可依，是拿「量词前一个字是动词/形容词」扫出候选、再逐条看上下文定案的，
  所以必然有漏，宁可漏改。
- **着重号**。底本用 `*` 圈词（「色*彩」→色彩），也用 `|` 断词（「黄|色」→黄色）。两个都不是字，一律删掉。
- **页端残迹**。全角数字 `１００`→`100`、`<p>`/`<br>` 标签、`----------------` 分隔线、
  篇末的出版年（「（1835年）」）与译者评注、电子本的校对署名（「（aisitair扫描 漪然校对）」）——
  后几样不是童话正文，整段删掉。
- **西文里的「一」**。底本把连字符印成了「一」（「Ha一vn」「16一99」「Dia一volo」），
  汉字与西文之间多出来的「一」也一并去掉。
- **字母表里的 OCR 讹字**。《识字课本》一节一个字母一段，丹麦文的 ø/æ 被认成了 c/e/E/Ф：
  「Ｋ母牛，小牛(Ko,Kolv)」→`Kølv`、「Ｌ狮子，眼镜(Lcve,Lorgnet)」→`Løve, Lorgnet`、
  「Ф牡蛎(Фsters)」→`Østers`、「Ｅ驴(Ｅsel)」→`Æsel`、「F月食(Eormørkelse)」→`Eormørkelse`。
- **底本自己重出的两处**：一篇里「牙痛姑妈」的篇名印了两遍（「它的标题是：」之后），删掉重复的那一遍；
  「我有点诗人品质，但是还不够。」独立成段地重出一次，删掉。
- **两处注文错位**：「孩子们的闲话」的注①—④排在篇名之后、正文之前，已用空行隔开；
  「丑小鸭」的注①被印到了它所指的那句之前，已挪到篇后并调好注码。

还没做的与格林那本一样：**没有与别的译本逐句对勘**，底本里个别音近形近的讹字仍在。
