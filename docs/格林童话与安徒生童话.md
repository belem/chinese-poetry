## 为什么放 `汇编/`

`docs/目录结构.md` 的第一条原则是「目录按一部书切」，第二条才是「作者朝代决定归属」。
格林兄弟是德国人、安徒生是丹麦人，都没有一个中国朝代可挂；两部书又都是短篇结集，
没有一个单一主时段。按 `汇编/` 现有的口径——**跨代、又没有单一主时段的整部书放这里**
——正好落下。`明/小说/`、`清/小说/` 都不对：那两层挂的是明清人的小说，童话既不是明清，
也不是小说。`汇编/README.md` 的目录表已补上这两部。

记录契约照全库：`author`（格林兄弟 / 安徒生）、`title`（底本篇名）、`dynasty`（德国 / 丹麦）、
`paragraphs`、`id`。安徒生底本分了四卷，合并成一份正文后卷次记在各篇的 `volume` 里。

## 底本的版式与两类毛病

两本都是一个书头（书名、著者、章节数、字数、简介、`========正文========`），之后一篇接一篇：
篇名前空一行，篇名短、顶格、不带句读；正文一段一行，长段落按定宽折行。书头不进正文。
格林童话的辅文（作者简介、内容简介）与童话之间还有一行「正文」作分隔，那行不是篇名。
安徒生底本另有卷题行（`第1卷`…`第4卷`）与篇末的发表年、校对署名、译者评注，后几样都不是
童话正文，一概不收。

**归底本的毛病，只改符号与认出是衍文的字：**

- 引号、破折号、省略号，底本一律写成 HTML 实体，`&ldquo;`→`“`、`&rdquo;`→`”`、
  `&hellip;`→`……`、`&mdash;`→`——`；成对的半角括号改全角；紧挨汉字的半角 `,;:!?` 与 `.`
  改全角；重复的点号（`！。` `，，` `。。`）删到该有的一个；词中间夹的空格删掉。
- **「一」当专名号／着重号，把单字圈成了「一X一」**：`一毛一`（毛）、`一抽一`（抽）、
  `一尸一`（尸）、`一槍一`（槍）、`一梆一`（梆）、`一里一`（白一里一透一红 → 白里透红）……
  `DOTTED` 里逐类核过才改；`一天一天`、`一模一样`、`一五一十`、`一颗一颗` 本来就这么写，
  不在表里，不动。
- **连写的「一一」**：`过了一一夜`、`揉一一揉`、`一一夜`，全书一律删一个。
  数词里的另算：`第一一夜`→`第一夜`、`第十一一夜`→`第十一夜`、`第二十一一夜`→`第二十一夜`。
- **着重号 `*`**：底本把词圈成 `色*彩`、`绿色*的`，「*」不是字，一律删掉，字不动。
- 电子本的校对署名（`（aisitair扫描漪然校对）`、`（漪然录入）`）连同它所在的整段评注一并剔除，
  有的还带着没换行的下一篇篇名。

以上逐类都写在脚本的 docstring 里，改一条就能重跑核对。
