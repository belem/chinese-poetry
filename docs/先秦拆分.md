# 先秦：把「文」从「诗」里拆出去，并消掉专书之间的重复

`先秦/诗/poet.xianqin.json` 有 1311 条，其中真正的诗只有个位数。其余是《论语》《孟子》《左传》
《庄子》《道德经》《金刚经》《孙子兵法》《山海经》《三十六计》……**文体、书名、作者三样全不对**，
而且与仓库里已有的专书大量逐字相重：同一段《论语》，`先秦/论语/lunyu.json` 有一份，
`poet.xianqin.json` 里又按章分条存了一遍。

这一轮按 AGENTS.md 的「一件作品只留一份正文」处理干净。逐条清单见 [先秦拆分.tsv](先秦拆分.tsv)。

## 怎么分派的

先按题名认书（`论语·学而篇·第二章` → 《论语》），题名不含书名的按别名表
（`鱼我所欲也` → 《孟子》、`郑伯克段于鄢` → 《左传》），认不出书名的按作者
（左丘明 → 《左传》、释迦牟尼 → 佛经）。

然后拿正文去已有专书里找：

- **正文逐字已在专书里** → 删本条，专书那份不动。
- **正文对不上但有书可归** → 移到 `先秦/文/<书>.json`。
- **本身就是诗/辞** → 留在 `poet.xianqin.json`。

判重是简繁归一、去标点后的子串匹配，按「全篇 → 最长可对上前缀」二分，前缀达到全书长度的
全部或 ≥20 字即视为重出。跨简繁（`孟子` vs `孟子`）、跨标点（`？` vs `□`）都能对上。

## 拆到一半才发现的：四书五经目录自己也有问题

`先秦/四书五经/` 名不符实——它只收了《孟子》《大学》《中庸》三本，没有《论语》，也没有五经；
`daxue.json`、`zhongyong.json` 是单章 dict 而不是列表，`loader` 读不了（`datas.json` 里那句
「四书五经的其他文件不符合两层结构, 以后再想办法处理吧」就是这个）。一并收干净：

- `先秦/论语/`、`先秦/孟子/`、`先秦/大学/`、`先秦/中庸/` 四个目录，一目录一本书。
- 大学、中庸 由 dict 改为单元素列表，正文不动。
- 孟子、论语 补进 `poet.xianqin` 里有、专书里缺的章节：论语补 21 段（述而篇缺的「圣人吾不得而见之矣」
  一节 + 各篇异文段），孟子按「书·卷·篇·节」补 52 节。`mengzi.json` 690 → 784 段。
- `先秦/四书五经/` 目录删除。

**没有并进去的**：《论语》十二章、论语三则、子路曾晳冉有公西华侍坐、生于忧患死于安乐、
鱼我所欲也、得道多助失道寡助——这些是**教材选目**，散取各篇拼成一课，不是古书单元，
也不是古书里的篇名。它们仍是 `tags` 意义上的选本记录，不往本经里塞。

## 楚辞：异文挂 variants，不另存一份

剩下三首楚辞与 `chuci.json` 同名篇互有脱衍：河伯（116/113 字）、惜诵（576/584）、思美人（413/415），
差在 `谯`/`憔`、`伫`/`𥩟` 这类异体字与个别虚词。处理是把 `poet.xianqin` 那一份挂到对应篇的
`variants` 字段，正文只留 `chuci.json` 的一份。《越人歌》专书未收，作独立篇目补进 `chuci.json`
（`section: 附`，无名氏），它是楚辞体的先声，留在「诗」里名不正。

`poet.xianqin.json` 处理完后删空，`先秦/诗/` 目录一并删除；`loader/datas.json` 的
`xianqin-shi`（id 34）删除。
