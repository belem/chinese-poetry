## 批次 1：题名全角空格改半角

规矩来自 issue：**标题只用半角空格**，全角空格 U+3000、制表符一律换成半角，
文字之间只留一个半角空格。实施上就是逐个字符替换，**不增删任何汉字**，
一批一批跑完可以用 `git diff` 逐行核对（改动只有空格那一个字符）。

改了 17 个文件：

- 史书：`史记`（130 个题名）、`三国志`（65 个）——「史記卷1　五帝本紀第一」→「史記卷1 五帝本紀第一」
- 章回小说：三国演义（120）、水浒传（120）、红楼梦（120）、东周列国志（108）、封神演义（100）、
  西游记（100）、镜花缘（100）、说岳全传（80）、儒林外史（56）
- 话本：三言二拍的三部（各 40）、初刻拍案惊奇（40）、二刻拍案惊奇（40）
- 诗：全唐诗 `poet.tang.22000.json`（49 条，白居易《新乐府》一批底本用 `\t` 分栏）

合计 1348 个题名。

### 没有动的

- 《全唐诗》《全宋诗》里「郊廟歌辭  善勝舞」「二風詩   一」这类**连续两个/三个半角空格**：
  那是底本的分栏（题与篇目、组诗与序号），不是错字，`scripts/check_title.py` 把它们记在
  `multi_space` 里，等有本子可校再说。
- 正文里同样的全角空格：这一批只动标题，正文归乱码修复流程。

## 批次 2：词（`ci.*`）

词 34 个文件、23445 条，`rhythmic`（词牌）与 `title`（词题）两个字段一起查。
全角空格、制表符、假名注音、西里尔与希腊字母、私用区、零宽字符、题名首尾空格：**0 处**，
这一批只动两种：

**题末句号（9 条）。** 题名不是句子，末尾不该带 `。` —— 词题本身就是一句短语，
加句号是抓取时按正文标点断句留下的：

```
永遇乐·彭城夜宿燕子楼，梦盼盼，因作此词。   → 删去句号
点绛唇·丁未冬，过吴松作。                   → 删去句号
眼儿媚·萍乡道中乍晴，卧舆中困甚，小憩柳塘。 → 删去句号
得阮梅叔书，倚此代答。                       → 删去句号
```

`宋/宋词/ci.song.22000.json` 7 条、`ci.song.23000.json` 1 条、`清/词/ci.qing.json` 1 条。
只删末尾那一个字符，题中本来的句读（「定风波·……余不觉。已而天晴，故作此」）不动。

**`rhythmic` 与 `title` 错位（1 条）。** `宋/宋词/ci.song.22000.json#924`：

```
rhythmic: 秋霁（西湖十咏      ← 词题「西湖十咏」的前半截粘在词牌后面，左括号没有着落
title:    平湖秋月）          ← 「西湖十咏」组词里的这一首，只剩后半截
```

按同文件其余词的写法（`title` 作「词牌·词题」）：

```
rhythmic: 秋霁
title:    秋霁·平湖秋月
```

正文一字未动。删掉的「（西湖十咏」是**组词信息**，不是这首词自己的词题，
留着的「平湖秋月）」也不能单独成题 —— 这一处是格式错误，不是异文。

### 没有动的

  删句号会改正文，等元曲那一批按本子处理。
- 《全宋诗》「降神用《高安》。」一类（1042 处）：郊祀乐章的老标点，一条一首、
  题与正文一一对应，等有政和／绍兴本可校时再定。
