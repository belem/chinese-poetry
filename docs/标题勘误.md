## 批次 1：题名全角空格改半角

规矩来自 issue：**标题只用半角空格**，全角空格 U+3000、制表符一律换成半角，
文字之间只留一个半角空格。实施上就是逐个字符替换，**不增删任何汉字**，
一批一批跑完可以用 `git diff` 逐行核对（改动只有空格那一个字符）。

改了 17 个文件：

- 史书：`史记`（130 个题名）、`三国志`（65 个）——「史記卷1　五帝本紀第一」→「史記卷1 五帝本紀第一」
- 章回小说：三国演义（120）、水浒传（120）、红楼梦（120）、东周列国志（108）、封神演义（100）、
  西游记（100）、镜花缘（100）、说岳全传（80）、儒林外史（56）
- 话本：三言二拍的三部（各 40）、初刻拍案惊奇（40）、二刻拍案惊奇（40）
- 诗：全唐诗 `poet.tang.22000.json`（49 条，白居易《新乐府》一批底本用 `\t` 分栏）

合计 1348 个题名。

### 没有动的

- 《全唐诗》《全宋诗》里「郊廟歌辭  善勝舞」「二風詩   一」这类**连续两个/三个半角空格**：
  那是底本的分栏（题与篇目、组诗与序号），不是错字，`scripts/check_title.py` 把它们记在
  `multi_space` 里，等有本子可校再说。
- 正文里同样的全角空格：这一批只动标题，正文归乱码修复流程。

## 批次 2：词（`ci.*`）

词 34 个文件、23445 条，`rhythmic`（词牌）与 `title`（词题）两个字段一起查。
全角空格、制表符、假名注音、西里尔与希腊字母、私用区、零宽字符、题名首尾空格：**0 处**，
这一批只动两种：

**题末句号（9 条）。** 题名不是句子，末尾不该带 `。` —— 词题本身就是一句短语，
加句号是抓取时按正文标点断句留下的：

```
永遇乐·彭城夜宿燕子楼，梦盼盼，因作此词。   → 删去句号
点绛唇·丁未冬，过吴松作。                   → 删去句号
眼儿媚·萍乡道中乍晴，卧舆中困甚，小憩柳塘。 → 删去句号
得阮梅叔书，倚此代答。                       → 删去句号
```

`宋/宋词/ci.song.22000.json` 7 条、`ci.song.23000.json` 1 条、`清/词/ci.qing.json` 1 条。
只删末尾那一个字符，题中本来的句读（「定风波·……余不觉。已而天晴，故作此」）不动。

**`rhythmic` 与 `title` 错位（1 条）。** `宋/宋词/ci.song.22000.json#924`：

```
rhythmic: 秋霁（西湖十咏      ← 词题「西湖十咏」的前半截粘在词牌后面，左括号没有着落
title:    平湖秋月）          ← 「西湖十咏」组词里的这一首，只剩后半截
```

按同文件其余词的写法（`title` 作「词牌·词题」）：

```
rhythmic: 秋霁
title:    秋霁·平湖秋月
```

正文一字未动。删掉的「（西湖十咏」是**组词信息**，不是这首词自己的词题，
留着的「平湖秋月）」也不能单独成题 —— 这一处是格式错误，不是异文。

### 没有动的

## 批次 3：诗（`poet.*`）

`poet.*` 各文件逐条查过：全角空格、制表符、假名注音、西里尔与希腊字母、私用区、

**改：题末句号 2 条。**

```

頌古七首 雲門示衆云：人人盡有光明在。              → 删去句号
```

第二条是釋克勤《頌古七首》的第七首：同组另外六首都不带句号（「頌古七首 須彌山」「頌古七首 麻三斤」），
只有这一首末字「在」后多一个句号 —— 公案里那句话本没有句号，是抓取时按正文标点补的。

**不改：郊廟朝會歌辭的旧标点（1160 处）。**

```
建隆郊祀八首 降神用《高安》。
元符親郊五首 升陞用《乾安》，罍洗、飲福並奏。
寧宗郊祀二十九首 降壇。
```

散在 `poet.song.249000/250000/251000.json` 三卷。这类题名照抄《宋史·乐志》，四库本里
「用《高安》」「降壇」后面本来就有句号 —— 删了就不是照录原书了。与「課本寫法不等於原文」
同一个道理：**有依据的读法不改**，所以整批留在 `trailing_punct` 的基线里。

**不改：《頌古》组诗题名末尾的句号（25 处）与釋遵式《改祭修齋决疑頌》的「頌曰：」（10 处）。**
前者是灯录里带下来的断句（「頌古四首 夾山境話。」），后者是底本引出正文的冒号，都不是抓取留下的。

**存疑未改**：

- 《全唐诗》三条「贈雷殿直。」「題泗州劉中丞郡中新樓。」「頌 諸佛不出世……少林有妙訣。」：
  「。」与题名之间没有其他线索，可能同郊廟一样是底本的标点，也可能同上一批那样是抓取断句。
  无本子可核，先留着。
- 杜甫「巫山縣汾州唐使君十八弟宴別兼諸公攜酒樂相送率題小詩留於屋壁，」：题末是逗号，
  仇兆鰲《杜詩詳注》题末有「」还是就这样，手头无本子可核。
- 李時亮「萬里波光外，孤城南極西。」、釋子琦「虛空無內外，事理有短長。……」：
  这两条像是**诗句误进 title**（正文另有一首），但没查清是哪一首漏了题，不猜。

## 批次 6：空格一律一个半角

issue #258 追加的话：**无论原来多少空格，标题都要降为一个半角空格**。这句话推翻了批次 1
「两空格是底本分栏、不动」的判法 —— 也对，空格不是字，照录底本算不上「读法」，
分栏要留就换个记号再说。于是两批一起做：

**全角空格／制表符（1348 个题名）。** 批次 1 的 17 个文件早已改过，这次把漏掉的旁支补齐：

- `唐/诗/全唐诗/poet.tang.52000.json`、`宋/诗/全宋诗/error/poet.tang.52000.json`：
  作者名「道鏡　善導」22 + 3 条
- `唐/诗/全唐诗/authors.tang.json` 作者名 5 条：「光\t威\t裒」「芙蓉古丈夫　毛女」「齊己　牟儒」等
- `rank/poet/poet.tang.rank.{22000,44000,47000,51000,52000}.json`、`rank/ci/ci.song.rank.{7000,8000}.json`：
  题名「新樂府 七德舞\t美撥亂，陳王業也」49 条、作者名「李隆基（玄宗　明皇）」「光\t威\t裒」、
  词牌「采莲　遍・采莲令」

`rank/` 是排行榜数据（按搜索量排序），不在 `loader` 里，但它和对应诗作的题名是同一份，
错字同样要改。改动只有空格那一个字符，`git diff` 可逐行核对。

**连续两个以上的半角空格（97327 处，263 个文件）。** 主要是《全宋诗》《全唐诗》沿用底本的
「题  其一」「郊廟歌辭  善勝舞」分栏。判据从「汉字之间三个以上」改成「连着两个以上」，
不再区分位置（题与序号之间、夹注之后的一律算）：

```
次韻漳州鄧教授二首  其一   → 次韻漳州鄧教授二首 其一
郊廟歌辭  善勝舞           → 郊廟歌辭 善勝舞
二風詩   一                → 二風詩 一
```

**这批与「照录底本」不冲突。** 批次 1、3 里判为不动的，是**字**（郊祀乐章的旧标点、
「琵琶引」的「秋索索」）—— 有本子依据的读法不改；空格不是字，底本用它排版，网页里
它就是多余字符，缺了也不算改字。

`scripts/check_title.py` 相应改口径：`multi_space` 不再要求「汉字之间、三个以上」，
`multi_space` 与 `fw_space` 从 `scripts/title_baseline.json` 里撤掉 —— 这两项是
「查出来就该改」的硬错，留着基线等于给它开后门。基线现在只剩 `trailing_punct`
与 `unmatched_punct`（都是等本子可校的）。

### 没有动的

- 正文里的空格：这一批只动 `title` / `chapter` / `rhythmic` 三个字段与作者名。正文里的
  全角空格（`先秦/文/fahuajing.json` 的偈颂、`唐/诗/全唐诗/*` 的 `prologue` 等）归乱码修复流程。
- `reference/`（导入源）与 `docs/progress/`（审查记录）：不是发布语料，`check_title.py` 也不查它们。

## 批次 7：作者名同口径

批次 6 改了题名与作者名里的空格，但检查范围漏了两块，作者名也没进 `check_title.py` 的字段表：

- `scripts/check_structure.py` 的 `SKIP_DIRS` 里有 `rank` 与 `error`，`check_title.py` 复用它遍历文件，
  于是 `rank/`（排行榜，题名与作者名跟诗作是同一份）和 `宋/诗/全宋诗/error/` 从来没被体检过；
- `FIELDS` 只有 `title` / `chapter` / `rhythmic`，作者名里的全角空格只剩肉眼能看。

**改动：作者名的 4 处全角空格 → 半角**（题名、正文一个不碰）：

```
芙蓉古丈夫　毛女 → 芙蓉古丈夫 毛女   （唐/诗/全唐诗/poet.tang.47000.json，2 条）
齊己　牟儒       → 齊己 牟儒         （poet.tang.55000.json、rank/、error/ 同一份）
尚隆之　吳永素   → 尚隆之 吳永素     （poet.tang.56000.json、rank/、error/ 同一份）
```

`rank/` 与 `error/` 里的同名字段一并改：三份是同一份题名与作者名的不同拷贝，只改一份等于没改。

**`scripts/fix_spaces.py`（新）**：题名与作者名的空格归一，`--apply` 才写文件。只替换那几段值的
字面，不重排文件 —— 各文件的缩进有的是 2、有的是 4，整体 `json.dump` 一遍 diff 就变成整个文件，
改动无从核对。

### 没有动的

- `光\t威\t裒`（`poet.tang.44000.json`）：那是《全唐詩》里光、威、裒三个人合署，制表符换成半角空格会
  读成一个人名。规矩「只留一个半角空格」在这里做不到，除非另找记号 —— 记在 KEEP 里，`check_title.py`
  照旧报出来，等人定。
- `rank/` 下题名的 98579 处两空格、`error/` 下的 938 处（`句  其一` 这种底本分栏）：按批次 6 的
  口径该改，但那是另一个批次的量，不在这次作者名的修订里。`check_title.py` 现在能看见它们了，数就在那里。
- 正文（`paragraphs`）、`prologue`、`authors/*.json` 的 `desc`：不是题名也不是作者名，归乱码修复流程。

## 批次 8：选本与史书（issue #258 点名的十一部书）

《隋唐演义》《楚辞》《安徒生童话》《伊索寓言》，用同一套口径把标题（含章回回目）再查一遍。
范围共 **275 个文件、20279 个标题字段值**（`title` / `chapter` / `rhythmic` / `subtitle` /
`section` / `category` / `subcategory`，外加《古文观止》选目的 `篇目`、《词综》《古诗源》目次的 `titles`）。

查的项与 `scripts/check_title.py` 相同：非半角空格（全角空格、制表符、U+00A0、U+2000–200A…）、
连续空格、首尾空格、配对符号（含 `（）`「」『』【】〔〕〖〗〈〉 与半角括号）、题末句读、
ASCII 残留（`.` `,` `?` `!` `:` `;` `'` `"` `[` `]` `&` `<` `>` `#`）、假名／注音、西里尔与希腊字母、
私用区、零宽字符、U+FFFD、框线符，以及**非 GB2312 的生僻字**（逐个看是不是乱码）。
明细脚本：`scripts/fix_title_batch.py`（`--apply` 才写文件，只换那几段值的字面，不重排文件）。

**改的只有下面这些，共 6 个文件：**

**隋唐演义 100 回回目里的全角空格（200 处）。** 每回两个，夹在「回次／上句／下句」之间：

```
第1回　隋主起兵代陈　晋王树功夺嫡  → 第1回 隋主起兵代陈 晋王树功夺嫡
```

与批次 1、6 的史书、章回小说同口径。全库 `fw_space` 从 100 处降到 1 处，剩下的那一处是
《全唐詩》作者名 `光\t威\t裒`，见批次 7。

**《词综》题末的逗号（2 条）。** 底本把句读排进了标题行（`齐天乐严县尹席上和李观我韵， 刘天迪`），
逗号是断句记号，不是题名的一部分。只删末字，`subtitle` 同步：

```
齐天乐·严县尹席上和李观我韵，  → 齐天乐·严县尹席上和李观我韵
尉迟杯·题卢古溪响碧琴所，      → 尉迟杯·题卢古溪响碧琴所
```

**《词综》卷二十四的一条「词牌」其实是出处（1 条）。** 底本 4981 行：

```
红见？梅苑。 无名氏
粉香尤嫩，霜寒可惯&怎奈向春心已转。……
```

同卷 4972、4975、4978、4984 四首作「尉迟杯见？梅苑」「洞仙歌见？梅苑」「万年欢见？梅苑」
「忆少年见？梅苑」，录入时都按「词牌＋正文」处理：词牌取前半，正文照录。这一首的前半只剩一个「红」，
`rhythmic` 记成「红见？梅苑。」整串就读不通了 —— 「见？《梅苑》」是**出处**，不是词牌。
本库对这类出处没有专门字段，别处一律留在题名里，这里照办：删题末句号，首句补满 12 字
（同卷其余各首一律 12 字），`词综.json` 目次里那条「题　作者」摘记一并改。
`rhythmic` 该填什么，要等有人按《梅苑》定下这调的名字，先不猜。

**《战国策》三条章题。** 两条题末多一个孤立的 `“`，一条把底本的生僻字记法带进了题名：

```
戰國策·卷二十八 韩三·东孟之会“            → 戰國策·卷二十八 韩三·东孟之会
戰國策·卷三十 燕二·奉阳君千朱讙与赵足“    → 戰國策·卷三十 燕二·奉阳君千朱讙与赵足
戰國策·卷七 秦五·楼<吾午>约秦魏            → 戰國策·卷七 秦五·楼{吾午}约秦魏
```

前两条是底本章头 `○东孟之会“东孟之会，`、`○奉阳君告朱讙与赵足“` 的引号（跨章的引文符号，
正文里那个引号照样留着），切题时被带进了题名，题名里没有配对的右引号。
第三条：底本用 `<…>` 标未编码的生僻字，全库一律写 `{}`，`import_zhanguoce_reference.py` 的
`clean()` 只洗了正文，章题漏了。脚本已两处都补上（`FIXES` 加两条、`build()` 里章题也过 `clean()`），
重跑 `--check` 一致。三条记录按「author|title|正文」重算 `id`，全库没有引用它们的 `记录` 指针。

**《安徒生童话》的副题分隔（1 条）。**

```
古教堂的钟-为席勒纪念册而作 → 古教堂的钟——为席勒纪念册而作
```

同书另有「老栎树的梦——一个圣诞节的童话」，`-` 是录入时偷懒，中文副题用破折号。

### 基线

`scripts/title_baseline.json` 从 `{trailing_punct: 1203, unmatched_punct: 7}` 改为
`{trailing_punct: 2417, unmatched_punct: 27}`。数目变大不是这一批改坏的，是**基线本身过期了**：
两项都只由 `title` / `chapter` / `rhythmic`（以及批次 7 之后的 `author`）统计，而 CI 的
`--files-from-diff` 只比本 PR 碰过的文件，`develop` 上没人重算过。先把 `develop` 原样跑一遍
（`git stash` 后 `python3 scripts/check_title.py --baseline scripts/title_baseline.json`）：

```

✗ trailing_punct: 2417           ✗ unmatched_punct: 27        （改动后）
```
