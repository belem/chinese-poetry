# `汇编/` 选本与各代补录的互见

`scripts/dedupe_huibian_poet.py` 的说明。逐条判定见 [`汇编与诗去重.tsv`](汇编与诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_huibian_poet.py --poet 汉                      # 预演
python3 scripts/dedupe_huibian_poet.py --poet 汉 --apply --date YYYY-MM-DD
```

`--poet` 选要清的补录：`汉`（`汉/诗/poet.han.json`）、`唐`、`宋`、`清`、`晋`、`南北朝`、`明`。
每跑一次只写一份补录与一份 TSV，一批一批来。

## 现状问题

`汇编/` 下的书（古文观止、昭明文选、乐府诗集、课本选目）是**选本**，有底本、有编次、有篇题；
各代 `poet.*.json` 是《历代》拆出来的**补录**（正文来自 海棠诗社语料，没有版本信息）。

同一篇两边各有一份，勘误时两边都要改。`poet.han.json` 314 条里有 40 条与选本重：

```
汉/诗/poet.han.json           司马迁《报任安书》2396 字
汇编/古文观止/卷五漢文.json    司馬遷《報任安書》2396 字
```

## 判据

- 正文 `t2s` 去标点前 16 字相同，相似度 ≥ 0.90，或一方的每一句都能在另一方里找到（`covered`）；
- 满足就删**补录**那条，选本不动（选本有底本、有编次，删了「这本书收了哪些」就没了）。

**不删的三类**：

| 情形 | 例 |
| --- | --- |
| 补录是整篇、选本只取一段（题名带「序」「节选」） | 补录《史记·游侠列传》2050 字 vs 古文观止《遊俠列傳序》666 字 |
| 选本的一条是多首合成（《古诗十九首》1269 字一条），补录逐首一条 | 选本是编法，不是同一件作品的两种录文 |
| 正文对不上（相似度 < 0.90 且逐句对不上） | 《滑稽列傳》4767 字 vs 679 字、课本选目的改写 |

## 本轮（`--poet 汉`）：40 条里删 33 条，留 7 条

删的 33 条是古文观止、昭明文选、乐府诗集、课本选目与 `poet.han.json` 的同一篇：
《报任安书》《过秦论》《治安策》《论贵粟疏》《答苏武书》《报孙会宗书》……
《战国策》那十来篇（古文观止署「佚名」、补录署「刘向」）也在内 —— 同一篇原文，作者署不署编者不影响判重。

留的 7 条见上表。`poet.han.json` 314 → 281 条，正文一字未动。
