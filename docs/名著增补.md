# 古典名著的收尾状态

「名著增补」指的是《红楼梦》《西游记》《三国演义》《水浒传》等长篇白话小说正文的补录。
它们随海棠诗社语料（MIT）一起进来，落在 `历代/` 的 `wen.*` 分片里，2026-10 目录重构时按作者朝代
拆进 `明/诗/poet.ming.json`、`清/诗/poet.qing.json`（见 [`历代拆分.md`](历代拆分.md)）。
本文件记的是：这几部书收齐了没有、有哪些已知缺口、还剩什么没做。

## 2026-10 修的回目编号

### 《三国演义》第一百零一回至第一百零九回

原数据把 101–109 回写成了「第一百十一回」…「第一百十九回」，与真正的 111–119 回撞号：

```
第一百回     汉兵劫寨破曹真武侯斗阵辱仲达
第一百十一回 出陇上诸葛妆神奔剑阁张郃中计   ← 实为第一百零一回
…
第一百十九回 困司马汉将奇谋废曹芳魏家果报   ← 实为第一百零九回
第一百一十回 文鸯单骑退雄兵姜维背水破大敌
第一百一十一回 邓士载智败姜伯约诸葛诞义讨司马昭
```

判据是回目本身：毛纶、毛宗岗父子评本，「陨大星汉丞相归天　见木像魏都督丧胆」是第 104 回，
「武侯预伏锦囊计　魏主拆取承露盘」是第 105 回，一路对到「困司马汉将奇谋废曹芳　魏家果报」是第 109 回。
十条只是编号写错，正文没有错位，也没有缺回——改号后 1–120 回齐全，按号排序也顺了。

### 《水浒传》第八十三回

「宋公明奉诏破大辽　陈桥驿滴泪斩小卒」是第 83 回，原数据与真正的第 82 回（梁山泊分金大买市）
用了同一个回号。第 83 回因此算缺失，改号后 120 回齐全。

### 《红楼梦》第二十七回的次序

第 27 回（滴翠亭杨妃戏彩蝶　埋香冢飞燕泣残红）那条原本排在第 30 回之后。正文没错
（首句接第 26 回末「要知端详，且听下回分解」，末段是《葬花吟》，结在「花落人亡两不知」），
是记录位置错了，已挪回 26 与 28 之间。

三处都只动 `title`（和一条记录的位置），`paragraphs`、`author`、`id` 一字未改。
`id` 由「作者+题名+正文」哈希得来，而 `scripts/backfill_ids.py` 的既定口径是「搬目录、重分片不变号」，
所以没有为改题名重算 id；真要重算，整库一起跑。

## 一部书一个目录，选篇已收干净

四部章回小说一条一回，动辄三五十句、几千字，与诗、词、文的粒度差得很远；
`scripts/check_structure.py` 的句长与词牌检查对它们全是噪音。2026-10 起它们各占一个目录
（`明/小说/`、`清/小说/`），在 `loader/datas.json` 注册成独立 dataset，不再混在 `poet.*` 里。

《聊斋志异》《陶庵梦忆》《浮生六记》走的是同一条路：先按版本整本取，再把 `poet.*` 里的选篇删掉，
一件作品只留一份正文。2026-10 这一步做完了 —— 三本书原来散在 `poet.ming.json`（6 篇）与
`poet.qing.json`（5 条）里的 11 条已全部删除，改由 `明/小说/陶庵梦忆/`、`清/小说/聊斋志异/`、
`清/小说/浮生六记/` 的整本正文承担。判重明细见下一节。

### 三本各自的缺口，先说清楚

- **聊斋志异只有 27 篇。** 识典那个青柯亭本电子本只做到四卷：卷一（16 篇）、卷五（1 篇）、
  卷九（1 篇）、卷十（9 篇），中间卷二的页面是一页压了七十多篇、篇名全丢，取不出单篇。
  又拿铸雪斋钞本（`CADAL02111693`）试了一遍：同样是整卷压页，篇名只落在 h3 上零星几处，
  所以没有拿它拼「全本」——拼出来的东西没法逐篇担保出处。27 篇是真数，不是抽样。
  补齐要另找能逐篇切开的底本，这件事没在本轮做完。
- **陶庵梦忆八卷 120 篇齐了。** 通行本 123 篇的说法含《补遗》三篇，粤雅堂本无补遗，八卷本身是完整的。
- **浮生六记卷五、卷六底本即「缺」。** 这书 1935 年后通行的「足本」后两卷是伪作，中央書局本
  只留「缺」字，照录。卷一至卷四全文（8747 / 4772 / 8226 / 14298 字），原 `poet.qing.json`
  里那条「卷一·闺房记乐（节选）」只有 1244 字。

### 课本选目里那四篇，判到最后两条是重

题面点的《促织》《山市》《狼》《湖心亭看雪》四篇，逐条查下来是这样：

- **《黠狼》（`汇编/课本选目/寓言故事.json`）就是《狼三则》其二。** 课本把《狼三则》拆开选，取的是第二则。
  正文与青柯亭本《狼三则》中间那则一致（「一屠晚归，担中肉尽，止有剩骨……」），**保留**：
  它是课本选目的独立视图，颗粒度与整本不同，正如唐诗三百首挂在全唐诗上并存。
- **《湖心亭看雪》两存了。** `古文观止·补.json` 里原有一条、课本选目 `山水游记.json` 没有收、
  新抓的 `陶庵梦忆·卷三·湖心亭看雪` 又有一条。逐字比：只有「凇/淞」「餘/余」「痴/癡」这类
  异体与断句之差，是同一篇。按「一件作品只留一份正文、选本并进总集」的口径，
  **删了 `古文观止·补.json` 那条**（整本比选本耐查），课本选目那份既然本来就没有，不必动。
- **《促织》《山市》不在课本选目里。** `汇编/课本选目/` 八个文件逐条查过，蒲松齡只有
  《群啄魚》《黠猱》《黠狐》《黠狼》《稚犬銜虎尾》五条，就是上面说的第二则，没有《促织》《山市》。
  所以这两篇不存在判重，只是 `poet.qing.json` 的选篇要并进整本 —— 已并。
- 顺带提一句：《黠猱》《黠狐》两篇也署蒲松齡，但正文不在青柯亭本里，出处存疑，没跟着一起删。

## 还缺的

1. **《聊斋志异》只到 27 篇**（卷一卷五卷九卷十）。识典的青柯亭本、铸雪斋钞本都是整卷压页、
   篇名不落 h3，取不出逐篇正文；要补齐得另找能逐篇切开的版本，见上一节。
2. **`□` 缺字**：这四部小说是最大来源之一，`poet.ming.json` 里 2445 处、`poet.qing.json` 里 1168 处。
   多数是句末的「？」「！」「。」被 OCR 成 `□`（如《西游记》第三十一回「你怎么瞒得过我□我这左耳往上一扯」），
   另一部分是「掼做个肉-子」这类整字被吃掉。前者可按标点位置判，后者要拿刻本逐句核，
   归到 `□` 缺字批量对勘那条线（单独开 issue）。
3. **回目与正文间的异体字没校过**：《水浒传》第 82 回回目首字衍出「回吴用使时迁盗甲」，
   《三国演义》「许诸裸衣斗马超」（通行本作「许褚」），都还未动。
