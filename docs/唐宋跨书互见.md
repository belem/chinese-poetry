# 《全唐诗》与《全宋诗》互见

`scripts/dedupe_tangsong_cross.py` 的说明。逐组判定见 [`唐宋跨书互见.tsv`](唐宋跨书互见.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_tangsong_cross.py                      # 预演
python3 scripts/dedupe_tangsong_cross.py --apply --date YYYY-MM-DD
```

## 现状问题

《全唐诗》末几卷（`poet.tang.5*`）收的是五代八宋的诗人：徐鉉、劉兼、王周、譚用之、孟貫、
李九齡、伍喬、朱存、胡宿、陳摶…… 他们入宋以后的诗，《全宋诗》又收了一遍。两书各按各的底本编，
921 组「正文前 16 字相同」的互见里，**486 组是同一个人、同一首**。

## 判据（三条都要）

1. 作者署名一字不差（简体化后比）；
2. 正文 `t2s` 去标点后整篇相同，或等长而只差正俗字（`徧/遍`、`岗/冈`、`祇/只`、`萡/箔`）；
3. 题名能对上（一条是另一条的后缀，或词袋重合 ≥ 0.5）—— 《全唐诗》的「秦淮（以下景物）」与
   《全宋诗》的「金陵覽古 秦淮」是编法不同，不算冲突。

删《全宋诗》那份：这些人物的编次在《全宋诗》第一卷，但正文底本《全唐诗》那边更早、更全
（徐鉉 309 首 vs 229 首）。删重复的一份不影响「《全宋诗》收了哪些」—— 那层信息在目录与卷次里。

## 本轮：921 组里删 486 条，两存 435 组

| 两存 | 组 |
| --- | --- |
| 同作者、正文有出入（异文） | 105 |
| 作者不同：`延寿／释延寿`（64）、`张泌／张佖`（15）、`赞宁／释赞宁`（5）这类同一人的两种署名 | 84 |
| 作者不同：`唐彦谦／戴表元`（22）、`花蕊夫人徐氏／王某`（16）、`杜光庭／宋徽宗`（6） | 44 —— 张冠李戴，要查原书 |
| 同作者、正文全同而题名对不上（组诗拆条） | 5 |

作者不同的一律两存、逐条记进 TSV：那是《全唐诗》《全宋诗》各自的归属，替古人定案不是这一轮的事。

## 结果

《全宋诗》254380 → 252668 条（少 1712 条里，486 条是这一批，其余另计）。
逐条比对过：没有一条正文被改动，全是删除。
