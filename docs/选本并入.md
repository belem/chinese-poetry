# 选本并入总集

`scripts/merge_selections.py` 的说明。逐条对照见 [`选本并入.tsv`](选本并入.tsv)，可随时重跑。

```bash
python3 scripts/merge_selections.py            # 预演
python3 scripts/merge_selections.py --apply    # 写回，并生成 选本并入.tsv
```

## 为什么并

选本是两百来首的精选视图，正文与总集重复。目录里留副本，同一首作品就有两份正文，勘误时两边都要改，改漏一处就漂。所以选本的正确定位是总集记录上的 `tags`，加上 `anthologies/` 那份目次。

四件事：

| 目录 | 原来 | 现在 |
| --- | --- | --- |
| `唐诗三百首/` | 65 首独立副本 | 能对上的 60 首挂 `tags: ["唐诗三百首"]`，剩下 5 首留原文件 |
| `水墨唐诗/` | 4 首 | 1 首并回（带 prologue），3 首留原文件 |
| `宋词三百首/` | 4 首 | 4 首都是清词与僻调，总集未收，全部留下 |
| `近现代诗/` | 41 首 | 3 首并回（欧阳修《生查子》→全宋词，魏学洢《核舟记》、荀子《劝学》→历代），12 首留原文件 |

`唐诗三百首/` 已经在 `docs/唐诗去重.tsv` 里记过一次（`全唐诗/唐诗三百首.json` 366 首那份），那是另一个文件。这个目录是上游 `poems-tangshi.js` 的 65 首，此前没并过。

## 怎么判同一首

沿用 `merge_anthologies.py` 的口径：正文（`t2s`、去标点）相似度 ≥ 0.8，或选本句子全部见于该记录。另加两条：

- **选本带序**：题名有「並序」时，第一段若不到全篇四分之一就是序，去掉再比。元结《賊退示官吏・並序》正文相似度只有 0.79，去序后能对上。
- **选本带前缀**：比对题名时剥掉「雜曲歌辭」「相和歌辭」这类乐府类目前缀，取前 4 字。「破山寺後禪院」对「題破山寺後禪院」靠的就是这条。
- **节选**：题名含「节选」时，正文是总集记录的前半段，按全本记并挂回原记录（白居易《村民苦寒（节选）》→《村居苦寒》）。

作者不同的一律两存，不做判断。

## 留下来的是什么

`近现代诗/` 当时剩 35 首，其中 10 首是明清作品（唐寅《畫雞》、高鼎《村居》、袁枚《所見》、王冕《墨梅》、譚嗣同《潼關》…）。它们留下，是因为**明清诗那时没有总集**——`全唐诗/poet.tang.*` 只到五代，`历代/` 只有 haitang 补的那 5607 条，对不上正文。

这一条已经解决：`scripts/split_dynasty.py` 把 `历代/` 里的明清作品拆成 `明代/诗/`、`明代/词/`、`清代/诗/`、`清代/词/` 四部书，课本选目一并归位。见 [`历代拆分.md`](历代拆分.md)。

## 排版

`save()` 只替换真正改过的记录：原文每层的缩进宽度、每行的行尾空格都从原文量出来照抄。宋词那批每行尾部有一个空格，`全唐诗/poet.tang.*` 用三层缩进，元曲是单行紧凑格式——三种排版都能逐字节复现，因此一条改动只产生几行 diff，不会让整份文件重新排一遍。
