# 选本并入总集

`scripts/merge_selections.py` 的说明。逐条对照见 [`选本并入.tsv`](选本并入.tsv)，可随时重跑。

```bash
python3 scripts/merge_selections.py            # 预演
python3 scripts/merge_selections.py --apply    # 写回，并生成 选本并入.tsv
```

## 为什么并

选本是两百来首的精选视图，正文与总集重复。目录里留副本，同一首作品就有两份正文，勘误时两边都要改，改漏一处就漂。所以选本的正确定位是总集记录上的 `tags`，加上 `anthologies/` 那份目次。

四件事：

| 目录 | 原来 | 现在 |
| --- | --- | --- |
| `唐/唐诗三百首/` | 65 首独立副本（PR #43 校勘后 55 首） | **目录已删**（2026-10）：拆开分卷的几首后共 58 首，57 首挂 `tags: ["唐诗三百首"]`（其中 1 首按目次取总集的正文、2 首按总集记载补录），1 首因总集只剩题注无从对勘而留下。逐条见 [`选本并入.tsv`](选本并入.tsv) |
| `汇编/蒙学/tangshisanbaishou.json` | 320 首（上游 `poems-tangshi.js` 的另一份选本，与上面那个 65 首/366 首的文件不是同一份） | 全部对上，挂 `tags: ["唐诗三百首"]`，选本那一份删除。逐条见 [`唐诗三百首并入.tsv`](唐诗三百首并入.tsv) |

| `近现/` | 41 首 | 3 首并回（欧阳修《生查子》→全宋词，魏学洢《核舟记》、荀子《劝学》→历代），12 首留原文件 |

### 唐/唐诗三百首/ 这一份怎么并的

底本目次是 `anthologies/tangshi300.json`（唐詩三百首注疏，掃葉山房石印本，56 条，只到卷三以后）。
选本 55 条与目次的对应关系不是逐条按序的，并的时候做了三件事：

- **分卷的几首拆开**。「長干曲四首」「塞下曲四首」在选本里是一条，在总集里是四条。按正文找同作者的整首记录、
  字头相接的串成一段，拆出来逐首并。只认正文不认题名——「塞下曲四首」在总集里叫「和張僕射塞下曲」，
  中段「月黑雁飛高」另有异文。
- **对不上号的按目次取总集**。骆宾王《在獄詠蟬・並序》的正文（「西陸蟬聲唱，南冠客思**深**」）与目次第 21 首
  （「南冠客思**侵**」）不同，按「选本与目次对不上时依总集」的口径，挂的是 `poet.tang.58000.json#3` 那条。
- **总集未收的按总集记载补录**。曹植《白馬篇》不是唐诗（它是 PR #43 把张冠李戴的《燕歌》改回来的），
  全唐诗只收李白的同名乐府，所以补录进 `三国/诗/poet.sanguo.json`；王昌龄《長信秋詞·其三》在总集里
  只有两条残缺的副本（一条作「暫將團扇共裴回」，一条悄悄丢了「暫」字），按《全唐詩》原貌补录一条。
  《春遊》那条总集只剩题注、没有正文，选本这一条留下不动。

## 怎么判同一首

沿用 `merge_anthologies.py` 的口径：正文（`t2s`、去标点）相似度 ≥ 0.8，或选本句子全部见于该记录。另加两条：

- **选本带序**：题名有「並序」时，第一段若不到全篇四分之一就是序，去掉再比。元结《賊退示官吏・並序》正文相似度只有 0.79，去序后能对上。
- **选本带前缀**：比对题名时剥掉「雜曲歌辭」「相和歌辭」这类乐府类目前缀，取前 4 字。「破山寺後禪院」对「題破山寺後禪院」靠的就是这条。
- **节选**：题名含「节选」时，正文是总集记录的前半段，按全本记并挂回原记录（白居易《村民苦寒（节选）》→《村居苦寒》）。

作者不同的一律两存，不做判断。

### 水墨唐诗这 4 首

四首正文都与全唐诗对不上，但**全唐诗确有这四首的记载**，所以不是「未收」，是数据集缺条目：

| 选本记录 | 处理 |
| --- | --- |
| 白居易《村民苦寒（节选）》 | 并回《村居苦寒》，正文取总集 |
| 杜甫《绝句三首》 | 补录「二十一人同入蜀，惟殘一人出駱谷。／自說二女嚙臂時，迴頭却向秦雲哭。」（总集《三絕句 二》之外别为一绝，选本把三绝混作一首） |
| 贺知章《晓发》 | 补录「故鄉杳無際，江臯聞曙鐘。／始見沙上鳥，猶埋雲外峰。」 |
| 杜牧《清明》 | 补录「清明時節雨紛紛，路上行人欲斷魂。／借問酒家何處有，牧童遥指杏花村。」 |

补录只取总集的书名/题名/传世名句作依据，**正文按总集的记载写，不采信选本的改写**——比如选本《绝句三首》有「杀刺吏」「秦云器」两处错字，补录时都没有带进来。挂 `tags: ["水墨唐诗"]`，`pos`、`prologue` 照选本记，便于回溯。补录的每条在 `选本并入.tsv` 里 `处理` 列写「新增」，`说明` 列写收录依据。

匹配口径因此加了两条：比对时抹平异体字（臯/皋），否则《晓发》对不上；重复补录按正文判重，脚本重跑幂等。

## 留下来的是什么

`近现/` 当时剩 35 首，其中 10 首是明清作品（唐寅《畫雞》、高鼎《村居》、袁枚《所見》、王冕《墨梅》、譚嗣同《潼關》…）。它们留下，是因为**明清诗那时没有总集**——`唐/诗/全唐诗/poet.tang.*` 只到五代，`历代/` 只有 海棠诗社语料补的那 5607 条，对不上正文。

这一条已经解决：`scripts/split_dynasty.py` 把 `历代/` 里的明清作品拆成 `明/诗/`、`明/词/`、`清/诗/`、`清/词/` 四部书，课本选目一并归位。见 [`历代拆分.md`](历代拆分.md)。

## 排版

`save()` 只替换真正改过的记录：原文每层的缩进宽度、每行的行尾空格都从原文量出来照抄。宋词那批每行尾部有一个空格，`唐/诗/全唐诗/poet.tang.*` 用三层缩进，元曲是单行紧凑格式——三种排版都能逐字节复现，因此一条改动只产生几行 diff，不会让整份文件重新排一遍。

## `tags: ["唐诗三百首"]` 混着三个来源，判断归属只认底本目次

`tags: ["唐诗三百首"]` 目前是三个来源打上来的，它们互有出入，谁也不等于底本：

| 来源 | 规模 | 情况 |
| --- | --- | --- |
| `汇编/蒙学/tangshisanbaishou.json`（上游 `poems-tangshi.js` 的另一份选本） | 320 首 | 逐条见 [`唐诗三百首并入.tsv`](唐诗三百首并入.tsv) |
| `唐/唐诗三百首/唐诗三百首.json`（上游 `poems-tangshi.js` 的 65 首） | 65 首，能对上的 60 首并作 tags | 见本文件上节 |
| 全唐诗自身爬取时打上的 | 余数 | 没跟任何目次比对过 |

前两份互有出入，两边都不能代表底本：

- 320 首那份有《行宮》《登鸛雀樓》《相思》《鹿柴》《靜夜思》《江雪》等底本目次第 1—170 首的作品，但那部分在 65 首那份里几乎一首都没有；
- 反之，65 首那份的曹植《白馬篇》、盧綸《塞下曲》、王昌齡《長信秋詞》等，320 首那份里也没有。

所以 **`source`（`sources` 字段）照旧保留，不做区分来源的细分标签**——
一首诗属不属于《唐诗三百首》只有一个是非题，来源是校对线索，不是归属。

判归属只认底本目次 `anthologies/tangshi300.json`（识典古籍《唐詩三百首注疏》，蘅塘退士编、章燮注，上海掃葉山房石印本），
用 `scripts/check_anthology.py --only tangshi300` 对齐。目次目前只抽到 56 条（卷一、卷二整卷挤成段落，标题切不准，宁缺毋滥）——
**56 条之外的部分仍是未核区**，挂着 tag 不等于核过。
