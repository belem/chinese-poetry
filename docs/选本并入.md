# 选本并入总集

`scripts/merge_selections.py` 的说明。逐条对照见 [`选本并入.tsv`](选本并入.tsv)，可随时重跑。

```bash
python3 scripts/merge_selections.py            # 预演
python3 scripts/merge_selections.py --apply    # 写回，并生成 选本并入.tsv
```

## 为什么并

选本是两百来首的精选视图，正文与总集重复。目录里留副本，同一首作品就有两份正文，勘误时两边都要改，改漏一处就漂。所以选本的正确定位是总集记录上的 `tags`，加上 `anthologies/` 那份目次。

四件事：

| 目录 | 原来 | 现在 |
| --- | --- | --- |
| `唐诗三百首/` | 65 首独立副本 | 能对上的 60 首挂 `tags: ["唐诗三百首"]`，剩下 5 首留原文件 |
| `水墨唐诗/` | 4 首 | 1 首并回（带 prologue），3 首按全唐诗记载补录成 `poet.tang.*` 新记录；目录删除 |
| `宋词三百首/` | 280 首 | 280 首全部在 `宋/宋词/ci.song.*` 找到同一首，加 `tags` 后目录删除（2026-10）。4 首清词与僻调此前合并时写下「总集未收」，实际库里有，只是正文有异文 |
| `近现/` | 41 首 | 3 首并回（欧阳修《生查子》→全宋词，魏学洢《核舟记》、荀子《劝学》→历代），12 首留原文件 |

`唐诗三百首/` 已经在 `docs/唐诗去重.tsv` 里记过一次（`全唐诗/唐诗三百首.json` 366 首那份），那是另一个文件。这个目录是上游 `poems-tangshi.js` 的 65 首，此前没并过。

## 怎么判同一首

沿用 `merge_anthologies.py` 的口径：正文（`t2s`、去标点）相似度 ≥ 0.8，或选本句子全部见于该记录。另加两条：

- **选本带序**：题名有「並序」时，第一段若不到全篇四分之一就是序，去掉再比。元结《賊退示官吏・並序》正文相似度只有 0.79，去序后能对上。
- **选本带前缀**：比对题名时剥掉「雜曲歌辭」「相和歌辭」这类乐府类目前缀，取前 4 字。「破山寺後禪院」对「題破山寺後禪院」靠的就是这条。
- **节选**：题名含「节选」时，正文是总集记录的前半段，按全本记并挂回原记录（白居易《村民苦寒（节选）》→《村居苦寒》）。

作者不同的一律两存，不做判断。

### 水墨唐诗这 4 首

四首正文都与全唐诗对不上，但**全唐诗确有这四首的记载**，所以不是「未收」，是数据集缺条目：

| 选本记录 | 处理 |
| --- | --- |
| 白居易《村民苦寒（节选）》 | 并回《村居苦寒》，正文取总集 |
| 杜甫《绝句三首》 | 补录「二十一人同入蜀，惟殘一人出駱谷。／自說二女嚙臂時，迴頭却向秦雲哭。」（总集《三絕句 二》之外别为一绝，选本把三绝混作一首） |
| 贺知章《晓发》 | 补录「故鄉杳無際，江臯聞曙鐘。／始見沙上鳥，猶埋雲外峰。」 |
| 杜牧《清明》 | 补录「清明時節雨紛紛，路上行人欲斷魂。／借問酒家何處有，牧童遥指杏花村。」 |

补录只取总集的书名/题名/传世名句作依据，**正文按总集的记载写，不采信选本的改写**——比如选本《绝句三首》有「杀刺吏」「秦云器」两处错字，补录时都没有带进来。挂 `tags: ["水墨唐诗"]`，`pos`、`prologue` 照选本记，便于回溯。补录的每条在 `选本并入.tsv` 里 `处理` 列写「新增」，`说明` 列写收录依据。

匹配口径因此加了两条：比对时抹平异体字（臯/皋），否则《晓发》对不上；重复补录按正文判重，脚本重跑幂等。

## 留下来的是什么

`近现/` 当时剩 35 首，其中 10 首是明清作品（唐寅《畫雞》、高鼎《村居》、袁枚《所見》、王冕《墨梅》、譚嗣同《潼關》…）。它们留下，是因为**明清诗那时没有总集**——`唐/诗/全唐诗/poet.tang.*` 只到五代，`历代/` 只有 haitang 补的那 5607 条，对不上正文。

这一条已经解决：`scripts/split_dynasty.py` 把 `历代/` 里的明清作品拆成 `明/诗/`、`明/词/`、`清/诗/`、`清/词/` 四部书，课本选目一并归位。见 [`历代拆分.md`](历代拆分.md)。

## 排版

`save()` 只替换真正改过的记录：原文每层的缩进宽度、每行的行尾空格都从原文量出来照抄。宋词那批每行尾部有一个空格，`唐/诗/全唐诗/poet.tang.*` 用三层缩进，元曲是单行紧凑格式——三种排版都能逐字节复现，因此一条改动只产生几行 diff，不会让整份文件重新排一遍。
