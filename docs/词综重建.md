## 为什么放 `汇编/`

《词综》是清人编的跨代词选（唐五代宋金元），跟《乐府诗集》《昭明文选》同类：跨代、
没有单一主时段，按 AGENTS.md 的选本落位规则进 `汇编/`，不并进某一朝的总集。
一卷一档，`卷N.json` 的 N 就是原书卷次，文件词典序即篇目次序。

## 字段

```
author     作者，照底本（底本抄错的按 authors/authors.json 归一，见勘误表）
dynasty    按作者查 authors/authors.json；查不到的留空（450 首，多是不见经传的宋元小家）
title      「词牌·首句」；底本原有小题的用小题（`菩萨蛮·题华州城楼`）
rhythmic   词牌（底本写作 `忆秦蛾`「菩萨鬘」「薄倖」的按通行名写，原字见勘误表）
subtitle   小题（有 title 里的小题时同一份，便于检索）
paragraphs 正文，一首一段（底本上下阕之间的空格照留）
notes      行内异文夹注（`(一作阑干)`、`一作。见` 之类），61 首有
tags       ["词综", "卷N"]
source_line 底本行号，便于回查
```

## 标题：`词牌·首句`

按 issue 里的规则：底本只有词牌时用「词牌·首句」，首句取正文开头的 12 个汉字（去标点），
开头那一句本身就落在 8~14 字区间时照原句（`苏幕遮·碧云天`、`雨霖铃·寒蝉凄切` 这类）。
底本 `·` 后面是小题的（`菩萨蛮·题华州城楼`、`青玉案·元夕`）直接沿用小题，不再叠首句。
`又` 条承上首的词牌与作者，`前题` 承上首的小题；两首以上同词牌同作者而底本没有小题的，
才补首句 —— 跟库内 `ci.song.*` 的做法一致（那边 277 首是 12 字首句、270 首是 7 字原句）。

## 底本的三种排法

底本卷首行的写法前后不统一，脚本按下面顺序试，认不出就报出来，不猜：

| 排法 | 卷 | 例 |
| --- | --- | --- |
| 分栏：`词牌[·小题]  作者` | 卷一～五、补遗多数 | `菩萨蛮·题华州城楼  昭宗皇帝` |
| 粘连：`词牌[小题]作者` | 卷六～三十 | `念奴娇赤壁怀古苏轼` |
| 粘连：`又` ＋ 小题 ＋ 作者 | 各卷都有 | `又黄州梦过栖霞楼苏轼` |

切分靠两张表：词牌表（库内 1626 个 `rhythmic` ＋ 有名词牌的正体与别名 ＋ 底本自己分栏卷的
左栏）和作者表（`authors/authors.json` ＋ 库内全部词作者，简繁两写；`SURNAME` 是姓氏表）。
底本把人名拆开抄的（`后主李煜` 的「李」、`韩亻屋`＝韩偓、`赵孟兆页`＝赵孟頫、`张癗`＝张埜）
先按作者表的纠正名再切一次。

## 正文里清掉的 OCR 残迹

底本把异文和注记都写成了行内符号，录入时一并抽出（不放正文，能读的进 `notes`）：

| 底本 | 例 | 处理 |
| --- | --- | --- |
| 括号夹注 | `玉阶(一作阑干)空伫立` | 抽出进 notes |
| `一作` ＋ 断点 ＋ 异文 | `还是一作。见？褪粉梅梢` | 抽出进 notes，正文恢复成「还是见」 |
| 只剩 `一作` | `情何限$衰柳` | 符号删掉、两侧补顿号 |
| `&` | `轻舟短棹西湖好&渌水逶迤` | 两侧是两句，改顿号 |
| `’X’` | `好一作、奴’为出一作、去’来难` | 引号里是异文，抽出进 notes |
| 半角 `,` `.` | `相思意.`、`飞絮,梦逐` | 改全角 |

改完正文里已无 ASCII 字符（`python3 scripts/check_structure.py` 的 ascii_residue 一项为 0）。

## 勘误表

[`词综勘误.tsv`](词综勘误.tsv)：90 条，逐条记底本行号与处理办法。

- **作者名**：11 条。`晃补之`→晁补之、`李耒`→李廌、`藤宗谅`→滕宗谅、`陈凝之`→陈与义、
  `张癗`→张埜、`赵孟兆页`→赵孟頫、`王亻屋`→王渥、`完彦`→完颜、`元如问`→元好问 等。
- **词牌**：1 条（`菩萨鬘`→菩萨蛮）。另外 25 处底本的异名／别名（`忆秦蛾`、`薄倖`、
  `柳色黄`＝石州慢、`调笑`＝调笑令、`渔父词`＝渔父、`黄金缕`＝蝶恋花……）是**底本就这么写的**，
  写盘时统一成通行词牌名，原字留在记录外，明细见 `docs/词综勘误.tsv` 与脚本里的 `TUNE_ALIAS`。
- **标题行未完全拆开**：78 条。行尾作者不在作者表里（`刘镇`、`潘元质`、`田不伐` 这类宋元小家的
  字号写法）、或整行被题注占住（`迈陂塘太和五年乙丑岁，赴试并州…`），脚本按 `SURNAME` 与
  词牌表兜底切开后仍对不上的，逐条列在这里，下一步人工核。
