## 为什么放 `汇编/`

《词综》是清人编的跨代词选（唐五代宋金元），跟《乐府诗集》《昭明文选》同类：跨代、
没有单一主时段，按 AGENTS.md 的选本落位规则进 `汇编/`，不并进某一朝的总集。
一卷一档，`卷N.json` 的 N 就是原书卷次，文件词典序即篇目次序。

## 字段

```
author     作者，照底本（底本抄错的按 authors/authors.json 归一，见勘误表）
dynasty    按作者查 authors/authors.json；查不到的留空（450 首，多是不见经传的宋元小家）
title      「词牌·首句」；底本原有小题的用小题（`菩萨蛮·题华州城楼`）
rhythmic   词牌（底本写作 `忆秦蛾`「菩萨鬘」「薄倖」的按通行名写，原字见勘误表）
subtitle   小题（有 title 里的小题时同一份，便于检索）
paragraphs 正文，一首一段（底本上下阕之间的空格照留）
notes      行内异文夹注（`(一作阑干)`、`一作。见` 之类），61 首有
tags       ["词综", "卷N"]
source_line 底本行号，便于回查
```

## 标题：`词牌·首句`

按 issue 里的规则：底本只有词牌时用「词牌·首句」，首句取正文开头的 12 个汉字（去标点），
开头那一句本身就落在 8~14 字区间时照原句（`苏幕遮·碧云天`、`雨霖铃·寒蝉凄切` 这类）。
底本 `·` 后面是小题的（`菩萨蛮·题华州城楼`、`青玉案·元夕`）直接沿用小题，不再叠首句。
`又` 条承上首的词牌与作者，`前题` 承上首的小题；两首以上同词牌同作者而底本没有小题的，
才补首句 —— 跟库内 `ci.song.*` 的做法一致（那边 277 首是 12 字首句、270 首是 7 字原句）。

## 底本的三种排法

底本卷首行的写法前后不统一，脚本按下面顺序试，认不出就报出来，不猜：

| 排法 | 卷 | 例 |
| --- | --- | --- |
| 分栏：`词牌[·小题]  作者` | 卷一～五、补遗多数 | `菩萨蛮·题华州城楼  昭宗皇帝` |
| 粘连：`词牌[小题]作者` | 卷六～三十 | `念奴娇赤壁怀古苏轼` |
| 粘连：`又` ＋ 小题 ＋ 作者 | 各卷都有 | `又黄州梦过栖霞楼苏轼` |

切分靠两张表：词牌表（库内 1626 个 `rhythmic` ＋ 有名词牌的正体与别名 ＋ 底本自己分栏卷的
左栏）和作者表（`authors/authors.json` ＋ 库内全部词作者，简繁两写；`SURNAME` 是姓氏表）。
底本把人名拆开抄的（`后主李煜` 的「李」、`韩亻屋`＝韩偓、`赵孟兆页`＝赵孟頫、`张癗`＝张埜）
先按作者表的纠正名再切一次。

## 正文里清掉的 OCR 残迹

底本把异文和注记都写成了行内符号，录入时一并抽出（不放正文，能读的进 `notes`）：

| 底本 | 例 | 处理 |
| --- | --- | --- |
| 括号夹注 | `玉阶(一作阑干)空伫立` | 抽出进 notes |
| `一作` ＋ 断点 ＋ 异文 | `还是一作。见？褪粉梅梢` | 抽出进 notes，正文恢复成「还是见」 |
| 只剩 `一作` | `情何限$衰柳` | 符号删掉、两侧补顿号 |
| `&` | `轻舟短棹西湖好&渌水逶迤` | 两侧是两句，改顿号 |
| `’X’` | `好一作、奴’为出一作、去’来难` | 引号里是异文，抽出进 notes |
| 半角 `,` `.` | `相思意.`、`飞絮,梦逐` | 改全角 |

改完正文里已无 ASCII 字符（`python3 scripts/check_structure.py` 的 ascii_residue 一项为 0）。

## 卷首记数与实收

底本每卷卷首有一行自记首数，写法前后三种，还有两卷根本没记数：

| 写法 | 卷 | 例 |
| --- | --- | --- |
| `类别＋数目＋首` | 卷一～三十 | `唐词六十八首`、`元词五十三首` |
| `（数量）＋类别` | 卷三十一、三十四～三十六 | `（六十九首）宋词`；卷三十四掉了「首」字，作 `（词五十七）宋词` |
| 只写类别 | 卷三十二、三十三 | `宋词`、`金元词` |

逐卷对账见 [`词综卷首记数.tsv`](词综卷首记数.tsv)（`python3 scripts/cizong_volcount.py` 重出）。
34 卷记数合计 **2064** 首，实收 **2251** 首，差 **+51**，分四类：

- **卷二十八 自记「元词二首」、实收 54 首（+52）**：底本把元人一段接在宋人之后 ——
  卷首写「元词二首」（李琳两首）之后没有另起「《词综》（卷二十九）」，
  赵文以下 52 首一路排下来，到 `苏武慢和冯尊师虞集` 才又出现卷首行。
  也就是说卷二十九自记的 52 首，正是这后一半。按底本分卷，不改。
- **卷七 +3、卷十四 +1、卷十六 +1、卷二十五 +1**：底本在记数之后又多排了「又」条，编者没算进去。
- **卷十七 −1、卷十八 −1、卷二十 −2、卷二十四 −1、卷三十 −1、卷三十五 −1**：底本并了「又」条或漏抄；
  卷三十五是卷末《玉漏迟》与卷三十四重出，底本抄了两遍（两份都留着）。
- **卷三十二、三十三**：底本自己没记数。

记数不改：这是清刻本编者自己写的数，与实收的差额是底本原貌，不在数据里补。

## 标题行：拆不干净的 77 行

[`import_cizong.py`](../scripts/import_cizong.py) 拆不开的 77 行（`docs/词综勘误.tsv` 里
「标题行未完全拆开」那一类），底本其实大多是齐的 —— 卡在词牌与作者撞字时切错了位置：
`四犯令侯` 的「侯」既是姓也可以是犯令的动词、`眼儿媚王` 的「王」既是姓也可以是小题的首字，
切分就把作者名切掉一半，或者整截当成了词牌。真实成因有两类：

1. **作者名被切半**（68 行）：`四犯令侯`（侯寘）、`柳梢青吴`（吴景奎）、`浣溪沙张`（张炎）、
   `满庭芳陈`（陈克）…… 名字那一半丢了，得按底本自身补回来；
2. **行内本来就有完整人名**（9 行）：`南柯子送淮漕向伯恭杨适`（杨适）、`青玉案和贺方回韵送伯固归吴中姚进道`（姚进道）、
   `迈陂塘  张炎`（分栏体，作者在后面），切分把小字题目与人名混在了一起。

[`cizong_heads.py`](../scripts/cizong_heads.py) 按底本自身取证逐条定案，明细见
[`词综标题.tsv`](词综标题.tsv)：

- 行内有作者表里认得的人名 → 取人名，余下的是小题；
- 只剩一个姓、底本此人又只此一首 → 这一段前后没有可承的「王」「陈」「杜」，名字是漏抄的，
  按《全宋词》该词归属补全（`眼儿媚王` → 王雱、`蓦山溪杜` → 杜良臣）；
- 同一人连出几首都只署姓 → 承上（`鹧鸪天许`「后庭花许」「夜行船许」「喜迁莺许」→ 许棐；
  `踏莎行洪`「瑞鹤仙洪」「齐天乐洪」→ 洪瑹；`满江红毛` 四首 → 毛滂）；
- **同一个字在不同地方不是同一个人**：`四犯令侯`「渔家傲侯」是侯寘的姓，而
  `朝中措元夕上潭帅刘共甫侯` 的「侯」也是侯寘，但 `风入松侯` 承的是它 —— 逐条看，不按字形套。

77 行里 **69 行已定案**（改作者 64 行，另 5 行重跑后自洽），还剩 8 行：
7 行的作者本来就对（`迈陂塘  张炎` 这类分栏体），只是解析器当时没认出，作者不动；
另有 1 行（`琴丝。一声声更苦，`）是底本把上一首的尾文串进了标题位，要动正文，留给对勘。

## 正文的问号

底本抄录时补的句读，末句多印成「？」：本册存正文的 1821 首里，正文共 **2133** 处问号。
其中相当一部分本来就是问句（`谁理商声帘外悄？`、`春去人间无路？`），不能一刀切成句号。

[`cizong_qmark.py`](../scripts/cizong_qmark.py) 按句子形态逐句判，明细见
[`词综问号.tsv`](词综问号.tsv)：

| 判法 | 处 | 例 |
| --- | --- | --- |
| 句中有疑问词（谁、何、怎、岂、多少、几许、争忍、肯把…） | 留 | `谁理商声帘外悄？`、`试问闲愁都几许？` |
| 句末是疑问收尾（否、未、几时、多少…） | 留 | `今在否？`、`春过二分能几许？` |
| 陈述句末印成问号 | 改「。」 | `多谢洛城人。`、`暖香惹梦鸳鸯锦。` |

改后正文剩 **675** 处问号（674 处判为问句、留着，1 处只有标点、记 `待核`）。

**这一轮按句子形态判，不是逐句对勘刻本。** 「有没有疑问词」是硬口径，`？` 与 `。` 的分别
最终还是得对着原刻本逐句定 —— 那一步留在下面「还没做的」第 3 条。

## 勘误表

[`词综勘误.tsv`](词综勘误.tsv)：90 条，逐条记底本行号与处理办法。

- **作者名**：11 条。`晃补之`→晁补之、`李耒`→李廌、`藤宗谅`→滕宗谅、`陈凝之`→陈与义、
  `张癗`→张埜、`赵孟兆页`→赵孟頫、`王亻屋`→王渥、`完彦`→完颜、`元如问`→元好问 等。
- **词牌**：1 条（`菩萨鬘`→菩萨蛮）。另外 25 处底本的异名／别名（`忆秦蛾`、`薄倖`、
  `柳色黄`＝石州慢、`调笑`＝调笑令、`渔父词`＝渔父、`黄金缕`＝蝶恋花……）是**底本就这么写的**，
  写盘时统一成通行词牌名，原字留在记录外，明细见 `docs/词综勘误.tsv` 与脚本里的 `TUNE_ALIAS`。
- **标题行未完全拆开**：77 条。行尾作者不在作者表里（`刘镇`、`潘元质`、`田不伐` 这类宋元小家的
  字号写法）、或整行被题注占住（`迈陂塘太和五年乙丑岁，赴试并州…`），脚本按 `SURNAME` 与
  词牌表兜底切开后仍对不上的，逐条列在这里。**已逐条核过**，做法与依据见上面
  「标题行：拆不干净的 77 行」与 [`词综标题.tsv`](词综标题.tsv)；这张表里这一行留着，
  是脚本每次重跑时的报告口。
