# 《元曲》里另存一条的词：《全宋词》那份留着

`scripts/dedupe_yuanqu_songci.py` 的说明。逐条判定见 [`元曲宋词去重.tsv`](元曲宋词去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_yuanqu_songci.py            # 预演
python3 scripts/dedupe_yuanqu_songci.py --apply --date YYYY-MM-DD
```

## 现状问题

`元/元曲/yuanqu.json` 是元人诗词曲的唯一总集，但其中几位（汪元量、王奕、仇远）本是宋末元初的词人，
《全宋词》里各有一份，词牌记在 `rhythmic` 上。《元曲》这份把同一首词题作诗题又收了一次，
而且**把词题塞进了 `rhythmic` 的括号里**、`title` 反而是空的：

```
宋/宋词/ci.song.18000.json#14   汪元量《望江南・忆江南》          54 字   ← 留
元/元曲/yuanqu.json#f13i6k      汪元量 rhythmic「望江南」title「幽州九日」 54 字   ← 删
```

## 判据（四条都要）

1. 作者同一人；
2. 正文 `t2s` 归一、去标点后相似度 ≥ 0.95（两读多是一字之差：`捻/拈`）；
3. 词牌主干相同 —— 两边都先去括号与「・」后缀（`八声甘州（题维扬摘星楼）` → `八声甘州`），
   再过别名表（`一剪梅/一翦梅`、`忆江南/望江南`）；
4. 匹配前**先按词牌筛一遍**：同一作者同一词牌往往有好几首，只比正文会在几首之间乱配
   （王奕《八声甘州》第一版就对上了他自己的《婆罗门引·忆叠山翁》，相似度 0.032）。

## 本轮结果

删 5 条：汪元量《幽州九日》《怀旧》《上阳宫里断肠时》、王奕《八声甘州（题维扬摘星楼）》、
仇远《金缕曲》。`yuanqu.json` 11595 → 11590 条，正文一字未改。

**没删的**：`宋江《念奴娇》` 与 `施耐庵《念奴娇》` —— 作者不同，是《水浒传》成书过程的归属异说，
按老口径两存。
