## 为什么不挂在某个朝代下面

与《史记》《三国志》《春秋左氏传》同理：《战国策》记西周至战国之事，是史部（《汉书·艺文志》
入「六艺略·春秋」类，与《国语》并列），不是一代之诗，也不是小说。`authors/authors.json`
里刘向的 `dynasty` 记「汉」，本文件 `dynasty` 记「先秦」—— 用的是「书中所记之事」的口径，
与 `史书/春秋左氏传/zuozhuan.json` 的「先秦」一致。

## 版式

题名作「戰國策·卷一 东周·秦兴师临周求九鼎」：卷次照底本（简体，含「卷一 东周」这种国别），
章题取底本原题，一章一条。

```
戰國策·卷一 东周·秦兴师临周求九鼎
戰國策·卷八 齐一·楚威王战胜于徐州
戰國策·卷三十三 中山·昭王既息民缮兵
```

- `author` 记「刘向」（西汉末编订，与 `authors/authors.json` 一致）。
- 不拆「某谓某曰」式的对话段，段序即底本行序，段内一字不动。
- 没有 `sources`（不写语料出处名，见 AGENTS.md）。

## 章头怎么切

底本一章起首的样子是「`○` + 章题 + 正文」，章题与正文同在一行，中间没有标点：

```
○秦兴师临周求九鼎秦兴师临周而求九鼎，周君患之……
```

切法只有一条：**题干首字重出** —— 第 1 个与题干首字相同的字，就是正文的起头。
底本 501 章里有 497 章走这条规则，切出来的章题与通行本《战国策》的篇题相合
（`秦兴师临周求九鼎`、`秦攻宜阳`、`苏秦始将连横`、`邹忌修八尺有馀`……）。

底本另有 4 类走不了这条规则的，逐条写死在脚本里：

| 底本 | 处理 |
| --- | --- |
| `○陈轸去楚之秦。` `○靖郭君善齐貌辨。` `○权之难齐燕战。` `○赵王封孟尝君以武城。` | 章题独成一行，下一行才是正文（`HEAD_ONLY`） |
| `○穰侯攻大梁侯攻大梁，乘北郢` | 章题脱一「穰」字，正文自「侯攻大梁」起（`SPLIT`） |
| `○昌国君乐毅为燕昭王合五国之兵而攻齐昌国君乐毅……` | 章题 17 字，超过重出规则的窗口，按题意切（`SPLIT`） |
| `○卫人迎新妇为人迎新妇，……` `○卫嗣君时胥靡逃之魏…○卫人迎新妇…` | 题头首二字就是正文前二字，按整段题头切（`SPLIT_TEXT`） |

上一版试过「最长可行切分」（从长到短试，取正文起头读得通的那一刀），501 章里错了 8 章
（题头被拉成正文的复写），已退回单一规则。

## 底本自身的毛病

**五处卷题被排进了上一章的行尾。** 卷二 西周、卷十 齐三、卷十七 楚四、卷十八 赵一、
卷二十五 魏四这五卷的卷题没有顶格另起，而是接在上一章末句之后：

```
……是以遣之也。’”卷二 西周
```

照录时先把行尾的卷题摘出来，剩下的当正文；卷题本身改用它做卷次。

**一处下一章的 `○` 排在上一章行尾。** 卷一《谓薛公》末句 `……齐王谁与为其国？”○齐听祝弗`
后面直接接下一条的 `○`，切开后上一章行尾多出一个 `○`，去掉。

**三处叠句号。** 卷九「是天下以燕赐我也。。」、卷十「齐其闻之矣。。」、卷十九「大王不好人。。」，
各收敛成一个。

**一处行内空行。** 底本的行是排满的，除卷题与章题里的全角空格外，正文里没有空格。

**`──` 两处。** 卷十三「以惴惴之即墨──三里之城，五里之郭──敝卒七千」、卷十七
「而李园女弟──初幸春申君有身，而入之王──所生子者」的破折号是底本的夹注记法，照录。
`scripts/check_structure.py` 的 `box_drawing` 只查 U+2500–U+257F 里的制表符号与 U+FFFD，
本文件用的 U+2500 连写不在其中；`先秦/孟子/mengzi.json` 的 `──` 已被同一条规则报过，属已知。

## 未编码生僻字的两种记法

底本用了两套写法标未编码的字：

- `{…}`：`{殸车}`、`{亦水}`、`{艹陵}`、`{苻廾}`、`{股目}`，这是全库既定的写法（AGENTS.md 2b），照录；
- `<…>`：`<广鼻>`×4、`<黄重>`×3、`<吾午>`×2、`<户卯>`、`<鱼卷>`、`<口夭>`、`<马戋>`、`<鸟旗>`，
  共 8 个字头 14 处。这不是全库的写法，照 `{…}` 改写成 `{广鼻}` 等，字不补。

底本另有 5 个私用区码位：U+E1E2（卷一「庐、\ue1e2在其北」）、U+E844×2（卷五「周\ue844谓王曰」）、
U+E859×2（卷三十「史\ue859」）。前四个在《东周列国志》同段已被定为「犴」「最」（`docs/名著增补.md`），
第五个是「史鰌」，照那个结论写成 `{犴}`、`{最}`、`{鰌}`，`{…}` 的写法按 AGENTS.md 2b。

## 与库内旧稿的关系

**`汉/诗/poet.han.json` 的两条刘向补录删掉。**

- 「战国策·乐毅报燕王书」即本文件卷三十《昌国君乐毅为燕昭王合五国之兵而攻齐》的后半，
  后者把燕惠王让乐毅的那段话与乐毅的回书排在一章，前者只是回书。
- 「战国策·赵且伐燕」在底本里只剩「赵且伐燕，苏代为燕谓惠王曰」一句残文（卷三十一 燕三），
  通行本钱谦益覆宋本那一章不在本底本里，不臆补，这份单条也不再留。

**`汇编/古文观止/卷四戰國文.json` 的 14 篇国策文正文删掉**，只在
[`古文观止·选目.json`](../汇编/古文观止/古文观止·选目.json) 留条目，`记录` 改指本文件的对应章。
