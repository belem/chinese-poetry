`scripts/dedupe_quanmingshi_pairs.py` 的说明。逐条见 [`全宋诗散卷重出.tsv`](全宋诗散卷重出.tsv)：

```bash

python3 scripts/dedupe_quanmingshi_pairs.py               # 预演
python3 scripts/dedupe_quanmingshi_pairs.py --apply --date YYYY-MM-DD \
```

## 这一批是什么

前两批（[全宋诗全同重出](全宋诗全同重出.md) 31 条、[全宋诗选本副本](全宋诗选本副本.md) 62 条）之外，
《全宋诗》里同一人的两条散在两个卷里、**题名各异**的那些：组诗的《其N》与单篇
（朱熹《雲谷二十六詠 桃蹊》／《桃溪》）、释子的《偈頌 其N》与《頌古 其N》
（釋如淨《偈頌三十八首 其九》／《頌古五首 其一》）、《詠懷 其一》与《感懷》。

题名对不上，只能靠正文判：

1. 正文 `t2s` 归一去非汉字后**等长**；
2. 只有一处出入（相邻的一字之差算一处 —— `明/名`、`玄/虚` 挨着的那两处是一处）；
3. 那一字之差查过识典古籍：两读皆有 → 异体；只有一读 → 讹字，删重复的一条；
   查不出 → 两存；多字出入、长度不同 → 两存（组诗拆条、编次不同、两份录文都在这一类里）。

作者不同的不动（归属异说），只有 `郊廟朝會歌辭` 例外 —— 那是乐辞的汇编署名，不是作者：
同一首乐章在几种仪式歌辞里各收一次（《攝事十三首 太祖室用《大定》》／《太常樂章三十首 酌獻第五室奏大定之舞曲》），
识典古籍里乐章名与被祭的室一一对得上，正文逐字相同即同一首。
