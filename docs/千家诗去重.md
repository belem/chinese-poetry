# 《千家诗》并进总集时留下的副本

`scripts/dedupe_qianjiashi.py` 的说明。逐条判定见 [`千家诗去重.tsv`](千家诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_qianjiashi.py            # 预演
python3 scripts/dedupe_qianjiashi.py --apply --date YYYY-MM-DD
```

## 现状问题

`宋/诗/千家诗/qianjiashi.json` 是选本（五绝／五律／七绝／七律，226 首，一条一首，带篇题）。
2026-10 按「选本不占目录、占标签」并进 `唐/诗/全唐诗/`、`宋/诗/全宋诗/` 时，
**总集里的副本没清干净**：同一首在总集里还躺着一条，而选本这份从头到尾没有一个 `tags`。

```
宋/诗/千家诗/qianjiashi.json  （唐）孟浩然《春眠》        ← 留（这本书收了哪些）
唐/诗/全唐诗/poet.tang.7000.json#916 孟浩然《春曉》      ← 与选本逐字相同的副本
```

唐诗三百首、水墨唐诗那两套并进总集时打得齐全，千家诗这套没做，所以这一批补上。

## 与 `汇编与诗去重` 的取舍相反

[`汇编与诗去重`](汇编与诗去重.md) 删**补录**、留选本：那里选本是带底本的分卷本（《古文观止》卷五漢文），
补录是 `poet.*` 这种没有版本信息的爬取稿。这里反过来：`qianjiashi.json` 只是选本目次，
删了就没法回答「千家诗收了哪些」；总集那条才是副本。所以**删总集那条，选本整本书不动**。

## 判据（五条都要）

1. 正文逐字相同（`t2s` 归一、去非汉字后整篇相等）—— 异文一律两存，不删；
2. 选本那条带 `chapter`（篇题）；
3. 总集里这一首只有一条与选本逐字相同 —— 两条都是总集的（《登鸛雀樓》朱斌／王之渙、
   《答人》太上隱者／太上隱君、《尋隱者不遇》孫革／賈島），删哪条都是替古人定案，一条不动；
4. 那条没挂 `千家诗` tag（挂了的说明并进去了）；
5. 那条最多带 3 个**题材／课本**标签（`古诗三百首`、`唐诗三百首`、`水墨唐诗` 这类选本标签不算）。
   「写景」「思乡」「三年级下册」「小学古诗」在选本那份上没有，删了就是丢信息，留着。

正文一个字没改。`check_structure.py --files-from-diff HEAD --baseline-from HEAD`：没有新增问题。

## 递进数据里的两件事

- **《全宋诗》里 `poet.song.255000.json` 整个文件是选本并入的**：300 余首「古诗三百首」，
  篇名多作「饮湖上初晴后雨（其二）」这种带括号序号的并入选本写法。按第 5 条这一批一条不删，
  该由「选本并进总集」（`docs/选本对齐.md`）那条线统一处理。
- **选本的篇题与总集的诗题常常不是一个**（《登山》／《題鶴林寺僧舍》、《春眠》／《春曉》、
  《偶成》／《秋日成詩》、《宮詞》／《廷試》）。判重只认正文，不认题名；
  题名差异本身是选本改题，不是错。
