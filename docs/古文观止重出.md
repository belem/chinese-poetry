# 《古文观止》一本之内的同题篇目

`scripts/dedupe_guanzhi_dup.py` 的说明。逐组判定见 [`古文观止重出.tsv`](古文观止重出.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_guanzhi_dup.py            # 预演：逐组打印
python3 scripts/dedupe_guanzhi_dup.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 现状问题

`汇编/古文观止/` 按卷分文件（`卷一周文.json` … `卷十二明文.json`，另有补编 `古文观止·补.json`）。
同一篇被排进两处的有 20 组：补编 18 篇与正编各卷重（《归去来兮辞》《滕王阁序》《报任安书》……），
《郑伯克段于鄢》卷一、卷三各一条。

## 判据：逐字见于保留那条、且不到它的一半

「同题的一节」才是副本。20 组里过这条线的只有两条：

| 组 | 补编 | 正编 | 逐字见于 | 为什么没删 |
| --- | --- | --- | --- | --- |
| 齊桓下拜受胙 | 90 | 102 | 是 | 「不到一半」不满足；正编另多「夏，会于葵丘，寻盟，且修好，礼也」 |
| 祁奚請免叔向 | 172 | 334 | 是 | 补编那本**丢了开头一段**（栾盈出奔楚…），留着它是那段正文的唯一出处 |

只比相似度更不行：补编摘的常是正文、正编还多出序或评，一段缺席就把相似度拉到 0.77
（《归去来兮辞》339／537 正是这样）；题同文异的又能低到 0.02（《治安策》398／5826）。

## 其余 18 组：两存

- **补编摘正文、正编还多出序或评**：《归去来兮辞》（正编多一整段序）、《送杨寘序》（补编多 13 字）、
  《谏太宗十思疏》《滕王阁序》《潮州韩文公庙碑》（正编夹「望国一作」「一作思国」这类注）、
  《宫之奇谏假道》（正编多卜偃对童谣、灭虢执虞公一节）。
- **题同而文不同**：《六国论》（苏辙 vs 苏洵）、《沧浪亭记》（归有光 vs 苏舜钦）、
  《子产却楚逆女以兵》（补编配的是《徐吾犯之妹美》）、《吴许越成》（补编配的是「吴子使来儆师伐齐」一段）、
  《郑伯克段于鄢》卷三那条是《穀梁传》的经解，与卷一《左传》本两回事。
- **补编的节本，正文各自独立**：《屈原列传》《报任安书》《治安策》《徐文长传》《青霞先生文集序》。

## 这一批实际做了什么

**删 0 条**，把《古文观止》的目次整理成一份
[`古文观止·选目.json`](../汇编/古文观止/古文观止·选目.json)：260 条，卷次 / 篇题 / 作者 / 记录 id。
它是后面几轮删重出篇目时的兜底 —— 删正文之前，得先有「这本书收了哪几篇」这层信息。
