# 《全唐诗》↔《全宋诗》作者不同的重出

`scripts/dedupe_tang_song.py` 的说明。逐组判定见 [`全唐诗全宋诗异作者.tsv`](全唐诗全宋诗异作者.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_tang_song.py            # 预演：分类、样例与条数
python3 scripts/dedupe_tang_song.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

两书正文前 16 字相同（`t2s` 归一、去非汉字）的组 **882** 个（清理前 976）。它们不是同一种东西：

| 判定 | 组 | 处理 | 本轮 |
| --- | --- | --- | --- |
| 同作者 | 576 | 《全唐诗》按体类卷／作者卷各排一遍造成的重出，属 `dedupe_tang.py` | 不动 |
| 一人多名 | 28 | 同一人的两种名讳、尊号与本名、法名前加「釋」 | 删《全宋詩》那条 |
| 一人误收 | 26 | 甲的诗混进乙的集子 | 删《全宋詩》那条 |
| 归属异说 | 33 | 两说并传，宋人笔记里就不定案 | **一条不动**，互挂 `tags` |
| 一卷多作者 | 32 | 组里同时含两三位作者（编排卷、联句） | 不动 |
| 待核 | 187 | 识典古籍检索也定不了归属 | 不动，列在 TSV |

**跨书互见不算重复的前提是有归属可判。**《昭明文选》收《古诗十九首》那是编书方式，
两书都收同一首而署了两个人，就不是编书方式了 —— 至少有一部书收错了。

## 三条判据

1. **同一人，两种写法**：張泌／張佖、李貞白／朱貞白、韓琮／韓綜、包佶／包信、雍陶／雍鳴、
   廖匡齊／廖齊（避讳省字）、曉巒／釋楚巒（法名前加「釋」）、宋太祖／趙匡胤、
   韓王從善／李從善（封爵与本名）、江景防／江景房、張隱／張隠、來鵬／來氏、越溪楊女／楊氏、
   李節度姬／李氏。删《全宋诗》那条。
2. **一人误收**：唐彥謙 22 首混进戴表元《剡源集》（《剡源文集》《剡源戴先生文集》
   《四明詩萃》与《御定全唐詩》两收，诗归唐彦谦）；朱存《金陵覽古》组诗记在杨备、杨修名下
   （《景定建康志》《六朝事跡編類》明题朱存）；杜牧《金陵》记在梅尧臣名下（《景定建康志》
   卷三十七明题杜牧）；曹松《贈廣宣大師》记在范仲淹名下；韦应物、权德舆的两首记在晏殊、
   强至名下。删《全宋诗》那条。
3. **归属异说一律不删**：《宮詞》百首王珪／花蕊夫人（《華陽集》系王珪，《全唐詩》卷七百九十八
   系花蕊夫人，《三家宮詞》《兩宋名賢小集》《石倉歷代詩選》皆题王珪）；《步虛詞》宋徽宗／
   杜光庭（《太上黃籙齋儀》系杜光庭，《玉音法事》《道門通教必用集》并收）；《金丹詩訣》
   陳楠／青霞子（《龍虎元旨》托名青霞子、《內丹祕訣·金虎白龍詩》系张果、《翠虛篇》系陈楠）；
   宋高宗题画诗与权德舆、韦应物、白居易、孟郊。两条并存，互挂 `tags` 一条「一作某《某题》」。

## 删哪一条

统一删《全宋诗》那条：这一批的组里《全唐诗》那条题名更全、`notes`／`prologue` 更多，
而《全宋诗》大量是宋人总集（《宋詩紀事》等）转抄后按作者编次的二次文献。
`tags` 是数据集自己打的，不作为保留依据。

## 没做的

- **同作者 576 组**不动：那是《全唐诗》自己的两套目录（乐府／非乐府）造成的，
  `dedupe_tang.py` 已经处理过一轮；两书之间剩下的这批要按《全唐诗》本书的重出规矩再清一次。
- **一人多名还有 90 组**（釋延壽／延壽、釋贊寧／贊寧这类）没删：作者名一侧带「釋」、
  另一侧不带，同一个人，但《全宋诗》是按「釋延壽」编次的一组诗（《山居詩》六十余首），
  与《全唐诗》的「延壽」条正文能一一对上；这批量大且成组，单独一批做。
- **187 组待核**：识典古籍 211 次检索覆盖 219 组，多数只能查到一两种总集，
  两说并存的（《全宋詩》据《宋詩紀事》、《全唐詩》据《御定全唐詩》）无法定案。
  逐组列在 TSV 的 `review` 行，下一轮再核。

## 结果

| 指标 | 清理前 | 清理后 |
| --- | --- | --- |
| 两书正文前 16 字相同的组 | 976 | 828 |
| 其中作者不同 | 250 | 187（+33 组两存互挂） |
| 删《全宋诗》记录 | — | 54 |
| 互挂 `tags` 的组 | — | 33 |
| `check_structure.py` missing_char | 6024 | 6024 |
| `check_structure.py` shi_line_length | 151 | 151 |

删的都是整条记录，正文一个字没动；`check_structure.py` 前后没有新增问题。

被改过的文件在 `docs/progress/` 里记一条「删了哪条、留哪条」的 fixes，`status` 不动 ——
删重复不是逐字对勘，不能因此算 `clean`。
