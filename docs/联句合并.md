# 《全宋诗》联句并条

`scripts/merge_lianju.py` 的说明。逐条判定见 [`联句合并.tsv`](联句合并.tsv)，可随时重跑：

```bash
python3 scripts/merge_lianju.py                                   # 预演：逐组打印取舍
python3 scripts/merge_lianju.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

《全宋诗》按作者编次，一首联句在几位作者名下各出一次，正文几乎一字不差。
`check_tree.py` 把《全宋诗》那 1412 条「异作者·异题」一直记成「需人工判」，
其中一半就是这一件事。

它既不是异文，也不是归属异说 —— **作者都对，只是同一首被拆开了**。
宋词、全唐诗那边用的「两存 + 互挂 `tags` 一作某」对它不成立：挂五次 tags 还是五份正文。

## 形制（2026-10-29 与维护者对齐）

一条记录代表一段文献，几位作者同赋，就不是「某一位的诗」：

```json
{
  "author": "趙概/歐陽修/王洙/韓絳/王珪",
  "title": "來燕堂與趙叔平王禹玉王原叔韓子華聯句",
  "paragraphs": ["賢侯謝郡歸，從游樂吾黨。", "…"],
  "notes": "聯句：趙叔平（概）、歐陽永叔（修）、王禹玉（珪）、王原叔（洙）、韓子華（絳）同賦。《永樂大典》卷八百二十三記…"
}
```

- `author` 写联句署名串，次序取原书篇题；
- `title` 取篇题最完整的那一读；
- `paragraphs` 一字不动；`notes` 记篇题信息与校勘；
- **不写句下署名。** 联句的「范。」「歐。」「張。」只见于《皇朝文鑑》《宛陵先生集》
  等几种底本，多数别集只有本文；逐句重新分配既没有统一底本，也无法逐句核实，宁缺勿滥。
  并条时若保留读的末尾带一行只有「某。」的署名残留（薛田本的「田。」），一并剔掉 ——
  认的只有「一个字＋句号」这一形，别的一概不碰。

## 删哪几读

| 情形 | 判据 | 本轮 |
| --- | --- | --- |
| 只存作者名 | 正文原作「無正文。」（原书只存名、正文见另一条） | 2 |
| 正文一字不差 | `t2s` 归一后逐句相同（巖／岩、憩／憇、惬／愜 这类异体不算差异） | 6 |
| 只差异体字 | 逐句不同处全是异体、正俗字（凉／涼、窻／窗、鴈／雁、柳／桞） | 2 |
| 等长而有讹字 | 取识典古籍能证实得更多的那一读，讹字写进 `notes` | 16 |

「有讹字」那 16 读都是同一首的另一份录文抄错了字（「鑪治」应为「鑪冶」、
「酬枕」应为「醉枕」、「間日」应为「閒日」、「虹霞」应为「紅霞」、「土簁」应为「土培」……），
取哪一读的依据逐组写在 `notes` 里。

后两类都不是「两读都传世」的异文：另一份录文是把同一个字抄错了（形近字），
所以取识典古籍能证实的那个读法，删掉抄错的。逐组依据都写在脚本的 `note` 里，
落进 `docs/联句合并.tsv`。

几条要留意：

- **《聯句》五读是一首，不是五首。** 這首詩在《全宋詩》裡分別掛在梅堯臣、韓絳、韓維、杜衍、
  謝絳五個人名下，題名一律只作「聯句」，看不出是哪一首。查《宛陵先生集》卷十一（四部叢刊
  景上海涵芬樓藏明刊本）卷末有一組「聯句附」，第一首即此篇；影印本題署只到卷目、**沒有篇題**，
  所以并条后 `title` 写作「聯句附（題名原闕）」而不另拟题名 —— 拟出来的题名不是古籍里的东西。
  記「謝少卿」「王子」的明萬曆本、《宛陵集》四庫本都是句下署名「謝少卿」「絳」「維」「衍」
  的残迹（五个人正是谢绛、韩绛、韩维、杜衍、梅尧臣），韩绛本正文里夹的「堯臣」二字同理，
  并条时剔掉。
- **「晚凉」是讹字，已改回底本的「曉凉」。** 《宛陵先生集》四部丛刊影印本卷十一「聯句附」首叶
  （识典古籍第 35 页，右半叶第二行）明作「古木含清吹，池上增曉凉」；《宛陵集》四库本影印同。
  各条旧文都从「晚凉」来，只有四库本经识典古籍整理后的文本作「晚凉」，是整理时认错字形。
  底本既在，「曉」「晚」不必两存，第三批已逐字改回「曉」。
- **谢绛名下的四首，与梅尧臣名下只差通用异体字。** 「順途／順塗」「芳罇／芳樽」「鴻雁迴／鴻雁回」
  「張絃／張弦」「夢幻慙他刼／夢幻慚他劫」都是异体、通用字，不是异文；玉麈尾一首谢绛本另作
  「夫之善談道」「況託懷袖好」「常許助閑放」「復屈驅虻蚊」，《宛陵先生集》卷十一作「夫子」
  「况」「嘗許」「蝱蚊」，是形近讹字。
- **泛汝聯句：三读里只有《南陽集》能证。** 《南陽集》卷二（韩维集，四库本，影印本可看）
  有全篇四十句，作「緍水薦囦鱗」「賢俊畢珪組」「所求義與比，要在身不污」，与韩维本合；
  韩维本这一句讹作「抰水薦抸鱗」，辛廱本讹作「稏鱗」，孫永本此句是对的但另有「雲煙／雞黍／
  紫筍／異珪組／身不汙」五处通用异体。所以正文取韩维本、**逐字改回《南陽集》可证的
  「緡水薦囦鱗」六个字**（`GROUPS` 里 `fixes={'抰': '緡', '抸': '囦'}`），别字不动。
  上一轮说「韩维本 400 字、辛廱本 399 字」是记错了：三读都是 40 句 480 字，差异只在字面。
- **「同题但不同篇」的两组别混进来。** 《冬夕小齋聯句寄梅聖俞》（歐陽修／陸經，梅堯臣有
  《依韻和永叔子履冬夕小齋聯句見寄》—— 是**答诗**，与联句本文不同韵脚）、《冬夕會飲聯句》
  （梅堯臣与刘敞等）都不在这批里；前者一篇已在第一批按「歐陽修/陸經」并过。
