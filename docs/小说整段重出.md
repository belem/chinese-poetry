# 章回小说里整段抄了两遍

`scripts/dedupe_novel_repeat.py` 的说明。明细见 [`小说整段重出.tsv`](小说整段重出.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_novel_repeat.py            # 预演
python3 scripts/dedupe_novel_repeat.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

`清/小说`、`明/小说` 的底本是把影印本按页切分的，跨页处偶尔整段重出：

```
清/小说/红楼梦/hongloumeng.json 第22回 paragraphs[45..47]   ← 留
同上                          paragraphs[49..51]   ← 删（与 45–47 逐字相同）
```

第 22 回贾政看灯谜，惜春那首「朝罷誰攜兩袖煙」的诗抄了两遍，第二遍还紧接着引了
「光陰荏苒須當惜，風雨陰晴任變遷」一句，是同一个人的灯谜被摺了两页。

## 判据

**同一回里连续 ≥3 段、逐字相同**，且重复的两处被剧情行文隔开（`dup - first ≥ 3`）。

这条卡得紧是有原因的：

- 只比同一回 —— 第 1 回、第 5 回都出现「假作真時真亦假」，那是小说里两次出现，不是重复。
- 要求「连续 ≥3 段」—— 章回小说的段落是分诗行的，一首绝句就占 2–4 段，
  单段重复多半是叠字或引文。
- 要求两处不相邻 —— 同一个人把同一首诗念两遍（中间夹「又念道」）是原文如此，
  那种两处紧邻，`dup - first` 正好等于段数。

## 结果

| 指标 | 清理前 | 清理后 |
| --- | --- | --- |
| 整段重出处 | 1 | 0 |
| 红楼梦第 22 回段数 | 56 | 53 |
| `check_structure.py` missing_char | 5953 | 5953 |
| `check_structure.py` shi_line_length | 151 | 151 |

只删了重复的那一遍，正文一个字没改。同一回里重复的短引文（哪两句诗在五个回目里都出现）
不算 —— 那是小说本身的重复用语，不是抄重。
