# 《千家诗》按 `reference/千家詩.txt` 勘正

2026-11 一次整体勘正：`宋/诗/千家诗/qianjiashi.json` 的篇题、作者、正文全部按
[`reference/千家詩.txt`](../reference/千家詩.txt) 重写，不再沿用旧库的爬取稿。

## 为什么整本重写

旧稿与底本不是「个别错字」的关系，而是三个层面的偏差：

- **误收**：旧稿末二首《送天師》（朱權）、《送毛伯溫》（明世宗）底本没有（明人七律，两首都不是《千家诗》的篇目），删；
- **串行**：旧稿五律《攜妓納涼晚際遇雨》两条、七律《中秋》《中秋月》一组的题与作者整体错位一格，
  连带《題臨安邸》《冷泉亭》《西湖》三首七绝的作者与正文也互相串了（林升／林洪／林稹混在一起）；
  逐条改不如按键位重建；
- **底本有序**：底本是一本有 224 个篇题的书（五绝 39、五律 45、七绝 94、七律 46），
  旧稿 219 条把「其一／其二」合成一条（宫词、曲江对酒、携妓纳凉、秋兴八首、雪梅），篇题则是爬取稿的并合写法。

因此本次以底本为准逐首重建：顺序、分卷、篇题、署名、正文、夹注全部照底本，一字不改。

## 结构性约定

- 分卷用 `paragraphs[].type`（五言絕句／五言律詩／七言絕句／七言律詩），沿用组诗的 `subchapter` 惯例：
  底本标作「其一／其二」的两首（`宮詞`、`曲江對酒`）收成一条，带 `subchapter`；
  底本各自单列的（`攜妓納涼晚際遇雨其一／其二`、四首《秋興》、兩首《雪梅》）仍是各自独立的条目，篇题照底本。
- 夹注（底本圆括号里的注、异文、注音）**照录**，不删：异文本身是底本的读法记录（「一作某人《某题》」的处理同理）。

## 没照底本改的两处

凡底本读法与通行本不同的地方，一律照底本 —— 《旅夜書懷》「星隨平野闊」、《秋浦歌》「離愁似箇長」、
《落花》「妒花風雨便相摧」、《長安秋望》「雲物凄凉拂署流」、《歸隱》「紫陌縱榮爭及睡／朱門雖貴不如貧」、
《雪梅》「騷人擱筆」、《上元應制》「仙臺」「霑周宴」等等，都留着 —— 这些是版本异文，不是讹字。

例外只有底本自身的**排印/录入瑕疵**（不动正文，改动只涉及排版）：

1. `### 破山寺後禪院 常 建`、`### 三月晦日送春 賈 島` 两条目，题与作者之间漏了分隔符 `/`，
   按体例补成 `/ 常建`、`/ 賈島`（否则会被读成一个叫「建」「島」的作者）；
2. 同两条与「曲江對酒其一／其二」「攜妓納涼晚際遇雨其二」的署名「杜 甫」「常 建」中间的空格、
   《詠史》夹注里的半角 `?` `!`，按全集体例改成「杜甫」「常建」与全角标点 —— 只动空白与标点；
3. 文末 `〔全文完〕` 是排版标记，不是正文，不抄进数据。
