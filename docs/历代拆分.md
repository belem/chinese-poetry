## 为什么拆

`历代/` 是 haitang 补录的一锅烩：5607 条，朝代只记在 `authors/authors.json` 里，每条挂
`"sources": ["haitang"]`。明清作者的作品有 2436 条沉在这里——唐寅、袁枚、龚自珍、纳兰性德
都在这儿，想「取明清诗」得先 join 作者表。这与「一部书一个目录」的约定冲突。

第一轮（2026-08）只拆明清：明人 492 → `明/`，清人 1091 → `清/`，元人 251 追加进《元曲》。
顶层目录改成 14 个朝代目录后（见 [`目录结构.md`](目录结构.md)），剩下的也全部按作者朝代拆开，

是书名），再判词（有 `rhythmic` 或题名首段是词牌），其余为诗。

还有 **177 条搬不走**：作者不在 `authors/authors.json` 里，记录也没有 `dynasty` 字段——

作者表补上这四行之后重跑脚本即可；在那之前它们随 `历代/` 目录一起下线，正文仍留在 git 历史里。

**元人不另建书。** 《元曲》已经是元人作品的唯一总集（11415 条），历代里那 324 条元人作品
若另立一部，同一批作者就有两部书。比对正文后 4 条已收（张养浩《咏江南》、张可久《风入松》、
赵禹圭《折桂令·题金山寺》、王实甫《中吕·十二月过尧民歌》——最后一条《元曲》记在王德信名下，
是同一人的两种署名），未搬，其余 251 条追加。

**宋人也不另建书。** 宋诗有 `poet.song.*`，宋词有 `ci.song.*`，历代里那 121 条宋人作品是补录。

## 诗还是词，怎么判

先看记录本身，再看形式，最后才看内容：

1. 有 `rhythmic` 字段 → 词
2. 题名「<词牌>・<题目>」且首段在常用词牌、曲牌表里 → 词（杨慎《临江仙》、唐寅《雨打梨花深闭门》属于这种，标题里看不出牌名，靠首句长短句才认得）
3. 句长 3~7 字交错（词的长短句）→ 词；句式整齐的五言、七言 → 诗
4. 题名首段是书名（`史记·…`、`红楼梦·…`、`论语·…`）→ 文，不搬

题名里「其一」「二首」这类分段不是词牌，脚本里单列了一份噪声表，否则《秋怀诗四首·其一》会被当成词。

按这四条，经文（论语、孟子、左传、红楼梦、三国演义、水浒传、西游记、幽梦影、声律启蒙、随园食单、
聊斋志异、陶庵梦忆……的篇目）一律判文：题名首段是书名（`楚辞·…`、`庄子·…`、`礼记·…`），
或者作者是经史子集的作者（老子、释迦牟尼、姬昌、子思……这些人在作者表里没有行，记录常被挂到别人名下）。

## 近现/ 怎么归位

两份文件（`元明清詩.json` 8 首、`近现代诗.json` 41 首）去掉重复的 3 首后是 45 首，与目标总集比对
（同作者、正文相似度 ≥ 0.6）：

- 戚继光《马上作》→ 并入 `明/诗/poet.ming.json` 的 `tags: ["课本"]`
- 其余 44 首总集未收，按体裁拆成 `近现/现代诗.json`（2 首，余光中《鄉愁》、艾青《我愛這土地》）与
  `当/poet.dang.json` 与 `当/ci.dang.json`（43 首，格律体；目录重构后历代里的当代作品也并进这两份）
- 《江南》《長歌行》（漢樂府）与汤显祖《遊園》也没对上千古总集里现成的那一条——先秦汉魏的乐府没走
  这套相似度比对，汤显祖那条是《牡丹亭·惊梦》的曲文，不是词
