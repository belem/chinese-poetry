## 为什么放在朝代目录下

`docs/目录结构.md` 第一条原则是「目录按一部书切」，第二层才是书。四部书的作者朝代没有争议
（罗贯中、施耐庵、吴承恩是明人，曹雪芹是清人），按作者朝代落位即可；不需要另立「名著」这个
按名气切的维度——否则同一部书迟早会有两份正文。

## 字段

沿用 `docs/目录结构.md` 的记录契约：`title`、`author`、`dynasty`、`paragraphs`、`id`。
没有 `sources`（不写语料出处名，见 AGENTS.md）。

题名格式是「第N回　回目」。《三国演义》的嘉靖本不分回、只分则（一卷若干则），故作「第N则」。

## 底本各自的坑

**《水浒传》是这批里最脏的。** 识典这份容与堂本按定长（26–30 字）折行，一行一段直接输出，
段落全被切碎；回次行与回目行也常被 OCR 弄糊（「弟三十七回」「第四十才回」「卷之四卜四」）。
处理办法：
- 按句末标点把折行重新合并成段（段长中位数 28 → 133 字）；
- 回次以卷序为准（一卷一回，卷 N = 第 N 回），不采信 OCR 的回次行；
- 回目从正文首行的回目行取，取不到时按容与堂本补（4 处）。

**字词讹误没有清理。** 识典的 OCR 在这本上损字很多，`scripts/check_structure.py` 只能查出
机械类的残留（ASCII、半角标点、裸 PUA，这些已清零）。正文的错字同样是错的，但需要逐句对勘
另一个版本才能定，这一批没做——四部书在 `fix_progress.json` 里都记 `needs_review`。

**《三国演义》有 5 卷没逐则切开。** 卷四、五、六、十七、二十、二十三在识典上整卷压在一页，
页内没有分则标记，只能整卷作一条，这些记录带 `tags: ["该卷目次未逐则切开"]`。宁可标出来，
也不按字数硬劈。

**《红楼梦》缺 12 回回目。** 程甲本有 12 回（1、5、27、30、32、33、69、72、74、81、95、115）
底本没有小标题，回目按通行本补，见 `scripts/shidian/convert.py` 的 `HLM_TOC_FALLBACK`。

**《西游记》的李卓吾总批已剔除**（`總批：` 及其后整段），序与题辞未收。

## 抓取脚本

```bash
cd scripts/shidian && npm install && npx playwright install chromium

# 1. 目录：从书页取起点，顺「下一篇」链串齐章节 id
node build_cat.mjs GY025 /tmp/hlm/catalog.json
# 2. 正文：每章渲染后的 <p> 段落（不解析内嵌 paragraphList，那里的句子是碎的）
node text.mjs GY025 /tmp/hlm/catalog.json /tmp/hlm/raw.json
# 3. 落成记录
python3 convert.py /tmp/hlm/raw.json 清/小说/红楼梦/hongloumeng.json --book hongloumeng
```

| 书 | bookId | convert 参数 |
| --- | --- | --- |
| 三国演义 | CADAL02111749 | `convert_sanguo.py`（版式不同，单独一支） |
| 水浒传 | NGJ89241199901879587548 | `--book shuihu` |
| 西游记 | NA11023 | `--book xiyou` |
| 红楼梦 | GY025 | `--book hongloumeng` |

`build_cat.mjs` 的目录树是虚拟列表，一次只渲染十几项、滚到底也只多几项，所以靠「下一篇」串链；
这也是为什么不能直接用 `chapter.mjs` 的目录正则抓这几本。
