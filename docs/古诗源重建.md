## 字段

```
author     照底本（`无名氏`、`乐府歌辞`、`杂歌谣辞` 也照抄）；底本作者行被抄成评语、
           或把作者与篇题并成一行抄的，逐条核过（见下文）
dynasty    照底本卷次的时段（卷一先秦、卷二～四汉、卷五～六三国、卷七～九晋、
           卷十～十四南北朝，卷十四的隋诗段记隋）
title      照底本；底本漏抄篇题的（作者名后面直接是评语或正文）按首句补
section    底本的 ○ 时段（古逸、汉诗、魏诗……北魏诗【附】……）
paragraphs 正文，一首一段，段内句读照底本；一首多行的按行拆段
notes      行内夹注与沈德潜评点
prologue   正文之前的引书与本事（`《史记》：……`、`汉末建安中，庐江府小吏……`）
tags       ["古诗源", "卷N"]
source_line 底本行号，便于回查
same_as    与库内已有正文逐字相同时，指向那一条的 id，正文位置只写一句「见该条」
```

## 底本的三种排法

底本一首诗的抄法不统一，脚本按「空行 + 短行（无句读、≤ 14 字）」切段首，再按后面跟着什么判身份：

| 形状 | 例 | 判读 |
| --- | --- | --- |
| 头 \| 正文 | `击壤歌` / `日出而作……` | 篇题 |
| 头 \| 头 \| 正文 | `高帝` / `大风歌` / `大风起兮……` | 作者 + 篇题 |
| 头 \| 头 \| 头 \| 正文 | `陆机` / `士衡诗亦推大家……` / `短歌行` / `置酒高堂……` | 作者 + 评语 + 篇题 |
| 同上，中间那行是引书 | `太公兵法引黄帝语` / `以下古逸谐语。` / `日中不彗……` | 篇题 + 题注 + 正文 |
| 头 \| 头 \| 正文，第二个头是作者名 | `司马彪` / `陆机` / `短歌行` | 上一首漏抄篇题的作者行 + 新作者 + 篇题 |
| 头 \| 正文，头在作者表里、正文是一长段评语 | `张华` / `茂先诗，《诗品》谓……` / `太仪斡运……` | 作者 + 评语 + 漏抄的篇题（按首句补） |

底本把作者行抄成评语的（`沈约` 那条是「家令诗，较之鲍、谢……」、`庾信` 那条是「陈、隋间人。」），
作者靠行号表 `AUTHOR_FIX` 认；作者与篇题并成一行的（`书屏风诗大义公主`、`杂诗思妇临高台，长想凭华轩。`、
`答孙缅歌《南史》：`、`无名氏短兵篇`），靠行号表 `HEAD_FIX` 拆。

## 正文里清掉的排印残迹

| 底本 | 处理 |
| --- | --- |
| 行末 `【……】` | 抽进 `notes`（沈德潜评点） |
| 句中 `【同纠。】【音岸。】【古陵字。】` | 抽进 `notes`，正文里用 `【】` 还原，知道注的是哪个字 |
| `\ue3ac`（PUA） | 评语内部的分隔符（排印本的分号），换成 `；` |
| 末尾粘着的评语（`……长夜漫漫何时旦。长夜句感慨。`） | 逐条列在 `TAIL_NOTE` 里拆进 `notes` |
| `■〈魚旦〉` 这类字形描述 | 照底本保留（生僻字的拼字写法） |
