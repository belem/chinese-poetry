# haitang 语料整体重跑：判重口径与 1273 条的去向

`scripts/haitang/import.py` 把 `reference/mit_licence_haitang/`（11407 条）补录进本库。
2026-10 首次补录只做了**一次**判重，之后 `--only works_3` 复跑过一次（收 5 条）。
这次把 8 个源文件整体重跑，发现原判重口径会把大量已在库里的条目当成新篇目收进来。
逐条判定见 `docs/haitang重跑.tsv`（11407 行），本文件说明口径。

## 问题

重跑预演收 1273 条。逐条查下来，这 1273 条里**没有一条是库里真缺的篇目**，
全是判重口径的漏子。改造后重跑：收 511 条、判重 10896 条。

## 四处根因

### 1. 判重键取的是原始正文，写盘写的是清洗后正文

`main()` 原先是 `key = dedup_key(content)`（原始正文），而落盘用的是 `clean_text(content)`。
源是数字出版转码，正文里有这些东西：

- 编者加的拼音夹注：`召（shào）滑`、`酴(tu)醾 (mi）`、`陂(bēi)田`、`擪(ye)管`
- `\r\n` 折行、词尾的 `！`/`？`、重复标点

这些在清洗时都会被处理掉（夹注删掉、标点归一），库里的正文当然没有它们，
键就永远对不上。于是**清洗后与库里一字不差**的条目照样被收。

修法：判重键与写盘正文同源（`clean_text` → `to_paragraphs` → `dedup_key`），
并在清洗里先删注音夹注（`RUBY`），再走「字母数字 → □」那一档，
否则注音会被写成缺字记号 `□`。

### 2. 建索引与比较用了两套口径

`Library.scan()` 按「清洗后正文」建索引，`near_dup()` 却拿调用方给的原始键去比库里的清洗后正文，
等于一边简化字一边原文，相似度凭空掉一截。另外题名与作者没做繁简归一：
库里是「王維 / 使至塞上」，源里是「王维 / 使至塞上」，`title_index` 各查各的，永远碰不上。

修法：索引与比较统一用 `norm_text()`，题名/作者查表前先 `t2s`。

### 3. 按「章」存的书要用包含关系判，不是相似度

《论语》《孟子》《中庸》在库里一条一章（`chapter` + 该章全部节），
haitang 源一条一节。于是：

- `孟子·梁惠王上·第七节`（1313 字）对应库里从「齐宣王问曰」起的两条（合计 1859 字）
- 拿节去比章，相似度 0.83，低于阈值 → 判不出重
- 更麻烦的是「节跨章」：源的一条盖住库里两条，怎么比都不对

修法：`Library.contains_dup()`——同一部书里，源这条若整段被库里某条包住，就算已收；
跨条的拼整书正文再判。书名从题名首节（`孟子·…` → `孟子`）或目录名（`先秦/孟子/` → `孟子`）取。

### 4. 异体字：库与源各写了一种

`《望岳》`库作「盪**胷**生曾雲」，源作「荡**胸**生曾云」；`《采薇》`库作「**𤞤**狁」，
源作「**猃**狁」；`《鹤鸣》`库作「其下维**榖**」，源作「维**谷**」。
一个字之差让相似度掉到 0.97～0.98，判重和 diff 都得为它打一架。

修法：

- `VARIANT`（胷/胊 → 胸）并入 `dedup_key`——这是「同一个字的两种写法」，该统一
- `LOOKALIKE`（𤞤/玁 → 猃，榖 → 谷）只在判重时折算，**不改写盘正文**

`猿/猨`、`滚滚/衮衮`、`杯/桮`、`只/祇`、`又/自`、`沈/沉`、`彷/仿`、`黛蛾/黛峨`
这类是**底本异文**，不是字形问题，一律不归一——替作者选字不是判重该干的事。
它们由 `NEAR_DUP = 0.9` 的同题异文判重兜住，`docs/haitang重跑.tsv` 里 615 条「同题异文」
就是这一类，相似度最低 0.90、中位 0.98。

## 11407 条的去向

| 判定 | 条数 | 处理 |
|---|---|---|
| 正文相同（清洗后逐字相同） | 9712 | 判重，不重收 |
| 清洗后相同（源原文有注音/标点残渣） | 30 | 判重，不重收 |
| 同题异文（同作者同题，相似度 0.90–0.99） | 615 | 判重，不重收 |
| 节含于库章（论语/孟子/中庸等分章书） | 533 | 判重，不重收 |
| 形近异体（𤞤/猃、榖/谷 等） | 4 | 判重，不重收 |
| 库中无此篇 | 513 | **真正的补录候选，另案处理** |

「库中无此篇」513 条里有整部书缺的（《周易》65 条、《荀子·劝学》、《中庸》若干章），
也有单篇缺的（姜夔《暗香》《一萼红》、柳永《夜半乐》《迷神引》、李清照《念奴娇》）。
这批要按 #40 的口径逐条核过来源再收，不属于判重修的范围，本 issue 不动它们。
