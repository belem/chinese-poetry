### 1.6 题名格式不统一

- **序数写法两套。** 章回小说用「第1回」，笔记志怪用「卷1」（`搜神记·卷1`、`虞初新志·卷1`、
  `阅微草堂笔记·卷1`、`小窗幽记·卷1`），三言二拍却用「第1卷」（`警世通言·第1卷`）。
  同一层次三种写法，建议统一成「卷1」。
- **书名前缀有无不一。** 四大名著题名不带书名（`第1回　…`），其余书都带（`镜花缘·第1回　…`）。
  单看「一本书一个目录」其实不必带，但既然已经不一致，改哪一边都是全库改动，先记账，不动。
- **空回目。** 红楼梦「第51回　」题名只有回号，没有回目（见 2.1，那一条本身是错位记录）。

### 2.1 红楼梦：第 51 回整条张冠李戴，第 50 回尾巴接错（2026-11 已改，见 2.7）

这是本轮最重的一处，牵动回目与韵文两边：

- `第51回　`（无回目）这一条，正文从「中不見一女子」句，儼然大家」开始，**上一句属于第 50 回
  李紈评诗**；接着是宝琴十首《怀古绝句》（第 50 回末），然后是袭人回家（第 51 回正文）。
  也就是说，**第 50 回的结尾被切进了第 51 回**。
- 第 50 回那条的结尾是「…何不寫出來大家一看？」要知端的」，**断在半句，且丢了「且听下回分解」**；
  紧接着挂着一句残批「蒙回末總批：詩詞之峭麗、燈謎之」（尾巴被吃掉）。
- 结果：第 50 回末缺一大段（评诗 + 十首怀古），第 51 回少半段开头与整个回目。

修法：把第 51 回条目前的「中不見一女子」…十首怀古末句」整段搬回第 50 回末，
第 51 回只留从「冬日天短，不覺又是前頭吃晚飯之時」起的正文，回目从目录页补。

### 2.3 水浒传：折行合并后丢句号，诗赞与正文黏连

底本按 26–30 字折行，合并回段时界面丢了句末标点，后果有两个：

- **诗赞和下一段正文黏成一坨。** 第 11 回开头：
  `馬之報。柴進道：既是兄長要行…` 前面那半句「…當以犬馬之報」是诗赞的末句；
  第 34 段 `頭綰兩枚丫髻…` 后面直接接「吕洞賓有首牧童詩，道得好：」，中间无分隔。
- **段末无标点。** 7558 段里 3152 段（41.7%）结尾不是句末标点，正文切分基本靠不住，
  引诗、对话、叙述分不清。

这本本来就记着「还没洗干净」（`docs/名著增补.md`、`docs/progress/_新增名著` 一脉），
这一轮确认了病根在**折行合并这一步**，不在 OCR 本身。修法应为重跑合并（按句末标点切，不按长度切），
不是逐句手补。同理：警世通言 39.4%、小窗幽记 44.2%、二刻拍案惊奇 27.3% 的段末无标点，
东周列国志 95.6%（几乎全篇无标点）—— 都是同一类折行残迹，而 `三国演义`（8.6%）、
`西游记`（2.9%）、`红楼梦`（3.7%）、`儒林外史`（1.4%）是好的，可作对照。

### 2.4 引导句与韵文没有分开的情况

红楼梦切得最细（`詩曰：`／`赤壁懷古　其一`／每两句一段），西游记同样把「詩曰：」单列一段；
封神演义则把「詩曰：丞相金鑾直諫君…」整句塞在一段里，三国演义、水浒传是把诗直接编进叙述段。
三本书三种切法，这不算错（底本排版各异），但**同一本书内要一致**：
封神演义第 1 回把「詩曰：」与诗并作一段、第 2 回又拆开，属内部不一致，改时统一。

- 三国演义第 1 则第 2 段：`臣聞春秋讖曰…謹奏。` 是完整表文，没有问题；但同则第 0 段的

- 儒林外史：正文末挂回末评语（第 1 回末「秦老是極有情的人，𨚫不讀書…作者于此寄慨不少。」），
  与「评语不收」口径冲突，需摘。
- 镜花缘：夹批直接混进正文，且认不出是批语：
  `開卷以班昭爲衆閨秀作引，可謂開門見山菊如。`（「菊如」是批者署名）

### 2.8 东周列国志：回号与正文整体错位 + 逐句对勘（2026-11 已改）

这是本轮最重的一处，`docs/progress` 里记的「只做了机械清洗」到此为止。

**底本与对校本。** 数据集正文与识典古籍《東周列國全志》（清 蔡元放 評本，書成山房咸豐四年刻本，

### 3.1 机械扫描结果（`scripts/check_structure.py`）

小说目录下**没有**西里尔/希腊字母、假名注音、裸 PUA —— 这几类是诗、词里的病，小说这边干净。

| --- | --- |
| missing_char（`□` 缺字） | 473 处，11 个文件 |
| ascii_residue（ASCII 残渣） | 103 处，6 个文件 |
| ci_pattern / shi_line_length | 0 |

`□` 集中在警世通言（153）、二刻拍案惊奇（143）、封神演义（47）、西游记（32）、镜花缘（31）、
阅微草堂笔记（29）。

`ascii_residue` 分两类：一类是页码、卷次混进正文（`1694`、`12`）；
另一类是 **OCR 把「。」「一」「十」「曰」认成「1」**，例如：

```
…覺袂言1：幸君無及于亂…        （警世通言 卷 10，应为「覺袂言曰」）
…衆丫鬟勸住1人人悲傷不巳…        （喻世明言，应为「衆丫鬟勸住。」）
…梁媽媽叉氣又苦又受，1驚又愁…    （同上，「又受一驚又愁」）
```

`1` 全库 103 处，其中东周列国志 47 处、喻世明言 47 处是同一模式。这是**可自动判**的一类：
「1」处在句首、前面是「，」或「。」时多半是「一」；处在「言」「曰」前是「曰」；
处在「住」「了」「來」后面、下句另起时是「。」。批量处理前须抽样核过。
