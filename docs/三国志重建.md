## 为什么在 `晋/`

陈寿（233—297）是巴西安汉人，蜀汉时任观阁令史，入晋后为著作郎，书成于晋灭吴之后。
`authors/authors.json` 里他的 `dynasty` 记的就是「晋」，按「作者朝代说话」的既定口径落位。
三国这一段历史不等于「三国」这个朝代目录——`三国/` 下装的是曹魏、蜀汉、孙吴作者的现存诗文
（`三国/诗/poet.sanguo.json`），史书本身归撰者。

## 版式

题名作「三國志卷N　X書N　篇名第N」，一卷一条：

```
三國志卷1　魏書一　武帝紀第一
三國志卷34　蜀書四　二主妃子傳第四
三國志卷65　吳書二十　王樓賀韋華傳第二十
```

- 卷次用阿拉伯数字，与原书「卷一对卷一」；卷内篇题照底本繁体，不改字。
- `paragraphs` 是这一卷的分段全文：陈寿本文与裴松之注**都在里面**，一条一段。
- `author` 记「陈寿」，`dynasty` 记「晋」。裴松之（372—451）的注不另记作者。
- 没有 `sources`（不写语料出处名，见 AGENTS.md）。

## 本文与裴注为什么不拆开

底本里两者只靠「〔一〕〔二〕…」这个标记分别，裴注段首就是「〔N〕」，本文段中的注号
「〔N〕」则指向其后那一组注。要拆成 `note` 字段就得重新断句、重建指向，
而底本本身已经把这件事做完了——照录反而不会错。因此：

- 段序即底本的行序，一卷之内不重排；
- 以「〔N〕」起句的段落共 1702 段，可以据此筛出裴注。

## 底本自身的两个毛病

**卷一小注编号有缺。** 卷一「太祖少機警」一段的注从〔一〕〔二〕直接跳到〔三〕〔四〕，
缺一组；后面「光和末」一段的注又从〔一〕〔二〕起。这是底本的分组方式，不是漏抄，
照录不改（同卷另有「〔一〕〔二〕」两组与前文重号，也是分组重起）。

**一处叠逗号。** 卷一裴注「群生注望，，遐邇怨歎」底本多一个逗号，改作一个。
这是全篇唯一一处正文改动，记在 `docs/progress/晋@小说@三国志@sanguozhi.json` 的 `fixes` 里。
