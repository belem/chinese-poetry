# `poet.han.json` 里的《楚辞》副本

`scripts/dedupe_chuci_han.py` 的说明。逐组见 [`楚辞汉诗去重.tsv`](楚辞汉诗去重.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_chuci_han.py            # 预演：逐组打印
python3 scripts/dedupe_chuci_han.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

`汉/诗/poet.han.json` 是从 `历代/` 拆出来的补录，里面混着 27 条《楚辞》各篇
（《惜誓》《招隐士》《七谏》《九怀》《九叹》《九思》），而《楚辞》整部书另在
`先秦/楚辞/chuci.json`：

```
先秦/楚辞/chuci.json#28   贾谊《惜誓》                ← 留
汉/诗/poet.han.json#68    贾谊《楚辞·惜誓》           ← 删
```

两读出自同一部底本（通行本《楚辞补注》），正文只差繁简与几处通用字
（沾濡／霑濡、後／后、虬／蚯、讬／托），不是异文。按「一件作品只留一份正文」（AGENTS.md），
删补录那份、留单行本 —— `chuci.json` 有 `section` 与分篇编次，补录是一条条散录。

## 判据

作者相同、篇名相同、正文相似度 ≥ 0.90。

篇名要归一：《楚辞》各篇的篇内小标题两书取法不同 —— `chuci.json` 题作《沉江》，
补录题作《楚辞·七叹·其二·沉江》。所以去掉「楚辞·」前缀，再取最后一个「·」之后那段比。
