# 《全宋诗》全同重出

`scripts/dedupe_quanmingshi.py` 的说明。逐条见 [`全宋诗全同重出.tsv`](全宋诗全同重出.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_quanmingshi.py            # 预演
python3 scripts/dedupe_quanmingshi.py --apply --date YYYY-MM-DD
```

## 判据（两条都要）

1. 正文 `t2s` 归一、去非汉字后**整篇逐字相同**（不是前 16 字相同）；
2. 同一件作品：同一人（署名经 `ALIAS` 归并后一致）、同一题（同样归一后比较）。

第 2 条与 `scripts/dedupe_tang.py` 的「同作者重出」同口径。作者真的不同的不动 ——
那是归属异说（《全宋诗》里同一首分署两家的一大把），与《全唐诗》一个口径：两存。

正文有出入的一律不动，那是异文。

## 本轮删了 31 条，一处不留

都是同一首在《全宋诗》里躺了两遍，留卷号靠前的、删靠后的：

- **切卷切重了一段。** 盛世忠 15 首一字不差地同时出现在 `poet.song.202000.json` 与
  `poet.song.220000.json`（两处都是同一个人的 15 首、题名全同、`id` 各异）。
  这批评语按一卷一千条切开，同一段被两个切片各收了一次。
- **同一卷里前后各收一次。** 岳珂《蘇文忠歸潁帖贊》（`poet.song.194000.json#2` 与 `#28`）、
  方岳《春暮》、釋文珦《訪山家》、釋紹曇《古樵》、陳必復《遠遊》、汪藻《春日》
  这类是同一人一段里的重出。
- **同一人分在两卷。** 王十朋、張維、姜特立、王大受、杜子更、黄春伯、李龍高、釋本才 各一首。

`id` 各异说明两条是两个切片各给的编号，不是同一份文件被读了两遍。

## 没有动的一类

`宋太宗《逍遥詠 其N》/《緣識 其M》` 是两部组诗互有重出，**题名不同**，正文也常有出入
（`姸/妍`、`淸/清` 这类古书异体与抄刻讹字）。2026-10 已按识典古籍《御製緣識》逐组核过，
只删了古书能证成的 12 条，其余两存 —— 见 [`重复清理.md`](重复清理.md)。本批不碰。
