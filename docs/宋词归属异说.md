# 宋词归属异说与别名归并

`scripts/dedupe_songci_attr.py` 的说明。逐组判定见 [`宋词归属异说.tsv`](宋词归属异说.tsv)，可随时重跑：

```bash
python3 scripts/dedupe_songci_attr.py            # 预演：分类、样例、条数
python3 scripts/dedupe_songci_attr.py --apply --date YYYY-MM-DD --reviewer <名字>
```

## 这一批做的是什么

`scripts/check_tree.py` 把「异作者」的重复一直记成「需人工判」。宋词这 116 组逐组看过，
其实只有两件事：

1. **同一个人的两种署名**被当成了两个人。`扬无咎／杨无咎`、`张元幹／张元干`、`曹邍／曹原`、
   `黄升／黄昇`、`毛幵／毛并`、`朱孙／朱㫹孙`、`张／张鎡`、`王炎2／王炎（双溪）`……
   这是异体字、生僻字打不出、缺字、繁简误转、同名两人用 `2` 区分，不是归属异说。
2. **真的归属异说**：柳永／欧阳修《蝶恋花》、仲殊／宝月一组、晏殊／杜安世《凤衔杯》。
   宋人笔记里就两说并存，《全宋词》自己也不定案。

两件事都不删正文（唯一的例外见下），只按《全唐诗》的老办法给两条互挂一条 `tags`：

```json
{"author": "柳永", "title": "凤栖梧·蝶恋花", "tags": ["欧阳修《蝶恋花》"], …}
```

## 分类与处理

| 类别 | 判据 | 处理 | 本轮 |
| --- | --- | --- | --- |
| `dup_same` | 署名一字不差、正文全同 | 删一条（同一个人两批数据各收一次） | 4 条 |
| `dup_variant` | 署名一字不差、正文有出入 | 两存，互挂 | 500 组 |
| `alias_same` | 同一人的两种署名、正文全同 | 删信息少的那条 | 0 |
| `alias_variant` | 同一人的两种署名、正文有出入 | 两存，挂「一作本名」 | 25 组 |
| `attr_same` | 不同人、正文全同 | 两存，互挂 | 22 组 |
| `attr` | 不同人、正文有出入 | 两存，互挂 | 85 组 |

「是不是同一个人」不靠猜：名单写在脚本的 `ALIAS` / `ALIAS_NOTE` 里，每条都写了理由。

### 唯一会删正文的一类

`dup_same` 与 `alias_same`：同一个人、正文**一字不差**，删掉重复的那条不丢信息。
本轮 4 条都是 `吕胜己《谒金门》` 一类，两批数据各收了一次。

## 正文有出入的组：哪一份被古籍证实得更多

两批录文抄法不同（[`宋词两批异文`](宋词两批异文.md) 那 540 组的延续）。
2026-11-02 每组取两份录文的中段、末段各一句检索（620 条），逐句数「原样被证实」
与「本读一处也没有、另有一读 ≥2 种书」。结果：

- 证据**对称**的组（两读都传世，或多数字句两边都被证实）占绝大多数 —— 版本异文，两存不改；
- 只有几处一边的读法在古籍里**一处也没有**，另一读有 ≥2 种书，按讹字改了字（下表），
  改完仍两存（作者归属另说）。

| --- | --- | --- | --- |

| `ci.song.12000.json#786` 崔与之 | 归梦**绕**家山 | 归梦**到**家山 | 《中興以來絶妙詞選》《宋丞相崔清獻公全錄》《全蜀藝文志》并作「到家山」 |

挂 `tags` 不是逐字对勘，不能因此算 `clean`。

## 全宋诗、全唐诗那两批

同一套办法能用到全宋诗（异作者 1341 条）与全唐诗（异作者 793 条），但两者都**不做**：

- 全唐诗 782 组归属异说 2026-10 已按这个办法处理过（见 [`唐诗内部去重.md`](唐诗内部去重.md)），
  报告里剩的是编排卷重出与「一作某」两存，不需要再动；
- 全宋诗的一半是**联句拆条**（《來燕堂聯句》一条记在赵概名下、另一条记在欧阳修名下），
  「两存 + 挂 tags」对它不成立，得先并成一条多人联句，属另一件事。
