## 「删除旧内容、整本重出」的落法

要求是「删掉库里所有《尚书》《周易》相关内容，按 `reference/` 重出」。落法是：

- 两部在库里各只有一份正文（`先秦/文/` 下那两个文件），选本里引到「周易」「尚书」
  字样的（`汇编/古文观止/`、`汇编/昭明文选/` 的篇中引文，`汇编/蒙学/` 的用典）是**它们自己的正文**，
  不是这两部书的副本，按「一件作品只留一份正文」的判据（逐字相重）不动；
- 旧稿每一段都不留，新稿逐段来自底本 —— 旧稿的 3 条（盘庚中、盘庚下、系辞下传）在底本里
  都有对应正文，重出后自然被替换，不是另存一份；
- 目录、`loader/datas.json` 的 key（`wen-shangshu`、`wen-zhouyi`）不变，只改 `comments`；
- `author` 由「无名氏」保持「无名氏」，不带 `id`（与 `先秦/文/` 其余经部一致）。

「今文尚书」这个旧名也改了：底本含今古文五十八篇（亡篇 19 条只有书序），
叫「今文尚书」名不副实，`name` 与 `先秦/文/README.md` 都改作「尚书」。

## 底本版式

两份都是抓取稿，不是整理本：

```
书名：尚书 / 作者： / 章节数 / 字数
========简介========
…（网页摘要，不是正文）
========正文========
虞书                 ← 分卷行
尧典                 ← 篇名独占一行（2—6 字、无句读）
昔在帝尧，聪明文思…   ← 一行一段
…
【帝告厘沃】          ← 亡篇名用【】括起，可跨行：「【汩作 / 九共 / 槀饫】」
◎周书·泰誓上         ← 泰誓三篇自带出处
```

周易是「乾卦」独占一行、`（乾为天）乾上乾下` 一行、`《乾》：…` 卦辞一行、六爻各一行。

脚本据此认篇（`is_heading`）与认卦（`…卦` 独占一行），只取 `========正文========` 之后的部分；
`书名/作者/章节数/字数/简介` 是网页表头，不进正文。

## 正文改动

正文一字未改，只做两类：

**一、拼回折行的两段**（拼接处没有丢字）：

| 书 | 底本 | 拼回后 |
| --- | --- | --- |
| 尚书·尧典 | `…乃言凪可绩，三载。汝陟` ⏎ `帝位。”` | `…三载。汝陟帝位。”` |
| 周易·坤卦 | `（` ⏎ `坤为地）坤上坤下` | `（坤为地）坤上坤下` |
| 周易·复卦 | `（` ⏎ `地雷复）坤上震下` | `（地雷复）坤上震下` |
| 周易·明夷卦 | `…三日不食。”有攸往，` ⏎ `主人有言。` | 一段 |

**二、ERRATA 里的定案讹字与缺字**，全部记在 `docs/progress/` 两条记录的 `fixes` 里，
每条写明依据。分三类：

- **形近、音近的讹字**（底本必错，通行本有定字）：`日若→曰若`、`凪→厎`、`像恭→象恭`、
  `母嚣→母嚚`、`菜夷→莱夷`、`今失厥道→今失厥图`、`有惟求旧→人惟求旧`、
  `七日宾→七曰宾`、`司冠→司寇`、`悄播→屑播`、`被裕→彼裕`；
- **缺字 `□` 与未转出的方括号字**：尚书 7 处（`罔昼夜□□→頟頟`、`下管□鼓→鼗鼓`、
  `厥篚□丝→檿丝`、`菌□→菌簵`、`尔惟□薛→曲糵`、`洮□水→颒`、`敜乃□→阱`）、
  周易 4 处（`□豕之牙→豮`、`□咨涕洟→赍`、`家人嗃□→嗃嗃`、`□谦→撝`）、
  `[B139]` 两处（`𢦏不畏死`、`暋为羞刑暴德`）、`[B194]→蘉`、`[A156]→敹`。
  这几处都有《尚书正义》伪孔传本 / 王弼本的一字之据，不是猜的；
- **抓取残迹**：半角逗号 `,`（乾卦）、小分号 `﹔`（坤卦）、孤立的起引号「（噬嗑卦）、
  衍字「斋」（睽卦）、拆字「女后）」→「姤」（姤卦）、`。，` 叠标点（酒诰）、
  误点断的逗号（盘庚中 2 处、洛诰「不易」、酒诰「远服贾，用孝养」）。

**两说并存、底本不算错的，一律不动**：异体字（`無咎，無譽` 的繁体）、古今字（`遯`/`遯卦`）、
`：「` 与 `，` 混用的爻辞提头（底本 64 卦里两种写法都有）、`「」` 与 `“”` 混用（多方、君陈、冏命用
`“”`，余篇用 `「」`）。这些是底本的行款，不是错字。

## 亡篇怎么处理

底本有 19 条只有书序、没有正文 —— 也就是「亡篇」：《汩作》《九共》《槀饫》《帝告》《厘沃》
《汤征》《汝鸠》《汝方》《夏社》《疑至》《臣扈》《典宝》《明居》《沃丁》《咸乂》《伊陟》
《原命》《仲丁》《河亶甲》《祖乙》《分器》《旅巢命》《归禾》《嘉禾》《成王政》《将蒲姑》
《贿肃慎之命》《亳姑》共二十八篇，底本按旧本的编者把它们并成 19 条（如「夏社疑至臣扈」一条）。

这些条目的 `paragraphs` 照录底本那一行书序，`note` 里写明「底本只有书序、没有正文；亡篇不补正文」。
**不臆造正文**：凭空补出来的「尚书」比缺着更坏。

## 与旧稿的差异

旧稿 3 条（商书·盘庚中、商书·盘庚下、系辞下传·其二）已全部替换：

| 旧稿 | 新稿 |
| --- | --- |
| `商书·盘庚（中）` 7 段 589 字，`□` 缺字 2 处 | `尚書·商书·盘庚中` 7 段 583 字，无缺字 |
| `商书·盘庚（下）` 2 段 268 字，`□` 缺字 1 处 | `尚書·商书·盘庚下` 2 段 267 字，无缺字 |
| `系辞下传·其二` 13 段 458 字（十翼之一） | 无：底本没有十翼，周易只收经文六十四卦 |

旧稿的「盘庚中/下」与底本段数相同（中 7 段、下 2 段），差异在缺字与讹字：
旧稿的 3 个 `□`（「以迁□肆上帝」「曷瘳□汝不谋长」「古后之闻□承汝」）在底本里是逗号，
是当年爬取时被吞掉的标点；重出后照底本作逗号，不再有缺字。
旧稿的系辞是十翼，底本没有，这一条不再保留 —— 十翼另找底本再补，见「还有没做的」。

全部新稿 450 段（尚书）、513 段（周易），逐段来自底本，段数即底本的行数。

## 复现与自查

```bash
python3 scripts/import_shangshu_zhouyi_reference.py            # 预演：79 条 / 64 条、字数、勘误数
```
