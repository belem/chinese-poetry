# 四书与《道德经》依底本整本重出（2026-11）

五部书此前都是从别处抓来的副本：儒家四部来源不同（《论语》是早期 [@wptoux](https://github.com/wptoux)
提供的简体版，《孟子》部分是 `poet.xianqin.json` 补录拼进去的），《道德经》是当年从「诗」里拆出来的 81 条。
本轮按 repo 内已有的底本**整本重出**，不再打补丁。

## 底本

```
reference/論語.txt    20 篇 ## 分篇，空行分段，1050 行
reference/孟子.txt    14 篇 ## 分篇，空行分段，1475 行
reference/中庸.txt    一篇到底，38 段
reference/大學.txt    一篇到底，16 段
reference/道德經.txt  81 章 ### 分章，章内按句分行，句末夹注「(一作…)」
```

五份都是繁体点校文本，与 repo 里其余底本（`reference/詩經.txt`、`reference/千家詩.txt`、
`reference/二十四史/…`）同一套体例，也是《诗经》《千家诗》已经走过的路：**底本进库，别处抓的不留。**

重出后的文件与底本逐字一致，`scripts/import_sishu_reference.py --check` 五份都报「一致」。

### 《论语》

旧文件是简体，且 533 段里有 21 段来自 `poet.xianqin.json` 的补录——补的写法是「正文对不上但有书可归
就塞进去」，结果同一句「學而時習之」在文件里出现两次，另有一批是同一章的异文并列（如「未若貧而樂**道**」
与「未若貧而樂」）。底本是完整的一本，这些重复与异文不再保留。

分章口径照底本：底本「子曰」与「曰」分段的，就分成两条（如《堯曰》篇「咨！爾舜……」与「子張問於孔子曰……」）。
504 段比通行本 492 章多，差的就是这类；按底本读，不改。

### 《孟子》

旧文件 784 段，723 段来自底本，另 61 段是 `poet.xianqin.json` 当年按「书·卷·篇·节」补录进来的
（[`docs/先秦拆分.md`](先秦拆分.md) 记着「孟子按书·卷·篇·节补 52 节」，后来又有一轮）。补录段与底本
章次重叠而文字有别，等于一本书两套正文。底本完整，只留底本。

### 《中庸》

唯一一处实质差异：旧文件「致廣大而盡精微，極高明而中庸」脱了「道」字，底本作「極高明而**道**中庸」。
其余是异体与通假，按底本统一：

```
底本  塗 願 繫 嶽 洩 卷 鼈 並 墜
旧文  涂 愿 系 岳 泄 拳 鱉 并 隊
```

（底本用正字，旧文件用后起通行字形。此库惯例是繁体、正字，故取底本。）

### 《大学》

16 段与旧文件段段对得上，只差异体与通假：

```
底本  閑 揜 苟 介 寔 菑 並
旧文  闲 掩 茍 个 实 灾 并
```

底本没有朱熹的补传与「右经一章」的标识，本文件照底本，不另加结构。

### 《道德经》

旧文件 81 条，问题最多：

- **简体**，且夹着「無」「德」半简半繁的写法（`含「德」之厚`）。
- **章次乱**：第 71 章排在第 2 条，第 40 章排在最后一条，第 39 章另有脱漏。
- **字号不统一**：`道德经（第一章）` 用简体标题，正文用简体。

重出后：81 章一章一条，`title` 作 `道德經（第N章）`（中文数字，与底本 `### 第一章` 一致），
正文繁体，章内按底本的断句分行成 `paragraphs`（218 段）。

底本里的 16 处夹注是校记不是正文，移到该条 `note`：

```
道德經（第一章）  note: 句讀或作「無，名天地之始；有，名萬物之母。」
道德經（第十五章）note: 一作「渙兮若冰之將釋」
…
道德經（第三十七章）note: 一作「夫亦將無欲」；一作「天下將自定」，非
```

## 没改的

- **《论语》十二章、论语三则、《寡人之於國也》《生於憂患，死於安樂》《齊桓晉文之事》** 等
  `汇编/课本选目/`、`汇编/古文观止/` 里的选段不动。它们是教材与选本的独立单元，
  与《先秦拆分》里「不往本经里塞」的判断一致，也与「逐字相重的删选本、不删选本自身的用场」那条不冲突：
  这里的用场是课本，不是经。
- **`reference/*.txt` 不动**，包括其中明显的异体与个别讹字（如 `絶`/`絕` 混用）。
  底本是要点校的对象，改了底本就失去了「另一套独立文本」的用处。
- **不补字、不校勘**。五部都不作章句校记，不用《十三经注疏》或别的刻本互校；
  本轮只做「同一部书、同一个底本」的对齐，正文一字不添。

## 质检

`python3 scripts/check_structure.py` 里，这五部只剩 `box_drawing` 一类命中，且是误报：
《孟子》四处 `──`（「威武不能屈──此之謂大丈夫」「又顧而之他──此其為饜足之道也」等）用的是
U+2500 制表横线，与底本 `reference/孟子.txt` 一致，被脚本的 `BOX_DRAWING`（`[\u2500-\u257f]`）当成了乱码。
底本本来是繁体点校文本，`──` 就是它的破折号写法，改了就与底本不一致，故照底本保留，另记在此。
`missing_char`（`□`）、`kana_bopomofo`、`bare_pua`、`ascii_residue` 四类，五部文件均为 0。
